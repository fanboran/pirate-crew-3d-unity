## 实机口径（像素化路径实测修正，2026-09-29）

实机图（`docs/images/pixelart-path/r14/`）出过两处"Blender 预览看不出、进管线才暴露"的问题，
已修在本脚本里，改其它件时照这两条自查：

1. **曲面上不做周向凹槽**：冷却塔原用"隔扇区半径 ±5.5%"做棱槽 → 实机三档色带下相邻扇区互相翻档，
   读成棋盘格（压到 ±1.5% 后读成镂空壳）。现改为**壳体光滑 + 外凸细肋条 ×16**（肋条单一面朝向、
   只落一档色）。平面凸起（厂房压型墙的外凸竖棱、罐体的箍带）不受影响。
2. **亮锈橙别铺长杆**：围栏横杆/竖条由 `Kit_Rust` 改 `Kit_RustDark`——成排围栏用亮橙会把整片场地染橙。

另：材质的 `roughness` 只服务 Blender 预览（实机逐物体只吃 albedo），预览用哑光 + 像素块边长 2，
**不做全图色阶量化**（会把 `#8C4A28` 推成饱和红）。
