# 美术翻新 · 技术口径审计报告（等距像素卡通）

> **审计基准**：工作树（最新提交 `fdf8a2d` + 未提交改动），工程 `pirate-crew/`（Unity 2022.3 / URP 14.0.12）。
> **审计对象**：技术域文档——渲染规格与四份调研、资产管线两篇、架构三篇、[描边 Shader 调试](../技术/渲染/描边Shader调试.md)、两份遗产调研；逐条与代码/资产实况对账。
> **三个审计问题**：①条款与工程实况是否一致；②条款之间是否自洽（同一量多口径）；③照条款做能否达成目标观感。
> **目标观感锚点**（自参考图实测）：真等距/2:1 类手绘像素等距、粗块像素（1 米 ≈ 30~50 像素、角色占屏高 ≈ 9%）、深色描边、明暗 2~3 档、局部暖光池 + 柔光/星芒、结构线 1px 画进贴图、场景偏暗（灰阶 p50 ≈ 32/255）。
> **未覆盖**：运行时性能实测、PlayMode 与实拍判图（归 M0/M1 门禁）、调研外链复核（审计期间网络不可达，与 `阳光感打光调研` 自记的同类受阻一致）、UI 与关卡设计域、`external/` 参照库的源码级复核。

## 0. 结论摘要

1. **方向公式可达成，且 shader 侧进度好于文档**：`PirateToon.shader` 已实现显式非等宽阈值阶梯 + 替换式暗部色 + 4×4 Bayer（并额外做了**块对齐相位**）+ 反向壳三 Pass + 平滑法线（GBA 编码 + 烘进顶点色 + 单测），另有若干六轮实拍得出的补丁（视线拉近、渲染序 +50、`_OutlinePixels=2`）**文档从未回写**。
2. **缺口集中在资产侧与配置侧**：像素纹理/调色板/密度校验/Blender 导出模板 **0% 落地**；渲染篇 §6 全局设置**大面积未达标**（MSAA 实为 4x/2x、Battle 场景 Bloom 实开、全屏 Sobel 描边 Feature 仍在两档 Renderer 挂载）。
3. **文档漂移三类**：①条款与实况不符（§6 三项、线宽 1px vs 实测 2px、`Offset 1,1` vs 视线拉近）；②同一量多口径（结构线宽度三口径、密度公式缺开方、红线 4 的域归属与现行架构互斥）；③跨域过期（EventBus 契约 5 处错登 + 1 处载荷类型不符 + 2 个 campaign 事件更名/删除；管线合并任务书阶段 A 被改道未回写；场景接线审计 6 项遗留）。
4. **一条与观感直接冲突的规格**：§6「Bloom 关——辉光横跨像素网格毁块感」——理由在现行管线顺序下**不成立**（URP Bloom 与像素化之间隔着 point 降采，光晕会被量化进 360p 网格），而参考观感最显眼的正是柔光/星芒；规格与两份调研都**没有**任何柔光机制。

## 3. 对齐参考观感的缺口（照条款做也做不出来的部分）

1. **纹理侧空转**：全项目**没有一张像素 3D 纹理**（53 张 Art 纹理全是 UI/FX/水贴图）；参考观感里占比最大的"砖缝/木板缝/裂缝/格纹"（1px 结构线）依赖尚未启动的量化链。当前画面是"平涂色 + 描边"，与手绘参考的差距主要在这里。
2. **调色板纪律 0% 落地**：无板文件（png/ase/gpl/lospec）、无 OkLab 锁板映射、无量化器；色带色目前是 `ToonPilotSetup.cs` 里的提案 hex。
3. **局部暖光池无机制**：附加光 0 + 单平行光 + 扁平环境光的组合下，火把/宝箱那种"局部暖光池"只能靠自发光贴图或贴花，规格未给通道与锁板归属。
4. **柔光/星芒无机制**（见 H3）。
5. **描边色不随材质**：装配链统一填 `StickTokens.INK`；参考像素画常用"随主体色加深"的描边（皮肤/衣物/木器各不相同），无派生规则。
6. **色带只有"亮 1 + 暗 2"**：`_BandCount` 第二刀只切暗侧内部（`PirateToon.shader:209-213`），受光面内部无更高一档；ramp 纹理形态未提供，美术调阶只能改材质浮点。
7. **顶点色 R 阈值偏移只有通路没有入口**：`SmoothNormalsBaker` 恒写 R=0.5 中性，全仓无刷顶点色工具——"美术刷 R 改切分点"目前不可用。
8. **密度/线宽无对账工具**：`ppm = RT高 ÷ (2×正交size)` 没有计算器/测试；试点相机 `ToonPilotSetup.cs:110` `orthographicSize=7` 不在任何档位表内，ppm 对账无从做起（7 → 25.7 ppm）。
