### 贯通线 2：装配方式是 Find 存量、死 UI、「假表」的共同根因

架构 P0-2（生成式场景 + 无 `[SerializeField]` 可连）自带因果链 → P2-7 的 Find 存量；
全量§三.4 列的是同一批 Find；视觉§二.1 的水模拟被杀本质是同一病——一个序列化引用 +
`SetActive` 粗暴关闭，没有显式的「退役什么、保留什么」连线；UI 的假回合表 / 假提示
是装配期写死、运行期无人接管。**战术修复各自为政会复发；结构性修复（稳定结构
Prefab 化 + 显式连线）一次关闭整族。** 归 Track 8，前置「场景接线审计」（本目录 README
待补表已列）。
