## 过期判据

两条满足任一即归档（不等于"这份报告当年写得不对"——它当年是对的）：

1. **对象消失**：报告所审的代码/资产/内容被整批删除或整体重写，逐条发现已无对应物；
2. **同类取代**：同类型的新一轮报告已把它逐条核销，旧清单不再对应当前代码。

仍有活账（未被销号、且对象还在）的报告**不归档**，继续留在 [专项/](../专项/)。
