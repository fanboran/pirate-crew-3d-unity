## 红线（已裁决事项，不许翻案、不许顺手改）

1. **图跨度维持现状**（150–280u，不缩不放）——2026-09-17 用户已裁"方案 D"：
   大图配原版分层军火（twang20 近程 / twang30 中程 / 全图级五件）+ 俯视海图瞄准 UI。
   "空尺度"问题用**内容填充**解决，不许缩图。
2. **「可见海域预算」数值不动**：正午雾 150→1200、全涌起点=半径+122、阴影 224、SSAO 0.55、
   地平线融合 1000→1400（契约表见 `docs/审计/视觉审计报告.md` §三）。
3. **角色模型不许改**（程序化低模船员是用户定案的最终风格）；场景资产走 Blender 管线。
4. **站面 box 是玩法真值**（`WorldMapRules` 连通性/跳跃测试守着），kit FBX 与散布是视觉层；
   改布局后连通性测试必须全绿。
5. **武器字段不归你**：`WorldMapCatalog.cs` 的武器/空投配置由主协调线的"分层军火配置"批次
   （方案 D）负责。你只动 placement / 出生点 / 注记相关字段；若武器字段尚未被该批次改过，
   保持原样别碰。

## 工作分解（每图一轮，图与图之间独立提交）

1. **基线**：先按现状重拍 8 图三机位（6/8 图从未被看过——地图审计 §二.11）。
2. **逐图迭代**（建议从 wreck_hymn、atoll_ring 之外的 6 图开始，这两张已相对最新）：
   - 打破镜像：非对称重摆但保持双方公平（路线数/高程/掩体量对等，形状不镜像）；
   - 密度：死水区填充次级地形件/礁石/叙事道具（kit 里有的是），散布 2-4 → 4-6 件/站面
     （交接 §20 既定方向）；
   - 出生构图：立一条"出生点面向战场、机位画面 ≥1/3 是可读战场"的规则并逐图校验；
   - 清理：悬空绿色方块、摆件与 kit 穿插、灰盒底座露边、共面缝隙；
   - 注记同步：placement 表的中文注记与实际数据一致（别再脱节）。
3. **每轮门禁**：改 `WorldMapCatalog` → EditMode 连通性全绿 → 重拍该图 → 判据 + 人眼 →
   原子提交（`fix(worldmap): <图id> 布局重摆——<要点>`）。
