## 0. 为什么重做（一句话）

Unity 版第一版把 Flash 原版的 **2D 侧视坐标 1:1 搬进 Unity 的 XY 竖直平面**、并用
`FreezePositionZ` 焊死深度，成了"披着 3D 引擎的 2D 游戏"；而 Godot 基准是真 3D
（XZ 地面 + 45° 三维相机 + 单位沿 Z 分路）。现在按 **Godot 的空间结构 + Flash 的数值**重新对齐。

### W2 —— 爆炸 3D 泛化（Combat 域）

- **名下文件**：`Scripts/PirateCrew/Combat/ExplosionResolver.cs`、`Tests/Combat/ExplosionResolverTests.cs`、

- **做什么**：按规范 §5 把 `ExplosionResolver` 从 2D 泛化成 **3D 球**：

- **验收**：`HarnessScope=Combat` 全绿（原 86 条按需更新期望值，并说明每条为何调整）+ 新增 3D 用例
