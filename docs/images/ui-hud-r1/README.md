# UI HUD 样板首拍档案（多彩卡通 · 图标优先版）

> 多彩卡通 UI 重设计（2026-09-19 用户三轮裁决）的**样板屏验收图**——战斗 HUD。
> 原始 PNG 在 `export/art-review/uihud-r2/`（不入库），此处为压缩归档版。
> 复现：ArtGate 全链 → 播放器构建 → `external/build/PirateCrew3D.exe -artReviewOut <dir>`。

## 风格定案（三轮裁决合并）

- **高饱和多彩**：17 武器 / 7 职业各有语义色相（哈迪斯式深底 + 宝石彩图标 + 金强调），色表唯一真值在 `UiSkin.WeaponColor/CrewColor`（同时是图标的静物主色，UI 与图标天然同色系）。
- **形状收敛**：小圆角（面板 8 / 按钮 6 / 图标格 10）、1px 细边、无贴纸硬投影——层级靠深底（InkDeep #1C2333）与彩色 chip 的明度差。
- **图标优先**：武器=静物图标格（选中才显示一行名字+说明）、名册=职业头像 pips（死亡换骷髅）、回合=徽章纯数字、动作钮=符号图标（准星/眼睛/舵轮/旗/抛物弧）。
- **juice**：按钮按压下沉+四态、血条白色 damage ghost 残影、回合徽章 pop、面板滑入、三星逐颗 pop（动效常量全在 `UiMotionRules`）。
