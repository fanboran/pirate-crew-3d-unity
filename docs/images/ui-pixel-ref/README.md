> 仅作为**内部风格目标**保存，**不得进构建产物、不得再分发**。本工程不复制它的任何贴图资源，

## 二、逐像素量出来的斜面结构（条形控件）

对 `ref-bars-life-mana.png` 取一条穿过条体中部的竖切（x=60），逐行颜色如下
（基本单位 **2px**，全部是整像素、无抗锯齿）：

| 位置 | 厚度 | 实测色 | 角色 |
| --- | --- | --- | --- |
| 外环（上） | 2px | `#54481E` | **外圈暗环**（同一色相的最暗档） |
| 斜面（上） | 2px | `#B9973B` | **亮档**——受光面，光永远来自左上 |
| 内暗线 | 2px | `#54481E` | 斜面**内侧**再压一道暗线 → 这是"凹陷感"的来源 |
| 填充亮沿 | 2px | `#FFA68B` | 填充体上沿提亮（模拟液面受光） |
| 填充主体 | 8px | `#F53C40` | 填充色 |
| 填充暗沿 | 2px | `#99133F` | 填充体下沿压暗 |
| 内暗线 | 2px | `#2F261F` | 同"内暗线"，底侧 |
| 斜面（下） | 2px | `#8C6F2A` | **中间档**——背光面（不是纯暗色） |
| 外环（下） | 2px | `#2F261F` | 外圈暗环 |

**条体总高 24px**（9 段 × 2px + 填充 6px）。换算成生成器的参数：

- `ink` 外环 = 2px，色 = 同色相最暗档；
- `bevelHi` 上/左 = 2px，色 = 同色相最亮档；`bevelLo` 下/右 = 2px，色 = 同色相中间档
  （**不是纯黑**——这是"金属/木牌感"而不是"描边感"的关键）；
- `innerShadow` = 2px 暗线，夹在斜面与内容之间（**凸起件也要有这道**，它把"平面色块"变成"有厚度的块"）；
- 填充体自带 2px 上亮 / 2px 下暗。
- **框架只用同一色相的 3 档明暗**（暗/中/亮），不是多色拼接；换主题只换色相。

## 三、格子化状态件（心形/星星）

- 字形单元 **16px 高**（实测标题行 y=1..16），逐格横向排列、格距恒定；
- 每个字形同一个**完整描边**（外圈墨色 1~2px），内部再用 2 档明暗分出面；
- **三态区分靠"内部明暗与饱和度"，不靠缩放**：满 = 饱和主体 + 上亮沿；半 = 主体压暗；空 = 只留外环与一层暗底；
- 顶部数字标题（`Life: 350/450`）是**点阵/像素字体**贴在条外，不在条内。

## 五、复现这份量化

```bash
python - <<'PY'
from PIL import Image
im = Image.open('docs/images/ui-pixel-ref/ref-bars-life-mana.png').convert('RGB')
col = 60
prev = None
for y in range(0, 45):                      # 竖切：逐行色带 = 上表
    h = '#%02X%02X%02X' % im.getpixel((col, y))
    if h != prev: print(y, h); prev = h
PY
```

判据口径：**色带边界必须落在偶数行**（2px 基本单位）；出现 1px 或 3px 的带即为生成器参数写错。
