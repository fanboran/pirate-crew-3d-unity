本批三处改动：① 低分辨率档回退到"只细一档"（180 → 216，不是上一版的 360）；
② 角色从胶囊图元改成**方块拼的台柱形**（腿/躯干/头/帽檐四段，每面各自成档）；
③ 墨线 1.2 → 2.0 低分辨率像素（1 像素在放大后太细，看着像没描边）。

未闭合：台阶顶面与立面的色带仍只差约 7%（读成一块面）；顶面渲出色与 albedo 十六进制逐位相同，
指向最终上屏的 gamma 处理。两条都需要一次带日志的下发值核对。
