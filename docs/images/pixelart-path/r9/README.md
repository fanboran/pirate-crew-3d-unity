## 3. 两档判据（本轮对判据口径的**有意改动**，不是把红改绿）

真实关卡有山体棱面、多材料、水面、单位，画面结构天然比试点密——拿试点阈值卡它，等于拿
"棋盘上有没有杂色"去判"风景画有没有杂色"。故判据分两档：

| 档 | 适用 | 硬门禁 | 只打印读数 |
| --- | --- | --- | --- |
| **机制档** | `pa-*`（试点·图元几何） | 块边长 / 平坦占比 / 跳变率 / 亮暗跨度 / 色数 / 墨线 / 抖动两态 | — |
| **观感档** | `pl1-/pl2-/pl3-`（真实内容；旧名 `pc-`） | 块边长 / 色数 / 墨线在写缓冲 / **光照未旁路**（见下）/ 场地在场 | 平坦占比 / 跳变率 / 亮暗跨度 |

**新增判据「光照未旁路」**：同机位比对**最终图**与**albedo 调试图**——完全相同 ⇒ 光照那一趟没生效。
这条与内容无关（不像"亮暗跨度"那样受场地本身明暗影响），直接替代了观感档里原本靠跨度兜的那件事。
三关实测都是 **100% 像素不同** ⇒ 光照与色带确实在生效。

## 4. 第 2 关的**已定位缺陷**：礁盘侧壁被描边整片涂黑（未修，登记待办）

`pl2-*` 三张出图上，每块礁盘的侧壁是一整片近黑（`#0D0D0D`），宽处**12 个艺术像素**，
而描边按契约应该是 **1 个艺术像素**。三张图里这块占比 3.7%，`dbg-outline` 缓冲里 2.9%。

**证据链（三张缓冲对读，定位到描边那一趟）**：

| 缓冲 | 近黑占比 | 说明 |
| --- | --- | --- |
| `pl2-dbg-albedo` | **0.0%** | 原色缓冲里礁盘是连续面（`#494038`），**没有**黑带 ⇒ 不是几何缺口、不是材质缺失 |
| `pl2-dbg-outline` | **2.9%** | 墨线缓冲里就有这些黑带 ⇒ **黑带是描边画上去的** |
| `pl2-wide` | 3.7% | 最终图 |

同一套代码在关卡 1（云场）与关卡 3（空岛）上没有这个现象（墨线占比约 1%，且是细线）。
差别在几何：碎岛壳是**逐格盒子拼出的厚板**（`IslandShellGeometry.AddSolidCell` 每格一块），
侧壁在屏幕上是十几像素高的连续面；描边那一趟的门控（`connectedTo < 1 && closerThan < 1`）
在这种"整面都不与邻居连通"的侧壁上会整面涂黑，而不是只在剪影边上一像素。

**修复方向（未动手，属渲染线）**：① 先按 `dbg-connect` 缓冲确认侧壁的 connected 位为什么没置起来
（是法线差超阈值、还是打包方向位缺失）；② 若确认是"等深处相邻两块"被判成不连通，则门控应加
"等深不算更远"这一条；③ 另一条独立路线是把礁盘的逐格盒子**焊成一张连续壳**（内容侧改动，
属 SceneBake 线）。**在这条修好之前，README 里第 2 关那张图是**临时**的**。
