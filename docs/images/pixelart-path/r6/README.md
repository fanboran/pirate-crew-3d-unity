# r6 · 逐物体独立描边（2026-09-22 深夜）

> 创始人：「为什么每个物体没有单独描边，我给你的 V3 也不是只有一个单一描边的啊，
> 角色自己的描边和场景描边应该是独立的啊」——这条是**架构问题**，不是参数问题。本轮的改动见 §1。

## 1. 机制：远→近 + 每物体"壳（Always）→ 本体（LEqual）"

**病灶**：绘制是"所有壳画完 → 所有本体画完"。那样任何物体的环都会被**随后画的任何本体**盖掉
⇒ 整个场景只剩最外圈一道轮廓，每个物体没有自己的描边。

**修法**（两件事必须成对，改一件就退化）：

| 件 | 做法 | 缺了会怎样 |
| --- | --- | --- |
| 绘制粒度 | 不再是 `DrawRenderers`（按 tag 分批），改成**自己收集 + 逐物体 `CommandBuffer.DrawRenderer`**，pass 索引**按 pass 名解析**（不写死序号） | 只能得到"全场景一圈外轮廓" |
| 次序 | **远 → 近** | 近→远时远物的壳会盖到近物身上 |
| 深度测试 | 壳 `ZTest Always` + `ZWrite Off`；本体 `ZTest LEqual` + `ZWrite On` | 壳用 LEqual 时，环会跟**先画完的大平面**抢深度，近侧下缘整条丢光（实测覆盖 0%） |

为什么"远→近 + Always"同时满足两个约束：
- 每个物体的壳先把它**整个剪影**画上去（连环），随后它自己的本体盖回内部 ⇒ 只余环；
- 环压在**更远的**物体上（正确：近物轮廓本该盖在远物上）；
- 比它**更近**的物体随后才画，它们的本体把覆盖处的环盖掉（正确：近物遮住远物轮廓）。

实测：墨线像素 **13150 → 51225**（4 倍）。画面上三级台面各有自己的闭合环、立柱/木箱/角色各自成环。

**代价与后续**：自己排就绕开了引擎的可见性裁剪（本路径物体量级几十个，可忽略）；
接进真实内容若成为瓶颈，应改用 `CullingResults` 可见列表 + `RendererList`。

## 2. 角色"没台柱感 / 太矮"：量出来是**取景问题**，不是渲染问题

| 镜头 | 红船员高 | 宽 | 模型锥度 0.35/0.40 = 0.875 折算到像素 |
| --- | --- | --- | --- |
| `pa-mid`（中机位，可见 18m 高） | 75px = **15 低分辨率像素** | 9 像素 | ≈ **1.1 像素** ⇒ 读不出 |
| `pa-close`（近机位，可见 8m 高） | 180px = 36 低分辨率像素 | 20 像素 | ≈ 2.6 像素 ⇒ 勉强 |

即：角色在画面里只有 15 个低分辨率像素高，模型的 12% 锥度在这个尺寸下不到一个像素。
**这是取景比例问题**（试点用 18 米视野看 1.85 米的人），不是着色/描边的问题。
要让"圆台柱"读出来，两条路（都要创始人拍）：
- **取景**：让角色在画面里更大（战斗场景的实际机位应当比试点的中机位近得多）；
- **模型**：加大锥度（例如顶 r 0.28 / 底 r 0.45 = 38% 锥度）——**这是改船员模型的裁决（2026-09-14），须先提案**。

"陷到地里 / 太矮"：脚底与地面**共面**（脚底 y=0、地面顶面 y=0），本身没有埋进去；
观感上像下陷，一部分来自**底部那圈描边缺失**——本轮逐物体描边之后，角色底部那圈已经有了
（见 `pa-mid` 里红船员脚下的环）。
