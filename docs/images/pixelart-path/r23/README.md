# 纯草坪验收场 · 第六批实拍（r23，邻近域配色 + 逐簇微 tint）

> **这批图是什么**：创始人判 r22「太显眼、要逐簇变色」后的收敛轮：
> ① 簇与地、簇与簇的色差全部压进 **#6FB86A ±8% 邻近域**（主 #6FB86A / 亮 #77BB70 /
> 暗 #639E5F / 底板 #5C9556），观感目标是"融进地面的细腻色纹"；
