## 判读（【AI 提案】待创始人裁决）

- **宽机位成立**：草坪首次读成"茂密的草地"，亮斑（GrassLight 三档斑块）连成大块且边缘
  自然，整体结构与参考库同族——`_SPRITE` 路线（遮罩只管形状/调色板只管颜色/无描边/
  整簇同光带）在宽机位口径下达标。
- **近机位是块状噪声**：特写档（7 m 可见）下艺术像素 ≈ 2 cm，纹素（5.6 cm）= 2.9 艺术像素，
  每纹素渲成 2×2+ 的色块 + 簇间重叠 ⇒ 读成"俄罗斯方块碎片"。这是**单一 sprite 尺度服务
  多机位的结构性矛盾**：参考库全程只在一个机位距离展示草坪。候选：① 定稿宽机位口径、
  近机位换专门的低频/detail 变体（按机位切图集窗）；② 近机位接受块感（像素艺术放大本就
  如此）；③ 回退小簇（0.45）+ 接受宽机位的细碎。
