## 判据（程序化，两套档位都跑）

```
python tools/pixel-review/judge_pixelart_pilot.py export/pixelart-l1-r10
python tools/pixel-review/judge_pixelart_pilot.py export/pixelart-l3-r10
```

两关都是 **全部核心判据通过**：块边长 3、色数 19/79、墨线在写缓冲、
**光照未旁路**（同机位与 albedo 调试图差 100%）、场地在场（15.3%/38.7%）。
平坦占比与亮暗跨度在关卡档只作读数（真实内容结构比试点密，理由见判据脚本的模块 docstring）。

## 已知偏差（沿用 r9 记录，本轮未变）

1. 海面是**替身**（平色平面，非活水面）；活水面接进本路径需要单独一轮。
2. 关卡 3 的出生高度与草皮面差 **0.4 m**（逻辑高度场 y=14.0 / 实测岛面 y=14.4），
   装配器按"关卡数据与几何的偏差"报警，未自动贴面。
3. 关卡 3 岛面上的**细碎深色斑点**是岛体自带的草丛/碎石小件，每个小件各自成剪影 ⇒ 各自有墨线；
   若嫌噪，旋钮是岛体烘焙时合并这些微件或让它们不出描边。
