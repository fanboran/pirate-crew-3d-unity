## 2. 取景口径（本轮两处纠正的结论）

| 档位 | 可见高度 | 说明 |
| --- | --- | --- |
| `wide` / `mid` / `close` | **32 / 16 / 7 m（十关同一组数，不随地图大小缩放）** | **人物大小是锚**：同一档在不同关卡里角色必须一样大，否则"横向比观感"本身不成立 |
| `overview`（仅海图） | 0.85 × 跨度 | 整张地图进画面——只用来读布局，不用来读观感（下面给了原因） |

两次踩坑与纠正：

1. **第一版把 mid 绑成 0.35×跨度** ⇒ 280 m 的地图里角色只有 150 m 地图里的**一半大**（创始人一眼看出来）。
   根因是"取景跟着场地大小缩放"，而观感图的锚应该是**角色的屏幕尺寸**。
2. **只把人放大还不够**（第二版 mid=16 m 固定）：16 m 的取景是一小片台面，与 README 里那两张
   （32 m 的整片场地）**不是同一种画面**。所以 wide/mid/close 三档全部对齐到样板关那一组
   （32/16/7 m），并额外给海图一张 `-overview` 用来看整图布局。

## 3. 顺带解决的：宽机位"站面被描边整片涂黑"（r9 §4 同类）

第一版整图取景（1.0×跨度）下站面被墨色整片盖掉：`pl101-wide` 近黑 **12.7%**、沙色站面只剩 0.6%，
而 `dbg-albedo` 里近黑 0.0%（几何材质都对）。本轮把观感档收到 32 m 后**这个现象消失了**：

| 档位 | 101 近黑 | 108 近黑 |
| --- | --- | --- |
| `-wide`（32 m） | **0.89%** | **1.18%** |
| `-overview`（0.85×跨度） | 7.04% | 6.42% |

**结论：这条缺陷与"物体在艺术画布上占多少像素"直接相关**——同一场景、同一材质，只改可见米数就从
1.2% 跳到 7%。这为修它指了方向（连通域门控在物体只占少量艺术像素时的行为），也让"观感图用 32 m 档"
这个口径顺带避开了它。整图总览那一档仍带这个缺陷，**未修，已登记待办**。

## 4. 判据脚本本轮修的两处（都是我的 bug）

档位识别与"场地在场"判据都写死了 `pl1-/pl2-/pl3-` 前缀，认不出海图的 `pl101-*`——
前者让八张图齐刷刷假红在"亮暗跨度 0.29"，后者让它们**静默跳过**判据（看着像通过，其实没查）。都改正则。
