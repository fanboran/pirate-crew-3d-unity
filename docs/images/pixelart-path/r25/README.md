# 纯草坪验收场 · 第八批实拍（r25，角色缝隙修复 + 抖动定标）

> **这批图是什么**：创始人报「角色左下角有缝隙」「色彩抖动怪」的修复轮，三个根因一次落：
>
> 1. **描边兜底扩到相切的更近侧剪影**（`8be645e9`）：角色侧壁比脚边地面更近，而逐像素深度差
>    （厘米级）远小于连通域阈值 0.25 m（v3 量纲）⇒ 两侧判成"相切连通"，外侧像素的门被
>    `connected` 关死、角色像素的门被 `closer` 关死——mid 机位下左剪影整条无墨、close 机位下
>    墨线到剪影切点戛然而止；底部再叠上草叶自己的描边，观感即"有描边但和角色之间隔了缝"。
>    修复 = 兜底分支扩为「邻域不开描边 且（邻域更近 或 相切连通）⇒ 墨线落在角色自己边界行」
>    （`PixelartOutline.shader`；契约 §4.4/§8 #11 同步）。
> 2. **抖动幅度单位重定标**（`0ee64fc4`）：旧施加式把偏移乘在 `1/(level-1)` 上，而量化真实
>    边界间距是 `1/level`（level=4 差 1.33 倍），强度 0.5 的实际摆幅 ±0.47 步长 ⇒ 相邻翻转带
>    重叠、全表面处处翻档——"整个亮面均匀棋盘格"的根因（r19/r24 定位）。
> 3. **抖动默认强度定 0.21**（`9e7b5d84`，创始人定值）：新单位下 = 只有色带边界 ±1/10 间距内
>    的像素翻档，撕边质感保留、大面干净。118 个 .mat 与 `PixelartMaterialFactory` 推平同步。
> 4. **密度图案满幅按模式归一**（`f781bae1`）：密度两态撕满一条带需要整带摆幅（±1 个间距），
>    归一挪到物体 pass 按模式折算（Bayer 满幅 ±0.5 间距 / 密度 ±1 间距），Bayer 侧数值行为
>    不变。首轮 r25 出图密度档跳变率掉到 0.327 即此回归，本轮已恢复。
> 5. **草坪全系关闭连通域降档**（`983ed426`）：创始人复验报"头上描边毛边超级严重"。逐像素
>    分类定位：墨线全程闭合，毛边是**紧贴剪影外侧的草地像素被降档压暗一档**（`102,167,98 →
>    73,124,71`，聚合窗格跨剪影混入物体深度/法线 ⇒ 误判"面转折"）——与草叶无关（头部高度
>    够不着），r24 就存在、被满屏麻点掩盖。修复 = 草坪 13 材质（地面 + 3 底色 + 9 草簇档）
>    `_AAScale = 0`（`Configure` 新增 `aaScale` 参数，角色/道具保持 1），草叶边缘深噪同机制
>    一并消除。

  close 机位左下弧段墨线贴身走完，不再有"描边浮在草上"的缝。
