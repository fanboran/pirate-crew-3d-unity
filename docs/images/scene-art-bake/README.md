## 判据归属（几何级才是硬门禁）

像素比对只回答"没有缺件、没有洋红、构图同源"；**几何正确性由两条程序化判据锁死**：

1. 重烘后 `Assets/Art/Models/SceneKit/Baked/` 网格资产**逐字节零漂移**（同配方两次烘焙一致）；
2. `SceneArtBakeDeterminismTests`（6 用例）：同配方+同种子两次合成，缓冲顶点/索引 bit 级一致。
