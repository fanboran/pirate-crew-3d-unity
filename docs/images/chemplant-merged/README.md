## 二、这批图的口径（不是审美偏好）

- **休闲化重制**：奶油混凝土 / 软蓝钢 / 珊瑚锈 / 灰绿植被；轮廓圆润、明暗柔和，
  目标不是写实废土，而是休闲游戏的可读性与可爱感。
- **干净大板广场**：6~8.5 m 奶油混凝土板，面层缩进 + 5 cm 暗色垫层形成倒角；板缝是
  断续细苔藓段，另配排水篦子与圆井盖；没有随机碎板、裂缝与散落小物件。
- **三处圆形苔藓花园**：石砌边圈 + 沙床 + 有厚度的苔藓丘 + 浅蓝水洼 + 园景石。
- **植被**：树冠 12~18 个椭球瓣深度互穿（下暗上亮、带根盘/主干/主枝）；草簇是
  “圆草团 + 3~5 片扁圆叶”；灌木 7~11 瓣；田埂树篱与远树剪影。
- **有构造的连续矮墙 + 大门**：勒脚/分格缝/壁柱/三层压顶/壁灯；方门柱 + 金属门扇 +
  门楣招牌 + 门卫亭。
- **重建主厂房**：门式刚架 + 压型墙板 + 窗带（洞口内衬/框/中挺/窗台）+ 大卷帘门 +
  雨棚斜拉杆 + 双坡金属屋面（24 道细肋/坡、天窗、通风器、檐沟/落水管、山墙百叶、爬梯）。
- **墙外**：4 m 网格起伏地形、5~6 块异色田畴 + 田垄、沿田界树篱、两圈树线、近墙灌木/
  草簇、土路车辙、草捆/木围栏，外围是雾灰绿远山与远景厂房/冷却塔/料仓/烟囱。

口径：物体 pass → 低分辨率域着色 → 屏幕空间描边 → 点采样上屏；块边 2 屏幕像素、
俯角 30°、逐物体 4 档色带。载体场景 `Assets/Scenes/Pixelart/PixelartChemPlantMerged.unity`
（装配器 `PixelartChemPlantMergedSetup`，取景表关卡号 5，35 个槽），
出图命令：开发包 + `-pixelartOut <目录> -pixelartLevel 5`。

材质/光照：奶油/软蓝/珊瑚锈域板；环境光暗蓝灰 `#5C6978`；浅天空蓝背景；深蓝灰柔墨线；
所有材质关闭“法线边压暗”，只留外轮廓；平贴苔藓/水膜 `Kit_Dec*` 不描边。物体 shader
带 `ShadowCaster` pass，太阳投影走真实 shadow map：树冠、檐口、管廊、罐体都有落影；
暗面由环境光托底，避免“白片 + 死黑”的两极。
图为 1920×1050：底部 30 px 是 Unity 开发包的 “Development Build” 叠字条，已裁掉，
画面内容未做修图。
