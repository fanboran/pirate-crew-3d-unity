## 二、这批图的口径（不是审美偏好）

- **合并方式**：只保留两套 kit 的建筑零件，布局彻底重构；不是两个整场件并排。
  围墙为不规则折线 + 三处坍塌缺口，缺口用废料堆、土坡、树丛封口。
- **视觉边界 ≠ 玩法边界**：可玩区止于围墙；墙外是草地/泥地/树线/远景厂房/堆场/土坡/电杆组成的
  **视觉连续、逻辑不可达**延伸区——从场内看出去不出现「一圈空海」，也不会读成悬空沙盘。
- **废弃质感（内外同一种荒地表皮）**：地坪是「泥土基面 + 残破水泥板阵列」——板间留缝、
  缝底压深色土条、缝里全长矮草，约 18% 的板整块缺失；草色用暗绿 + 土褐（不用鲜绿），
  墙根草甸与墙外连成一片。墙外同样以土色为底、草/碎石/泥斑混合，不是均匀草坪。
  另有灌木、枯树与阔叶树、藤蔓、大积水洼、裂缝、翘起水泥板、瓦砾、油桶、托盘木箱、
  倒伏电杆、废弃铁路支线；全部零贴图、零金属度，细节由几何密度与平色槽对比承担。
- **场外补地**：渲染时另加一块只进渲染、不进 FBX 的远景地面（z = −0.6），避免镜头越过
  总范围时读成悬空。
