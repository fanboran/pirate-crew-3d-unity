## 1. 概述

- **一句话**：致敬 Nitrome《Mutiny》的**回合制投掷对战**游戏——两支海盗小队在加勒比小岛上用各式武器互掷互轰，把对方全队送下海。
- **类型**：回合制策略 / 炮术对战（artillery tactics）。
- **平台**：Windows PC（Unity 2022.3 + URP）。
- **核心体验**：估距、算抛物线的**一掷定胜负**张力；回合间攻守易位的策略展开；船员编成与战役推进。
- **参考坐标**：玩法原型 = Flash《Mutiny》（灵感来源；逆向材料已归档，不作设计依据）；画面方向 = **For The King / Tunic**——等距轴测 + 卡通赛璐璐 + 描边 + 像素纹理 + 像素化后处理（见 §9 与 [美术.md](美术.md)）。

## 2. 核心玩法：回合制投掷对战

### 2.1 对战结构

- 两队海盗（红/蓝）在**立体岛群竞技场**上轮流行动；**一回合只操作一个单位**（该单位本回合可跳、可扔各一次，用武器即回合结束）；**全队阵亡（含落水）即负**。
- 回合骨架以现役实现（`TurnRules`）为准；**数值尚未设计**，现值为占位。
- 空间模型：**悬浮岛群高低错落浮于海面**，场地范围收在环形区域内（环形说的是范围的形状，不是对称要求）；等距相机（俯角基准 30°、方位可自由旋转）。契约见 [3D空间模型对齐.md](../技术/3D空间模型对齐.md)。
- 战斗交互：**两态制**（自由镜头 ⇄ 选中），选中态内按「操作模组」瞄准（标准投掷先行）；自由镜头俯角可临时偏离基准，键位与 Esc 矩阵见 [操作与交互.md](操作与交互.md)（细节【提案/待定】）。

### 2.2 投掷与伤害

- 武器库：**现役 = 标准小炸弹空壳**（任意武器行为统一为抛掷炸弹，待重做）；重做基线见 [武器系统.md](武器系统.md)——武器清单与逐项数值**全部【提案/待定】、逐值待**，原 17 武器逆向数值表已随依据链退场作废。
- 弹道：抛物线，仰角由标准投掷模组的参数给出（方向角/仰角/力度三参数，米制口径；设计见 [操作与交互.md](操作与交互.md) §6，可判定规格见 [投掷行为契约](../技术/投掷行为契约.md)）；爆炸公式与溅射衰减的空间合成口径见 [3D空间模型对齐.md](../技术/3D空间模型对齐.md) §5（常数尚未定案）。
- 地形互动：可破坏掩体、落水即死、危险区域（岩浆/风暴关）。

### 2.3 AI 对手

- 1P 模式的 AI：**评估链已随武器掏空整拔**（对局行为不变：对手每回合只会结束回合），重做时与武器一起再立（原逆向伪代码仅作历史参考，已归档）。

## 5. 船员管理（CrewManagement）

- 循环：**招募 → 编成 → 出战 → 结算**；船员没有经验/等级/成长系统。
- 招募池以数据表为准；**职业体系已根除**（全员同一造型），船员差异只在数据与 HUD。
- 界面：名册/编成卡/统计（M3 骨架在役）。

## 9. 美术方向（概要）

**等距轴测（俯角 30°、方位可自由旋转，正交投影）+ 卡通赛璐璐（2~3 档色带）+ 反向壳描边 + 像素纹理（Point 采样）+ 全屏像素化后处理（起步 640×360）+ Beveled Pixel UI**。

完整口径（调色板策略/光影约定/可读性判据/待定项）：[美术.md](美术.md)。技术实现：[渲染管线.md](../技术/渲染/管线/渲染管线.md)；资产生产：[像素纹理.md](../技术/资产管线/像素纹理.md)。
