## 1. 概述

- **一句话**：致敬 Nitrome《Mutiny》的**回合制投掷对战**游戏——两支海盗小队在加勒比小岛上用各式武器互掷互轰，把对方全队送下海。
- **类型**：回合制策略 / 炮术对战（artillery tactics）。
- **平台**：Windows PC（Unity 2022.3 + URP）。
- **核心体验**：读风、估距、算抛物线的**一掷定胜负**张力；回合间攻守易位的策略展开；船员编成与战役推进的成长回报。
- **参考坐标**：玩法原型 = Flash《Mutiny》（逆向为数值权威）；画面方向 = **For The King / Tunic**【创始人指定】——等距轴测 + 卡通赛璐璐 + 描边 + 像素纹理 + 像素化后处理（见 §9 与 [美术风格指南](美术风格指南.md)）。

## 2. 核心玩法：回合制投掷对战

### 2.1 对战结构

- 两队海盗（红/蓝）在一座被海水包围的小岛竞技场上轮流行动；**全队阵亡（含落水）即负**。
- 回合机、出手顺序、行动点与移动规则的**数值权威**：静态逆向文档 §回合规则（禁止另立口径）。
- 空间模型：XZ 水平竞技场 + 斜 45° 相机 + 单位沿 Z 分路（契约见 [M2-3D空间模型对齐.md](M2-3D空间模型对齐.md)，**视角正交化**后契约不变）。

### 2.2 投掷与伤害

- 武器库 **17 种**（炮弹/炸药/近战/特殊），逐武器的伤害、射程、装填、爆炸半径等**全部以静态逆向武器表为权威**。
- 弹道：抛物线 + `ThrowLift` 仰角抬升（数值出处见空间模型文档）；爆炸公式与溅射衰减以逆向文档为准。
- 地形互动：可破坏掩体、落水即死、危险区域（岩浆/风暴关）。

### 2.3 AI 对手

- 1P 模式的 AI 走逆向文档的**伪代码权威**（目标选择/落点评分/风偏修正）；Unity 侧已实现落点评分的 XZ 质心距离罚项（M2 波次记录）。

## 4. 战役与进度（Campaign）

- **设计容量**：33 关（沿用原版关序；天空三档正午/黄昏/风暴按关卡分组轮换，见逆向 skyColour 索引）。
- **当前实现**：3 个手作关卡（关卡制作管线见 §10 技术概要的关卡文档）。
- 星级/经验曲线：已实现骨架，曲线数值为**提案标注**（待校准）。
- 存档：战役进度/编成/设置经 SaveManager 落盘（Core 服务）。

## 5. 船员管理（CrewManagement）

- 循环：**招募 → 编成 → 出战 → 结算 → 成长**。
- 招募池与职业色、武器配平以数据表为准（17 武器色 / 7 职业色为玩法语义常量，不随美术换肤变动）。
- 界面：名册/编成卡/统计（M3 骨架已闭环）。

- **界面清单**：Bootstrapper（装配根）→ 主菜单 → 选关 → 船员管理 → 战斗 HUD（含暂停/结算弹层）。

- **UI 风格**：像素斜面浮雕 Beveled Pixel + Chunky Pixel【创始人裁决】（概要见美术指南 §5；换肤实施后重写 [UI设计语言.md](UI设计语言.md)）。现有 UI 技术底座（令牌层 StickTokens / 槽位路由 / 模态栈 / 装配器 StickKit）风格无关，全部沿用。

## 9. 美术方向（概要）

**等距轴测（斜 45° 正交）+ 卡通赛璐璐（2~3 档色带）+ 反向壳描边 + 像素纹理（Point 采样）+ 全屏像素化后处理（起步 640×360）+ Beveled Pixel UI**。

完整口径（调色板策略/光影约定/可读性判据/待定项）：[美术风格指南.md](美术风格指南.md)。技术实现：[渲染管线-等距像素卡通.md](../技术/渲染管线-等距像素卡通.md)；资产生产：[像素纹理资产管线.md](../技术/像素纹理资产管线.md)。

## 10. 音频

- 程序化音频管线（`Game2AudioAssets`，无外部音频资产）；事件→音效映射随 EventBus 契约登记。
- 音乐/音效的风格随新美术方向校准（像素风游戏常用 chiptune 取向）【AI 提案·待立项】。

## 11. 技术概要（入口，细节在专门文档）

- 引擎：Unity 2022.3 + URP 14；asmdef 模块化（Core / Campaign / CrewManagement / PirateCrew.Gameplay / UI），Bootstrapper 组装根，EventBus 事件契约（[EventBus事件契约.md](../技术/EventBus事件契约.md)）。
