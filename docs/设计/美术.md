# 美术 · 等距像素卡通

> **这份文档解决什么问题**：本作画面的**唯一美术口径**——视角、色彩、画面元素规格、UI 风格、角色造型。所有场景/角色/特效/UI 的美术实现与验收以本文为准。
> **方向来源**：为降低开发难度，整体 3D 画面表现转向本风格。参考游戏：**For The King**（等距+卡通+描边）、**Tunic**（等距卡通低模）。
> **技术实现口径**：[渲染管线.md](../技术/渲染/管线/渲染管线.md)；**资产生产口径**：[像素纹理.md](../技术/资产管线/像素纹理.md)；**品控评审规程**：[美术品控评审.md](../技术/美术品控评审.md)；**游戏整体设计**：[游戏设计文档.md](游戏设计文档.md)。

---

## 1. 视觉定位

### 1.1 一句话印象

> **玩家第一眼应该看到**：一块 30° 俯角、2:1 像素网格的加勒比小岛，像一件被精心制作的**像素玩具模型**——粗墨线勾边、2~3 档色带铺面、明快调色板；红蓝两台小海盗以粗块像素质感对峙，脚下椭圆阴影把他们"钉"在地面；整个画面被统一的后处理像素化笼罩成一体，UI 是微微凸起的浮雕像素块，像可以按下去的塑料键。

### 1.2 方向构成公式

- 游戏内容画面 = **视角（等距轴测，3D 斜 45°）+ 渲染技术（卡通赛璐璐 + 模型描边/卡线）+ 纹理风格（像素纹理）**，整体后处理呈像素画风。
- UI 画面 = **像素斜面浮雕（Beveled Pixel UI）+ 粗块状像素（Chunky Pixel）**——微微凸起的 2D 风格。

---

## 2. 视角与取景

### 2.1 相机

- **正交投影 + 俯角固定 30°**：屏幕投影：地砖菱形宽:高 = **2 : 1**、地面线倾角 26.57°、竖向按 0.866 压缩——即手绘像素画沿用的"2:1 网格"，也是**规则像素阶梯**的来源（sinθ = 0.5：地面轴横移 2 像素 / 下降 1 像素；真等距 35.264° 的 sin = 0.5773 与像素网格无整数比，阶梯长短不一）。
- **方位角可自由旋转**（口径：「左右可以随便旋转」）：两态交互下自由镜头 = 编辑器飞行式——右键 + 鼠标转视角，俯角可在 15°–80° 内临时偏离基准（行为口径见[相机行为契约](../技术/相机行为契约.md)）。方位 0 = 45° 对称菱形基准构图；只有 45° 及其对称位给出两条地面轴对称的菱形（`tanα_X = sinθ·tanφ`、`tanα_Z = sinθ·cotφ` 在 φ=45° 时相等），别的方位下两组地面线的阶梯长短不一——**这是明确接受的取舍**，不做 45° snap。
- 俯角与玩法零耦合：弹道与落点判定不随俯角变化，改俯角只改画面。投影比与像素密度方程见[渲染管线.md §1.1/§3.1](../技术/渲染/管线/渲染管线.md)。
- **正交 size 取整数**（世界半高单位），像素网格在世界空间对齐，减少游动；size 与 RT 高成对定（渲染管线.md §3.1）。

### 2.2 地图构成【待定】

- 是否格子拼装：未拍板。倾向方案：**逻辑上格子、视觉上软化**——寻路/占位/AI 走格子（开发难度最大杠杆），观感上用边缘扰动贴片、装饰物压缝、非均匀摆放掩盖接缝（For The King 即此做法）。
- 硬约束：**观感必须"非格子块"**——不能一眼看出格子拼缝。

## 3. 色彩

### 3.2 调色板策略【已取消】

> **口径**：「先把有限色卡取消吧这个项目」——"全局 32~64 色锁板 / 纹理量化入板"机制整条作废。色彩纪律改为**逐资产在源的槽位色表**，槽位定义与 Unity 侧镜像见 [调色板.md](../技术/资产管线/调色板.md)。
>
> 保留（未被取消且仍在执行）的只有色相**取向**：加勒比主题（暖白沙地 / 饱和草坡 / 深蓝海水 / 木材棕 / 红蓝阵营色）——它描述的是**取向**，不引入"锁定色数"这层机制。

## 4. 画面元素规格总表

1. **赛璐璐色带**——2~3 档，暗部色相偏移（偏冷/偏紫）非纯乘暗；无镜面高光（[渲染管线.md §6](../技术/渲染/管线/渲染管线.md)）。
2. **描边**——反向壳、RT 空间 1px、统一墨色（与 UI 令牌 INK 同色）（[渲染管线.md §6.1](../技术/渲染/管线/渲染管线.md)）。
3. **像素化**——全屏后处理，起步 640×360，nearest 降采 + 放大（[渲染管线.md §3.1](../技术/渲染/管线/渲染管线.md)）。
4. **纹理**——低分辨率像素、Point 采样、mip 关、不压缩/BC7、纹素密度全项目锁一值（[像素纹理.md §1/§3](../技术/资产管线/像素纹理.md)）。
5. **内部结构线**——不靠 shader，直接画进纹理（2px 深色线）（[像素纹理.md](../技术/资产管线/像素纹理.md)）。
6. **色带过渡**——4×4 Bayer ordered dithering，抗脏渐变（[渲染管线.md §6](../技术/渲染/管线/渲染管线.md)）。
7. **特效**——粒子 + 全屏像素化（自动风格化）；大招可配 8~12 帧手绘序列帧点睛（[渲染管线.md §4](../技术/渲染/管线/渲染管线.md)）。
8. **世界空间文字（伤害数字）**——走像素化层，用像素数字（[渲染管线.md §3.1](../技术/渲染/管线/渲染管线.md)）。

## 5. UI 方向（概要）

- **Beveled Pixel UI + Chunky Pixel**：全分辨率独立层（不进像素化 pass）；像素浮雕 = 基色平涂 + 上/左高光边 + 下/右阴影边 + 外圈墨描边，纯程序化九宫格生成。
- 按压反馈：位移 1px（右下）+ 高光/阴影对调（模拟凹陷），不用 scale。
- 几何以 **2px 为基本单位**：外圈暗环 2px → 斜面亮/中 2px → **内侧再压 2px 暗线**（凹陷感的来源）→ 内容；框架只用**同一色相的 3 档明暗**（暗/中/亮，不是多色拼接）；格子化状态件字形单元高 16px，三态靠内部明暗与饱和度区分、**不靠缩放**；色带边界必须落在偶数像素行。
- **标准参照**：`docs/images/ui-pixel-ref/`（三张参照图：两张 Terraria 截图片段出**条状件与格子件**的逐像素几何表，一张像素工具对话框出**控件词法**——面板/控件体/描边的明度分级 + 蓝色阶焦点态；量前先把色量化到 8 档）。
- **UI 视觉唯一权威 = Aseprite 参考库**（`pirate-crew/Assets/Art/Sprites/UI/Aseprite/theme.xml` + `sheet.png`），量测与署名见 [docs/images/ui-pixel-ref/README.md](../images/ui-pixel-ref/README.md)；复刻承载三层与调试面板见 [架构总览 §8.1](../技术/架构/架构总览.md)；九宫格实现规范见 [UI九宫格.md](../技术/资产管线/UI九宫格.md)。
- 字体：像素字体原生档四档（16 = 正格点黑16，12/10/8 = 缝合像素；禁放大、禁伪粗），口径见 [UI设计语言.md](UI设计语言.md) §七。
- 布局线框 / 状态反馈纪律 / 中文文案的现行规范见 [UI设计语言.md](UI设计语言.md)；现有 StickUI 底座**风格无关、全部沿用**，换皮不换骨。

## 6. 与现有资产/铁律的关系

1. **M2 空间契约**（立体岛群竞技场）——坐标与数值语义不变；相机：透视→正交、俯角固定 30°、方位角可自由旋转（[3D空间模型对齐.md](../技术/3D空间模型对齐.md) §2 已同步）。
2. **船员低模"角色模型不改"铁律**——不变；渲染层换赛璐璐+描边+像素化，模型本体不动。
3. **Blender 无头资产管线**——沿用，加纹理量化与平滑法线导出步骤（[像素纹理.md](../技术/资产管线/像素纹理.md)）。
4. **描边 pass 经验**——直接复用（[描边Shader调试.md](../技术/渲染/调研/描边Shader调试.md)）。
5. **管线合并任务书**（烘焙资产/数据编目/运行时组装三层）——沿用，量化属烘焙器岗位的新增步骤。
6. **旧"风格化写实 PBR"条款**（PBR 材质分区/光影氛围/雾效/ACES/常显单位描边）——**全部废止**，以本文为唯一口径。

## 9. 角色

> 全部船员的造型 = **一个圆球（头）+ 一个圆台柱（身）**，无任何其它部件。
> 圆柱穿**阵营色**（红/蓝，单位身上唯一的阵营色块），圆球固定**木色** `#D4A76A`、不得被阵营色污染；船员差异只在数据与 HUD（血条/名牌），不体现在造型上。
> 选中态表现见 [美术品控评审.md](../技术/美术品控评审.md) 回归清单 G-1；尺寸/分段等实现常量以角色网格库代码为真源（"角色模型不改"铁律，代码即最终口径）。
