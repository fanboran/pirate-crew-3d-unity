# ① 战斗竞技场（沙滩新兵 / 搁浅船礁盘）

> level_1 的场景美术设计：给程序化生成的灰盒场地补上地景/道具/水体/天空，达到「玩家进游戏愿意玩」。

## 1. 场景概念

- **一句话概念**：正午烈日下，一艘断成两截的海盗船横卧在珊瑚礁盘的沙脊上，潮水正漫过它的肋骨，
  两拨船员从沙滩两侧围上来抢夺同一只箱子。
- **氛围关键词**：搁浅 · 日晒 · 斑驳。正午偏后热带晴天；风只作用于旗帜与棕榈叶的顶点动画，
  不作用于弹道（弹道与风解耦）。
- **地形事实**：场地 100×34 m，中脊为满高抬升带、数据网格名含 `ship`/`mast`——
  「中脊 = 搁浅船龙骨与桅杆基座」有数据依据（真源 `TerrainCatalog`）。方案：低平沙滩为底 +
  一条礁岩/船骨中脊，不做多层堡垒。

## 2. 构图

- 相机口径见[相机行为契约](../技术/相机行为契约.md)：正交、俯角固定 30°、方位可自由旋转。
  构图铁律：屏幕上下 = 世界 Z（上远下近）、左右 = 世界 X（左红右蓝）；纵深全可见、X 向平移跟焦。
- **次要焦点**：西滩红队旗杆与东滩蓝队旗杆一对，旗色按名册取。
- **宝箱**：按「有实心地形且上方无遮挡的列」随机空投，最多 3 只同屏——是武器补给，不是胜负条件。

## 3. 地景

- **不挖洞**：基础地面永远存在是代码既定取舍，且原版水道列被作者写进了出生点；0 块列读成「沙洼/潮沟」。
- **潮间带**：场外湿沙坡 + 水膜色，与泡沫线构成「沙→湿沙→泡沫→水」四段过渡
  ——消灭「大平面水直接切沙滩」的核心手段。湿沙坡是边界外唯一的地貌提示层。
- **沙地**：**严禁大面积纯色**；纹理规格见[像素纹理.md](../技术/资产管线/像素纹理.md)。
- 植被纪律：**船面不长草**。

## 4. 水体、天空与远景

- **水体**：按[像素海面](../技术/渲染/管线/像素海面.md)现役口径——不透明、色带分层、不做半透明混合。
- **泡沫**：用色带亮色，不用粒子发光。
- **落水即死与边界**：判定见 3D §4。**边界不做可视化提示层**——
  暗水带、危险虚线一律不铺，只靠湿沙坡到水面的自然过渡；禁止可玩区大面积红与红色水面。

## 5. 可玩性约束与既定取舍

**装饰不得改变玩法（硬约束）**：

1. 不改变碰撞与地形语义：**视觉绝不可私自改变碰撞顶面高度**（口径见 3D §9）；破坏后视觉壳随破坏流程同步消失/降高。
2. 不遮挡选中（屏幕空间 30px 半径，3D §3）与**投掷预览线**（整条抛物线不得被实体遮挡）。
3. 不制造新碰撞体；出生点不入水、不被装饰压住。
4. 不暗示可走区域；弹道与风无关；饱和红只属红队。

**既定取舍**：掩体石/木箱维持无碰撞、沉船甲板不可站立（level_7 玩法）——将来恢复需同步把投掷碰撞查询
从「仅地形」扩到「地形+掩体」，属较大改动需先评审。

**待裁决**：椰子树/炸药箱接入玩法、告示牌文案。
FX 无验收判据已登记于 [美术品控评审.md §8 Q-18](../技术/美术品控评审.md)；纯色大平面阈值挂 Q-17。

# ② 环境表现与关卡自然化

> 口述的方向性构想记录与现状对照。**性质：提案/待定**——未经确认前，
> 不得当作已确认设定被其它文档引用。口径来源：[像素海面](../技术/渲染/管线/像素海面.md)（现役权威）、
> [关卡/00-管线与设计语言](关卡/00-管线与设计语言.md)（建关约束）、
> [地图设计审计报告](../审计/归档/地图设计审计报告.md)（已归档·仅作沿革）。

## 1. 水体表现（最高优先级）

- **水体要点**：海浪拍打沙滩与水泥柱要有**受力反馈**；有**白色泡沫**也有**半透明感**；
  目标是「正常的水体动态表面模拟」做成像素风格化渲染。
- **现状与冲突**：像素海面方案定「水体不透明」（半透明 + 点采样会混出板外色），与「半透明感」冲突；
  方案 §4「明确不做白帽粒子」与「拍击反馈」冲突。像素海面的 F1–F7（色带波纹/描边/岸线带）未实现，
  现役海面是"马平色替身"；潮汐/湿沙系统已有。
- **建议路线**【提案】：半透明感不靠真 alpha，用**两色带/抖动伪造"能看见水下"**（岸线带已预留）——待定夺。
- **拆分**【提案】：先落地像素海面 F1–F3 → 半透明读感口径裁决 → 拍击反馈（先定白帽粒子做不做）→ 泡沫量产（等正交 size 定档）。

## 2. 环境小动态（海鸥 / 螃蟹等）

- **现状**【实测】：环境活物层已建成（真源 `Ambient/` 模块，战斗场景已接线）——海鸥轨道盘旋/俯冲/惊飞、
  螃蟹横爬缩沙、水下鱼群、远景鸟剪影、植被旗帜风摆、灯笼浮标、昼夜天气档。
- **缺口 1（核心）**：海鸥轨道中心是旧 50×17 竞技场的硬编码坐标，布点没跟关卡地形挂钩。
  【建议】布点改数据驱动：鸥绕岛、蟹贴真实水线、鱼游礁间，从岛与岸线几何派生。
- **缺口 2（数量固定，不按面积缩放）**：不够"多样"。多样性 = **种类 × 布点 × 主题匹配**的合力
  （不只是种类多）：每个生态带备若干种、出现在该出现的位置、按关卡母题组队；
  **零动画静物也算数**（珊瑚/贝壳/海星/漂浮木/玻璃瓶/破渔网，参照 Sandcastle Demo 装饰件）。
- **缺口 3**：活物层建于写实期，几何/材质是否满足像素路径口径**未验收**（挂待办 pixelart-着色路径）。
- **布料/飘扬**【实测+建议】：C# 侧风摆规则仍在，shader 端已随 PBR 清退删除——重建即待办
  （像素路径风 keyword 变体）。铺开时复用同一套：化工厂帆布/防雨布/破篷布、船帆、旗帜。

## 3. 关卡地形自然化（反对"空中大方块"）

- **地形要点**：不要大方块悬空感，要有**现实感**——破败道路塌陷、桥梁半塌入水、浅水散落物、
  废弃化工厂泡在浅水里、几片相邻沙滩、水泥圆柱耸立成平台。
- **玩法耦合**（同批口述）：浅水跳跃**有水花**；跳进旁边的海（深水）可能直接死——浅/深水有明确生死分界。
  【提案】浅水行走/跳跃为**新增层**，不改深水即死红线。
- **落地路径**【提案】：走[关卡/00-管线与设计语言](关卡/00-管线与设计语言.md)六阶段。母题四个：
  破败道路/塌陷桥梁、浅水工业场地、相邻沙滩群、水泥柱阵+耸立平台（先做哪个待裁决）。
- **地形切面**【提案】（参照 Sandcastle Demo）：地面**有边界、能看到土层截面**——整块地形像沙盘/剖面模型。
  截面 = 几条水平色带（草皮/土/岩），与像素色带口径天然契合；是美术+相机取景两处联动。
  【待澄清】整关四周包侧壁（沙盘式），还是只在相机可见的低边做？
- **视角移动**【提案】（参照 Sandcastle Demo 的「视角移动方案学沙堡」）：先实测 Sandcastle Demo 的环绕/俯仰/缩放手感，
  把差异点写进[相机行为契约](../技术/相机行为契约.md)后裁决——**本文不预设结论**。
