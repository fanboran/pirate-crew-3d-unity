# 环境表现与关卡自然化

> 口述的方向性构想记录与现状对照。**性质：提案/待定**——未经确认前，

## 1. 水体表现（最高优先级）

- **水体要点**：海浪拍打沙滩与水泥柱要有**受力反馈**；有**白色泡沫**也有**半透明感**；
  目标是「正常的水体动态表面模拟」做成像素风格化渲染。
- **现状与冲突**：像素海面方案定「水体不透明」（半透明 + 点采样会混出板外色），与「半透明感」冲突；
  方案 §4「明确不做白帽粒子」与「拍击反馈」冲突。像素海面的 F1–F7（色带波纹/描边/岸线带）未实现，
  现役海面是"马平色替身"；潮汐/湿沙系统已有。
- **建议路线**【提案】：半透明感不靠真 alpha，用**两色带/抖动伪造"能看见水下"**（岸线带已预留）——待定夺。
- **拆分**【提案】：先落地像素海面 F1–F3 → 半透明读感口径定案 → 拍击反馈（先定白帽粒子做不做）→ 泡沫量产（等正交 size 定档）。

## 2. 环境小动态（海鸥 / 螃蟹等）

- **现状**【实测】：环境活物层已建成（真源 `Ambient/` 模块，战斗场景已接线）——海鸥轨道盘旋/俯冲/惊飞、
  螃蟹横爬缩沙、水下鱼群、远景鸟剪影、植被旗帜风摆、灯笼浮标、昼夜天气档。
- **缺口 1（核心）**：海鸥轨道中心是旧 50×17 竞技场的硬编码坐标，布点没跟关卡地形挂钩。
  【建议】布点改数据驱动：鸥绕岛、蟹贴真实水线、鱼游礁间，从岛与岸线几何派生。
- **缺口 2（数量固定，不按面积缩放）**：不够"多样"。多样性 = **种类 × 布点 × 主题匹配**的合力
  （不只是种类多）：每个生态带备若干种、出现在该出现的位置、按关卡母题组队；
  **零动画静物也算数**（珊瑚/贝壳/海星/漂浮木/玻璃瓶/破渔网，参照 Sandcastle Demo 装饰件）。
- **缺口 3**：活物层建于写实期，几何/材质是否满足像素路径口径**未验收**（挂待办 着色路径）。
- **布料/飘扬**【实测+建议】：C# 侧风摆规则仍在，shader 端已随 PBR 清退删除——重建即待办
  （像素路径风 keyword 变体）。铺开时复用同一套：化工厂帆布/防雨布/破篷布、船帆、旗帜。

## 3. 关卡地形自然化（反对"空中大方块"）

- **地形要点**：不要大方块悬空感，要有**现实感**——破败道路塌陷、桥梁半塌入水、浅水散落物、
  废弃化工厂泡在浅水里、几片相邻沙滩、水泥圆柱耸立成平台。
- **玩法耦合**（同批口述）：浅水跳跃**有水花**；跳进旁边的海（深水）可能直接死——浅/深水有明确生死分界。
  【提案】浅水行走/跳跃为**新增层**，不改深水即死红线。
- **落地路径**【提案】：走[关卡/00-管线与设计语言](关卡/00-管线与设计语言.md)六阶段。母题四个：
  破败道路/塌陷桥梁、浅水工业场地、相邻沙滩群、水泥柱阵+耸立平台（先做哪个待定）。
  **创始人补裁**（2026-09-30 口述）：装饰数量**固定不缩放**；主攻**多样性**（种类 × 布点 × 主题匹配，
  非单纯扩种类）+ 静物点缀；布点跟关卡地形挂钩（现海鸥轨道还是旧 50×17 竞技场硬编码，重排时一并解）。
- **地形切面**【提案】（参照 Sandcastle Demo）：地面**有边界、能看到土层截面**——整块地形像沙盘/剖面模型。
  截面 = 几条水平色带（草皮/土/岩），与像素色带口径天然契合；是美术+相机取景两处联动。
  【待澄清】整关四周包侧壁（沙盘式），还是只在相机可见的低边做？
- **视角移动**【提案】（参照 Sandcastle Demo 的「视角移动方案学沙堡」）：先实测 Sandcastle Demo 的环绕/俯仰/缩放手感，
  把差异点写进[相机行为契约](../技术/相机行为契约.md)后定案——**本文不预设结论**。
