## 二、设计意图与纪律

1. **画布 = 恒定像素密度**（红警 2 式）：1 画布单位恒 = `PixelSkin.Unit` 屏幕像素，画布逻辑尺寸随
   分辨率整数倍生长（1080p → 960×540），任何分辨率无分数缩放。**比例换档单点 = `PixelSkin.Unit`**
   （现值 = 2，`Scripts/UI/Skin/PixelSkin.cs:73`）；设置面板比例下拉只接这一个真源。
2. **颗粒度 1:1 对齐**：UI 的基本单位与 3D 艺术像素同格（640×360 RT 最近邻放大后一个 3D 像素块 =
   UI 一个基本单位），界面与战场在同一套颗粒语言里。基本单位 `u` 的现役值与可调预设档口径见
   [九宫格规范](../技术/资产管线/UI九宫格.md)。
3. **UI 是全分辨率独立层，不进像素化 pass**（渲染线线四条红线之一，见
   [渲染线线](../技术/渲染/线线/渲染线线.md) §1）。
4. **像素纪律在代码强制，不走 prefab 承载**：顶点像素对齐、字号 = 字体原生档、件禁乘色、整格坐标
   （[架构总览 §8.1](../技术/架构/架构总览.md) 控件层）。
5. **两套语法别互相推广**（对照走查裁决）：条槽（血条/进度条）是**五段**（近黑描边/外环/斜面/内暗线/槽底）；
   面板与按钮是**近黑描边 + 受光侧唇边 + 平脸**（凸起靠一级明度差，不靠每边斜面）。第一版把金框语法
   推广到全部面板被否——量测与走查记录见 [ui-pixel-ref README](../images/ui-pixel-ref/README.md)。
6. **两族共用最外那道近黑描边**：同屏读成一种画风；斜面框架只用同一色相的 3 档明暗（暗/中/亮），
   换主题只换色相。

## 三、机制骨架（跨皮肤有效，换皮不换骨）

1. **Token 单源**：布局数字一律取 `UI/Skin/AseLayout` 令牌层（theme.xml `<styles>`/`<dimensions>`
   间距语法全表登记），**`Px()` 是唯一换算出口**——theme 数字是设计格，直接当画布像素用 = 比例减半
   （观感挤的根源）。接屏时不手写画布像素字面量。
2. **变体表驱动**：控件 kind → `PixelSkin` 槽组映射表（槽位表见
   [九宫格规范 §四.2](../技术/资产管线/UI九宫格.md)），调用点零手配色。
3. **zone 布局表 + 防撞合同**（战斗 HUD）：
   - 顶部带：小地图占左上角 → 红条/徽章/蓝条以屏幕中轴**镜像等长** → 模式钮收右上角贴缘；
     互不侵犯（间隙 ≥8px）；
   - 底部带：[返回] → [武器面板贴底居中] → [提示条] 共享同一条底边线，不悬空、不骑叠；
   - 中央战场区只准小件（徽章/提示文字），大战场留给 3D；
   - **防撞合同**：装配期对顶层部件两两 AABB 检测，相交即警告（曾因此修掉模式钮压血条、
     提示条压面板两起真实事故）；
   - 改布局 = 改 `BattleHudBuilder` zone 常量，**不手挪单个部件**。
4. **组件陈列页自检**：`UIShowcase.unity` 场景跑 `UiGalleryPage` 陈列页（全部件 = 运行时真件、可交互；
   编辑器菜单 PirateCrew/UI/打开组件展示，命令行出口 `UiShowcaseSceneSetup.CaptureFromCommandLine` 自动出图；
   调试画廊另有 `WidgetGalleryPanel` / `PartsGalleryPage`）。改 Token/贴图后出一张图即可全貌回归——
   **组件陈列页是设计系统的活文档**。
5. **契约测试锁纪律**：纹理导入契约 `PixelArtTextureImportTests`；文案无英文残留 `UiStringsTests`；
   九宫格契约测试**待补建**（见待办 [ui-九宫格契约测试补建](../项目/待办/ui-九宫格契约测试补建.md)）。
6. **Canvas z 序五层**（从低到高）：z=0 世界视图（3D 战场/背景）→ z=10 HUD 常驻层 →
   z=20 准星与瞄准层 → z=30 提示层（气泡/Toast）→ z=40 模态层（结算/设置/确认框）+ 全屏压暗遮罩。
   高层屏蔽低层输入。

## 四、状态反馈纪律

- **按压反馈**：位移 1px（右下）+ 高光/阴影对调（模拟凹陷），**不用 scale**【创始人裁决】。
- **焦点/选中 = 色相信号**（蓝阶描边），与按压信号（位移 + 明暗对调）是两套独立信号，
  **不混用在同一控件上**（[ui-pixel-ref §三](../images/ui-pixel-ref/README.md) 结论 2）。
- **四态可辨且可判定**：normal / hover / pressed / disabled 各态有明度差或描边差；
  disabled **禁止 hover 反馈**。
- **选中信号同屏唯一**：当前选中对象的信号只出现一处（页签的「当前页」是位置态，不算选中对象，
  不占用选中信号）。
- **危险态**：不可投掷 = disabled + 文字说明；落水/出局 = 警示摇晃 + 提示条。
  **摇晃只用于状态警示，不用于装饰**。
- **动效纪律**：只做缩放/位移/透明度；时长 0.09~0.24s，不做慢动画；同屏循环动画 ≤1；
  不做背景粒子、常驻呼吸、按钮 hover 回弹。
- **可读性对比度下限**（WCAG 2.1）：文字对底 ≥4.5:1，非文字图形对底 ≥3:1；
  具体明度分级以 Aseprite theme colors 为准。
- **Esc 语义统一**（逐层退栈）：瞄准态 → 退到角色默认；聚焦态 → 回角色默认；
  角色模式 → 退出角色模式；战斗顶层 → 弹「返回确认」。

## 五、界面布局（线框）

> 线框只锁**布局结构**（锚点/相对位置/尺寸关系）；视觉标注（底色/字号/描边）一律以权威库为准，不在线框内标。
> 通用规则：控件一律锚点 + 相对尺寸摆放，**不写绝对屏幕坐标**；角落件锚四角，居中 `(0.5,0.5)`；
> 面板居中时四周留足边距。

### 6.1 通用规则

- **全中文**：任一界面不得出现英文单词；例外 = 品牌名「3D」、按键字母（Esc / WASD / E / 空格）、
  版本号数字。由 `UiStringsTests` 无英文残留断言锁死。
- **术语统一**：`Crew`→船员、`Turn`→回合、`Roster`→名册/编成、`Throw`→投掷、`Launch`→抛自己、
  `Ally`→我方、`Enemy`→敌方。
- **按钮文案 2–4 字动宾结构**（「出战」「上阵」「返回」），不用「点击这里」。
- **中英混排**：中文与西文/数字之间插一个半角空格（「存活 8/8」「第 3 关」「XP 120」）；
  数字与单位之间不加空格；伤害/血量后缀写中文（「生命」「经验」），不写 HP/XP；
  百分比用半角 `%` 前不加空格（「78%」）。
- **排版**：中文不适用斜体，强调只靠字号档 + 颜色；全角中文标点；省略号用「……」；
  中文列表用「、」不用英文逗号。
- **符号**：`★☆` 不用字符，用图标 sprite（两套字体是否含此字形未确认）；数字用字体自带半角西文；
  血量/评分/星级/时间用等宽或表格数字防跳动；快捷键字母保留半角大写。

## 七、中文字体（像素字体原生档四档）

【创始人裁决口径，实现细节见[架构总览 §8.1](../技术/架构/架构总览.md)】

- **四档**：16 = 正格点黑16（`ZhengGeDianHei16`）；12 / 10 / 8 = 缝合像素
  （`FusionPixel12/10/8-zh_hans`，缺字回退链已烘进资产）。
- **没有的档不硬凑、绝不放大**（12px 烘 24 = 翻倍，已否决）；**禁伪粗**（TMP 合成加粗在位图上 =
  重影乱码，已全局禁用）。
- **位图口径** = 原生档 samplingPointSize + RASTER_HINTED + atlasPadding 0 + 图集 Point +
  `TextMeshPro/Bitmap` 材质。字号是独立体系，不锚定艺术像素。
- 选型样张与许可见 [../images/ui-font/README.md](../images/ui-font/README.md)。
