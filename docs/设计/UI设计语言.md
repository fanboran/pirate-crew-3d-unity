# UI 设计语言 · 多彩卡通（夜海宝箱）

> 视觉系统的设计意图与使用纪律。所有常量的**代码真相源**是
> `pirate-crew/Assets/Scripts/UI/Skin/UiSkin.cs`（Token）与
> `CartoonSpriteFactory.cs`（皮肤算法），本文记录"为什么这么设计"；
> 数值以代码为准。组件真实长相的回归自检见组件陈列页（`UiGalleryPage`，
> 出图机位 `ui-gallery` / `ui-gallery-icons`）。
>
> 姊妹篇：stick-world（game-2）的 `docs/设计/UI/01-设计语言.md`——两边共享
> "Token 单源 / 变体表 / zone 布局表 / 陈列页自检"的机制骨架，视觉语言各自独立。

## 一、视觉哲学

### 1.0 多彩卡通是全局唯一皮肤

主菜单、选关、船员管理与战斗 HUD 统一走**同一套皮肤栈**
（`UiKit` 工厂 → `CartoonSpriteFactory` 平色皮肤 → `UiSkin` Token）。
任何界面不得出现第二套材质语言（旧木板 / 羊皮纸 / 玻璃拟态栈已退役清单化）。
**技术保证**：Editor 装配与运行时动态件共用同一工厂，皮肤/字号/动效单轨。

### 1.1 夜海宝箱（核心比喻）

界面的底是一口**夜海中的沉箱**：深靛蓝的近黑（`InkDeep` #1C2333）,
里面装着宝石——17 种武器色、7 种职业色在高饱和度下发光,金色是箱体上的黄铜锚点。
这是对《哈迪斯》UI 机制的解构与转译,哈迪斯"多彩而不乱"靠四件事:

| 哈迪斯的机制 | 本项目的转译 |
| --- | --- |
| **色即身份**:每个神/祝福一个专属色,玩家 0.1 秒读色识物,色彩是信息压缩 | 17 武器色 / 7 职业色(内容色板),图标格底、静物、pips 同色系 |
| **深底策略**:背景近乎纯深,彩色图标像宝珠宝石般跳出——对比让多彩成立 | `InkDeep` 夜海靛蓝做全部容器底,内容色不与其争明度 |
| **金线统一**:无论多少种色相,金色细线作为"系统色"贯穿全部框架,多彩而不散 | `Gold` 是唯一强调色(§1.2),tintable 件自带 1px 同色系深边,全件同语言 |
| **装饰即功能**:Art Deco 边框不是装饰,是信息容器(血条框/槽位框) | 凹槽构造线、端箍、徽章环(§3.3)——装饰都在"容器"语义上 |

### 1.2 一个强调色

全套 UI 只有**一个操作强调色:金**(`Gold` #F2C14E)。用于且仅用于:

| 用途 | 例子 |
| --- | --- |
| 主行动点 | 投掷自爆 / 继续 / 再来一局 / 确认 |
| 选中态 | 已装备武器格金框、当前模式钮 |
| 仪式感数值 | 结算星级、武器名 |

**内容色 ≠ 操作色**:队色(红/蓝)、武器色、职业色是"画在画面里的颜色",
只上图形与图标底,**永不出现在操作按钮底上**。强调色滥发会让玩家找不到
"该点哪"——多彩属于世界,金色属于操作。

### 1.3 图标优先,文字退位

原版 Flash 逆向基准就是全图标操作(跳跃/攻击皆图标)。文字只留四类:
界面标题、结算横幅、一条操作提示、无障碍兜底(武器名在选中时显示一次)。
**图形规范**:非文字元素对比度 ≥3:1,文字 ≥4.5:1(WCAG 2.1,测试断言锁死)。

### 1.4 拟物极度抽离 + 两段卡通明暗

不追求材质真实感。材质暗示只用**一道线**的程度,且只在有构造语义处用:

- **两段卡通明暗**(全部件):顶亮带 + 主段略暗的灰度阶梯,乘色后保留——
  糖豆人式"上受光"卡通体积,不用渐变、不破坏平涂纪律;
- **凹槽构造线**(血条族):顶 1px 反光、底 30% 暗带、两端 2px 端箍——
  木桶箍的极度抽象,凹槽是"被箍住的容器",不是一条黑缝;
- 禁止:写实纹理、投影、内外发光、斜纹大面积铺底。

## 二、色彩系统

### 2.1 基底(三档语义,同屏不得出现第四种近黑)

| Token | 值 | 语义 |
| --- | --- | --- |
| `InkDeep` | #1C2333 | **独立容器底**:面板/武器面板/小地图/模态卡片 |
| `InkSoft` | #2A3350 | **嵌件与浮空控件底**:chip、图标钮、pips 边框、提示条 |
| `BarTrackInk` | #10141E | **凹槽底**(有填充压顶时):血条族专用 |

### 2.2 文字与强调

| Token | 值 | 用途 | 对 InkDeep 对比度 |
| --- | --- | --- | --- |
| `TextOnInk` | #F5EFE0 | 正文/按钮字 | 13.7:1 |
| `TextDim` | #CFC6B0 | 辅助/角标 | 9.1:1 |
| `Gold` | #F2C14E | 唯一强调色(§1.2) | 9.4:1 |
| `InkOnGold` | #2A1D0E | 金底上的字 | — |
| `Danger` | #8A1F1F | 破坏性动作底 | 白字 8.0:1 |

### 2.3 队色(内容色的特例:唯一允许成对出现在 HUD 结构上的色)

`TeamRed` #FF3A2A / `TeamBlue` #3366FF(图形),文字场景用提亮档
`TeamRedText` #FF8A7A(6.9:1) / `TeamBlueText` #7FB0FF(7.0:1)。

### 2.4 内容色板(色即身份的落点)

- **武器 17 色**(`UiSkin.WeaponColor`):图标格底与静物主色共用一套——
  UI 与图标天然同色系,如樱桃弹 #E23B3B、香蕉黄 #F0D048、巫毒紫 #9A5FD0;
- **职业 7 色**(`UiSkin.CrewColor`):水手天蓝 / 炮手橙 / 狙击青 / 钩子黄铜 /
  纵火火红 / 骷髅骨白 / 船长金;
- 纪律:饱和度 ≥0.28(多彩下限,测试锁死)、彼此可分、不上操作按钮。

## 三、形状与装饰语言

### 3.1 圆角:两档 + 全圆

| 档 | Token | 值 | 用途 |
| --- | --- | --- | --- |
| 容器档 | `RadiusPanel` | 8 | 面板/大图标格/小地图 |
| 控件档 | `RadiusChip` | 6 | 按钮/chip/提示条 |
| 全圆 | — | 半径=半高 | 仅血条填充(Pill)与圆件(徽章/圆点) |

### 3.2 细边

1px 细边(`StrokeThin`)。tintable 件烘 0.16 灰深边(乘色后=同色系深边);
固定色件边线比底亮一档。**无粗描边、无贴纸硬投影**。

### 3.3 构件修饰语言(2026-09-19 定案,血条是标志件)

| 件 | 修饰 | 语义 |
| --- | --- | --- |
| 全部 tintable 件 | 顶亮带 32% 高 / 主段 0.88(Pill 0.82) | 上受光的卡通体积 |
| 血条凹槽 BarTrack | 顶 1px 反光 + 底 30% 暗带 + 两端 2px 端箍 | "被箍住的容器" |
| 面板 PanelInk | 上沿 1px 微光 6% | 与凹槽顶反光同语言 |

**切片安全约束**:修饰只依赖垂直方向或落在九宫格 border 区,任意拉伸形态
稳定——依赖水平方向的纹理(斜纹等)会被中段拉伸抹除,一律不做。

### 3.4 间距系统

`Safe`(屏缘安全距)=16,`PanelPadding`=14,`Gap`=12;件内间距只取
4 / 6 / 8 / 12 / 16 五档。

## 四、字体规范

### 4.1 字族分工(三族,与 stick-world 同源的开源字库)

| 族 | 字体 | 授权 | 角色 |
| --- | --- | --- | --- |
| 标题 | StickHand(站酷快乐体骨架+确定性扰动,`tools/fonts/gen_hand_font.py`) | OFL 1.1 | 手绘海盗字:游戏名/横幅/回合数字/面板标题 |
| 正文 | 霞鹜文楷 Lite Medium | OFL 1.1 | 按钮/行文本/HUD 常读 |
| 次级 | 霞鹜文楷 Lite Regular | OFL 1.1 | 说明/提示/角标 |

规则:**手写体只上"仪式感短文本"**(数字、标题、横幅),长句一律霞鹜文楷
(手写体小字号可读性差);混排时同屏至多两族。

### 4.2 字号八档(`UiSkin.Font`,全项目唯一真值)

| 档 | 值 | 用途 | 字族 |
| --- | --- | --- | --- |
| Display | 48 | 主菜单游戏名 | 标题 |
| Banner | 36 | 结算横幅 | 标题 |
| Title | 26 | 界面标题 | 标题 |
| Section | 20 | 区块标题/武器名 | 次级 |
| Hud | 18 | HUD 常读/单位名/模式 | 正文 |
| Body | 15 | 按钮/行文本(基准) | 正文 |
| Hint | 14 | 辅助提示 | 次级 |
| Tiny | 13 | 角标/HP 数字/快捷键 | 次级 |

### 4.3 使用纪律

- **字号跟控件走**:按钮字高 ≥ 控件高的 1/3(44px 钮 ≥15px 字),
  不做"大按钮小字"的空洞感;
- 旧 `UiTheme.Font*` 档位经 Editor 侧映射后与本表一致,新代码一律引本表;
- 运行时动态文本经 `UiKit.RuntimeFont`(Resources 副本)取同族字体,
  杜绝 TMP 默认字体(无中文字形)漏网。

## 六、布局原则(zone 带)

- **顶部带**(垂直中心 y=500):小地图占左上角 → 红条/徽章/蓝条以屏幕中轴
  **镜像等长**(640) → 模式三钮收右上角贴缘。互不侵犯(间隙 ≥8px);
- **底部带**(底边线统一 y=16):[暂停/返回] → [武器面板贴底居中] → [提示条]
  共享同一条底边线,不悬空、不骑叠;
- **中央战场区只准小件**(徽章/提示文字/准星),大战场留给 3D;
- **防撞合同**:装配期对顶层部件两两 AABB 检测,相交即警告
  (`[HUD 布局防撞]`,曾因此修掉模式钮压血条/提示条压面板两起真实事故);
- 改布局 = 改 `BattleHudBuilder` zone 常量,不手挪单个部件。

## 七、图标语言

三类,全部像素程序化(无 GPU 渲染依赖),双轨同源(运行时内存/烘焙 PNG):

| 类 | 产线 | 规格 |
| --- | --- | --- |
| 武器静物 | `UiIconPainter.PaintWeapon` 17 种 | 96×96,主色=武器色,自动 1px 深边+顶部 gloss |
| 职业头像 | `PaintCrew` 7 种,两件式底+职业标记 | 96×96 |
| 符号 | `UiGlyphs` 平涂(准星/眼/骷髅/星/旗…) | 48×48 矢量判定 |

纪律:图标即信息(色相=身份),不配文字说明除非选中;风格统一由同一 Raster
工具类保证(深边/高光同参数)。

## 八、动效语言(juice)

| 动效 | 参数 | 用途 |
| --- | --- | --- |
| Pop 弹入 | 0.24s back-out 过冲 1.18 | 徽章/模态卡片/星级逐颗 |
| Punch | 按钮点击 | 全部可点件 |
| 按压下沉 | 2px | `UiPressSink` 全钮 |
| Damage ghost | 主填充 12/s,白残影 2.2/s 只降不升 | 血条族 |
| 面板滑入 | 淡入+24px 上移 | 模态 |

纪律:动效只做缩放/位移/透明度;时长 0.09~0.24s,不做慢动画。

## 九、落地与自检(管线闭环)

1. **Token 单源**:一切数值出自 `UiSkin`,代码里禁止散落魔法值;
2. **变体表**:按钮档位 `UiKit.ButtonKind` 表驱动,调用点零手配色;
3. **组件陈列页**:`UiGalleryPage`(ui-gallery / ui-gallery-icons 机位出图)——
   改 Token 后出一张图即可全貌回归,**组件面板是设计系统的活文档**;
4. **防撞警告**:装配期自动检测(§六);
5. **对比度测试**:WCAG 断言在 `UiSkinTests` 锁死,改色必跑;
6. 本文档 + 陈列页图 + gallery 出图入 `docs/images/ui-hud-r1/` 归档。
