## 一、视觉哲学

### 1.0 手绘涂鸦是全局唯一皮肤

主菜单、选关、船员管理与战斗 HUD 统一走**同一套手绘皮肤栈**
（`UiKit` 工厂 → `SketchSkin` 槽位帧 → `tools/sketch_ui` 烘焙贴图 → `UiSkin` Token）。
任何界面不得出现第二套材质语言（旧木板 / 羊皮纸 / 玻璃拟态 / 平色九宫格已退役清单化）。
**技术保证**：Editor 装配与运行时动态件共用同一工厂，皮肤/字号/动效单轨；
贴图落 `Assets/Resources/UI/Sketch/`，场景序列化引用与播放器 `Resources.Load` 一份两用。

### 1.1 夜海宝箱（核心比喻）

界面的底是一口**夜海中的沉箱**：深靛蓝的近黑（`InkDeep` #1C2333）,
里面装着宝石——17 种武器色、7 种职业色在高饱和度下发光,金色是箱体上的黄铜锚点。
这是对《哈迪斯》UI 机制的解构与转译,哈迪斯"多彩而不乱"靠四件事:

| 哈迪斯的机制 | 本项目的转译 |
| --- | --- |
| **色即身份**:每个神/祝福一个专属色,玩家 0.1 秒读色识物,色彩是信息压缩 | 17 武器色 / 7 职业色(内容色板),图标格底、静物、pips 同色系 |
| **深底策略**:背景近乎纯深,彩色图标像宝珠宝石般跳出——对比让多彩成立 | `InkDeep` 夜海靛蓝做全部容器底,内容色不与其争明度 |
| **金线统一**:无论多少种色相,金色细线作为"系统色"贯穿全部框架,多彩而不散 | `Gold` 是唯一强调色(§1.2),tintable 件自带 1px 同色系深边,全件同语言 |
| **装饰即功能**:Art Deco 边框不是装饰,是信息容器(血条框/槽位框) | 凹槽构造线、端箍、徽章环(§3.3)——装饰都在"容器"语义上 |

### 1.2 一个强调色

全套 UI 只有**一个操作强调色:金**(`Gold` #F2C14E)。用于且仅用于:

| 用途 | 例子 |
| --- | --- |
| 主行动点 | 投掷自爆 / 继续 / 再来一局 / 确认 |
| 选中态 | 已装备武器格金框、当前模式钮 |
| 仪式感数值 | 结算星级、武器名 |

**内容色 ≠ 操作色**:队色(红/蓝)、武器色、职业色是"画在画面里的颜色",
只上图形与图标底,**永不出现在操作按钮底上**。强调色滥发会让玩家找不到
"该点哪"——多彩属于世界,金色属于操作。

### 1.3 图标优先,文字退位

原版 Flash 逆向基准就是全图标操作(跳跃/攻击皆图标)。文字只留四类:
界面标题、结算横幅、一条操作提示、无障碍兜底(武器名在选中时显示一次)。
**图形规范**:非文字元素对比度 ≥3:1,文字 ≥4.5:1(WCAG 2.1,测试断言锁死)。

### 1.4 手绘沸腾（material 的极度抽离）

不追求材质真实感。**"手画感"本身就是材质**：每件 UI 的轮廓是 wobbly 扰动的
圆角矩形墨线（cos 整数频率噪声，平铺无缝），三帧沸腾逐帧重掷边缘（0.12s 节拍、
逐件独立相位）——UI 像是被人一支笔画出来、还在微微呼吸。面板黑场烘 2~3% 纸感噪点。
禁止：写实纹理、投影、内外发光、渐变。

- **tint 槽纪律**：彩底件（血条段/职业 pip/武器格/徽章圆片）统一用白实底+墨边的
  tint 槽（pip/ring/fill/cell），运行时 `Image.color` 乘色——白系边乘深色会隐形，
  彩底件一律走墨边；固定色槽（panel/btn 系）不乘色（color=white）。
- **按钮四态是四张贴图**（normal/hover/pressed/disabled 各自沸腾），不靠 tint 变色；
  `SketchBoil` 用指针事件维护 hover/pressed。时序铁律：`OnEnable` 不得 Apply
  （AddComponent 同步触发时 Slot 尚未赋值）。

## 二、色彩系统

### 2.1 基底(三档语义,同屏不得出现第四种近黑)

| Token | 值 | 语义 |
| --- | --- | --- |
| `InkDeep` | #1C2333 | **独立容器底**:面板/武器面板/小地图/模态卡片 |
| `InkSoft` | #2A3350 | **嵌件与浮空控件底**:chip、图标钮、pips 边框、提示条 |
| `BarTrackInk` | #10141E | **凹槽底**(有填充压顶时):血条族专用 |

### 2.2 文字与强调

| Token | 值 | 用途 | 对 InkDeep 对比度 |
| --- | --- | --- | --- |
| `TextOnInk` | #F5EFE0 | 正文/按钮字 | 13.7:1 |
| `TextDim` | #CFC6B0 | 辅助/角标 | 9.1:1 |
| `Gold` | #F2C14E | 唯一强调色(§1.2) | 9.4:1 |
| `InkOnGold` | #2A1D0E | 金底上的字 | — |
| `Danger` | #8A1F1F | 破坏性动作底 | 白字 8.0:1 |

### 2.3 队色(内容色的特例:唯一允许成对出现在 HUD 结构上的色)

`TeamRed` #FF3A2A / `TeamBlue` #3366FF(图形),文字场景用提亮档
`TeamRedText` #FF8A7A(6.9:1) / `TeamBlueText` #7FB0FF(7.0:1)。

### 2.4 内容色板(色即身份的落点)

- **武器 17 色**(`UiSkin.WeaponColor`):图标格底与静物主色共用一套——
  UI 与图标天然同色系,如樱桃弹 #E23B3B、香蕉黄 #F0D048、巫毒紫 #9A5FD0;
- **职业 7 色**(`UiSkin.CrewColor`):水手天蓝 / 炮手橙 / 狙击青 / 钩子黄铜 /
  纵火火红 / 骷髅骨白 / 船长金;
- 纪律:饱和度 ≥0.28(多彩下限,测试锁死)、彼此可分、不上操作按钮。

## 三、形状与装饰语言

### 3.1 手绘槽位表（贴图即形状，`SketchSkin` 槽名）

形状不再由圆角 Token 推导，而是**烘焙槽位**（96px 贴图、九宫格 border=10、三帧沸腾）：

| 槽 | 内容 | 用途 |
| --- | --- | --- |
| `panel` / `panel_light` | 夜海靛蓝深底（88%/72% 透明玻璃窗）+ 白 30% 手绘边 + 纸感噪点、wobble 1.8 | 面板/模态卡片 / HUD 横条 |
| `btn_*` 四态 | 白 7% 叠加底 + 白系三级边（16/30/38，pressed 金边） | 常规按钮/chip/提示条 |
| `btn_primary_*` 四态 | 金实底 + 墨边 | 主行动钮（Primary 变体） |
| `danger_*` 三态 | 红 14% 叠加 + 红边 | 危险动作（Danger 变体） |
| `btn_ink_*` 四态 | 奶油纸底 + 墨边 | 亮背景形态（波次 B 主菜单用） |
| `progress_bg` / `progress_fill` | 凹槽底 / 金填充 | 血条轨 / gallery 金条 |
| `accent_*` / `tab_*` | 金叠加选中态 / 页签 | 选中格 / 页签（波次 B） |
| `groove` / `groove_focus` | 凹槽 / 金边聚焦 | 输入框（波次 B） |
| `pip` / `ring` / `fill` / `cell` | **白实底+墨边 tint 槽**（近圆/圆片/圆角条/方格） | 运行时乘色：职业点/徽章/血条段/武器格 |
| `sep_h` / `sep_v` | 手绘波浪分隔线 | 分隔（波次 B） |

### 3.2 墨线纪律

边线是沸腾墨线（LINE_W 2.6@4x 超采样），**无粗描边、无贴纸硬投影**；圆槽
（pip/ring）不切片整图缩放，方槽走九宫格（烘焙自检三关锁平铺无缝）。

### 3.3 间距系统

`Safe`(屏缘安全距)=16,`PanelPadding`=14,`Gap`=12;件内间距只取
4 / 6 / 8 / 12 / 16 五档。

## 四、字体规范

### 4.1 字族：文字统一 StickHand（隔壁纪律）

| 字体 | 授权 | 角色 |
| --- | --- | --- |
| StickHand（站酷快乐体骨架+确定性扰动） | OFL 1.1 | **全部 UI 文字**：标题/按钮/HUD 常读/说明/角标 |

规则：全 UI 一族手写体（笔画等粗，1080p 小字号可读性优于霞鹜文楷细笔画——
2026-09-20 可读性裁决）；`UiKit.RuntimeFont` 三档统一返回 StickHand，
霞鹜文楷资产保留给未来长文场景（如剧情文本）。

### 4.2 字号八档(`UiSkin.Font`,全项目唯一真值;2026-09-20 可读性裁决整体上调)

| 档 | 值 | 用途 |
| --- | --- | --- |
| Display | 52 | 主菜单游戏名 |
| Banner | 42 | 结算横幅 |
| Title | 30 | 界面标题 |
| Section | 24 | 区块标题/武器名 |
| Hud | 22 | HUD 常读/单位名/模式 |
| Body | 18 | 按钮/行文本(基准) |
| Hint | 16 | 辅助提示 |
| Tiny | 15 | 角标/HP 数字/快捷键(手写体小字下限) |

### 4.3 使用纪律

- **字号跟控件走**:按钮字高 ≥ 控件高的 1/3(44px 钮 ≥15px 字),
  不做"大按钮小字"的空洞感;
- 旧 `UiTheme.Font*` 档位经 Editor 侧映射后与本表一致,新代码一律引本表;
- 运行时动态文本经 `UiKit.RuntimeFont`(Resources 副本)取同族字体,
  杜绝 TMP 默认字体(无中文字形)漏网。

## 六、布局原则(zone 带)

- **顶部带**(垂直中心 y=500):小地图占左上角 → 红条/徽章/蓝条以屏幕中轴
  **镜像等长**(640) → 模式三钮收右上角贴缘。互不侵犯(间隙 ≥8px);
- **底部带**(底边线统一 y=16):[暂停/返回] → [武器面板贴底居中] → [提示条]
  共享同一条底边线,不悬空、不骑叠;
- **中央战场区只准小件**(徽章/提示文字/准星),大战场留给 3D;
- **防撞合同**:装配期对顶层部件两两 AABB 检测,相交即警告
  (`[HUD 布局防撞]`,曾因此修掉模式钮压血条/提示条压面板两起真实事故);
- 改布局 = 改 `BattleHudBuilder` zone 常量,不手挪单个部件。

## 七、图标语言

三类,全部像素程序化(无 GPU 渲染依赖),双轨同源(运行时内存/烘焙 PNG):

| 类 | 产线 | 规格 |
| --- | --- | --- |
| 武器静物 | `UiIconPainter.PaintWeapon` 17 种 | 96×96,主色=武器色,自动 1px 深边+顶部 gloss |
| 职业头像 | `PaintCrew` 7 种,两件式底+职业标记 | 96×96 |
| 符号 | `UiGlyphs` 平涂(准星/眼/骷髅/星/旗…) | 48×48 矢量判定 |

纪律:图标即信息(色相=身份),不配文字说明除非选中;风格统一由同一 Raster
工具类保证(深边/高光同参数)。

## 八、动效语言(juice)

| 动效 | 参数 | 用途 |
| --- | --- | --- |
| Pop 弹入 | 0.24s back-out 过冲 1.18 | 徽章/模态卡片/星级逐颗 |
| Punch | 按钮点击 | 全部可点件 |
| 按压下沉 | 2px | `UiPressSink` 全钮 |
| Damage ghost | 主填充 12/s,白残影 2.2/s 只降不升 | 血条族 |
| 面板滑入 | 淡入+24px 上移 | 模态 |

纪律:动效只做缩放/位移/透明度;时长 0.09~0.24s,不做慢动画。

## 九、落地与自检(管线闭环)

1. **Token 单源**:一切数值出自 `UiSkin`,代码里禁止散落魔法值;
2. **变体表**:按钮档位 `UiKit.ButtonKind` → `SketchSkin` 槽组表驱动,调用点零手配色;
3. **烘焙管线**:`python tools/sketch_ui/gen_sketch_ui.py` 一键重烘 32 槽×3 帧
   (配色改脚本顶部常量区),平铺自检三关任何槽位失败即停产;再跑
   `PirateCrew/UI/设定手绘皮肤导入参数` 落 .meta;
4. **组件陈列页**:`UiGalleryPage`(ui-gallery / ui-gallery-icons 机位出图)——
   改 Token/贴图后出一张图即可全貌回归,**组件面板是设计系统的活文档**;
5. **防撞警告**:装配期自动检测(§六);
6. **对比度测试**:WCAG 断言在 `UiSkinTests` 锁死,改色必跑;
7. 本文档 + 陈列页图 + 出图入 `docs/images/ui-hud-r1/` 归档。
