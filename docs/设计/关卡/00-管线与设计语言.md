# 关卡布局与现状

> **本文是什么**:关卡地形的布局形制 + 各关设计文档入口 + 当前状态声明。
> **角色分工**:地形布局由用户设计;**编成(人数/摆位/武器/luck)与一切战斗数值尚未设计**——
> 关卡数据里的编成是占位,仅保证可玩,不构成设计。参照游戏(《Mutiny》)只作灵感库,
> 布局一律自研。

## 一、布局形制

> 用户口径:地图像糖豆人那种——**到处都是浮空的**,布局不许摊成一排平面。

1. **整块岛体**:每座岛是一个可读的整体(整船/整岛),底部有船体/岩锥收形;
   禁止贴水薄甲板、矩形拼盘、同层平铺、木板+草方块混搭。
2. **悬浮与纵深**:岛群高低错落浮在海面上方,每岛有厚度,相邻岛纵深错开;
   落水即死;岛间高差保留「越水武器/绕路」的玩法语义。
3. **场地范围呈环形区域**:整场收在一个**环形范围**内表达——环形说的是范围的形状,
   不是对称要求;地形以岛形轮廓记录(数据即形状),不存在矩形采样网格。
4. **大色块高可读**:能站/会死一眼分清;形状与色彩回到玩具级清晰(美术口径见[美术.md](../美术.md))。
5. **船类不长草**(任何途径都不行,含全局草散射);船体走 Blender 手作管线
   (见[资产管线/Blender导出](../../技术/资产管线/Blender导出.md))。
6. **消灭垂直硬截断**:岛缘/船体与空气的交界要有收形(倒角/渐窄/悬挑),禁止直上直下的墙。

## 二、关卡现状

- 现役四关的**地形布局由用户设计**:01 云端漫步 / 02 天空之岛 / 03 废弃化工厂 / 04 废弃化工厂2
  (各见同目录设计文档;03/04 的美术件为 AI 产出、未经用户过目)。
- **编成与数值未设计**:单位数量、出生摆位、初始武器、空投池、luck 及全部战斗数值,
  关卡数据里的现值均为占位;设计时机由用户定。
- **关卡设计方法论尚未开始**:难度、编成规则、建关约束均无既定方案;
  待用户启动关卡设计时从零立,本文不预设。
