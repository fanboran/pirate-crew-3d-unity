# 关卡管线与设计语言

> **本文是什么**：关卡制作的**工序章程**（六阶段管线）+ **建关约束**与参照经验提炼。
> 参照游戏（Nitrome《Mutiny》）只作**灵感库**——布局一律自研，不搬不抄；逐关实算细节已随归档逆向退场，
> 本文只留提炼后的规则与结论。
> **角色分工**：关卡策划（AI，产出一律标「提案/待定」）负责设计与落地；用户是制作人兼终审，
> 样板先行——美术方向与体验目标未经用户过目不算数。
> **标注约定**沿用 [美术.md](../美术.md)。
> 每关的纸面设计见同目录 01–04 各关文档。

## 一、制作管线（六阶段）

1. **概念立项**——定体验目标：这关想让玩家感受什么、教会什么、记忆点是什么；选地形母题与对称档。
   产出：关卡设计文档的「概念卡」一节（一页以内）。门禁：用户确认方向（样板先行铁律）。
2. **纸面设计**——俯视布局图、编成表、武器投放表、关内节奏曲线、难度定位；对照 §四建关约束逐条自查。
   产出：设计文档全文 + 布局图 PNG（`tools/level-design/render_layouts.py` 从文档 ASCII 块渲染，文档是唯一真源）。
   门禁：建关约束自查全绿；有意偏离基准的条目显式标注。
3. **灰盒落地**——布局译成代码数据：高度场/编成/武器池/摆位表；视觉先用可站面烘焙件
   （云场/空岛 prefab，逻辑-视觉按构造对齐）。
   产出：可玩关卡 + EditMode 测试（站位实心、编成数、摆位契约、水距/簇数等可测约束）。
   门禁：无头编译 0 错；EditMode 全绿。
4. **玩法走查**——出图/试玩，按设计文档的验收清单逐条核对。
   产出：实拍截图（`docs/images/level-design/`）+ 走查记录（验收清单勾选结果写回设计文档）。门禁：用户过目通过。
5. **美术接入**——按设计文档的资产清单把灰盒观感升级为正式美术（Blender 手作 / 岛壳烘焙）。
   产出：替换后的 prefab/FBX + 重烘实拍对比。门禁：实拍对比无缺件、无洋红；用户终审。
6. **封版**——锁资产：确定性测试钉住几何、manifest 登记上游、交接文档回写。
   产出：测试绿 + `scene-assets.json` 登记 + 交接指南新条目。门禁：全部门禁通过。

**回退规则**：走查或终审不通过 → 回到对应阶段改设计/改数据，不允许"先上线后补文档"。

## 二、每关一份设计文档（模板）

章节固定，方便对照走查：

1. **概念卡**——一句话 / 体验目标 / 教学目标 / 记忆点 / 母题与对称档
2. **关内节奏**——开场 → 发展 → 高潮 → 收尾的强度曲线（附简单示意）
3. **布局**——ASCII 布局块（```layout，渲染成 PNG）+ 分区表 + 尺度实算（簇数/最大水距/人均平台面积）+ 建关约束对表
4. **编成与数值**——双方单位表（类型/世界坐标（米）/luck/初始武器），luck 语义见 `LevelData`
5. **武器与掉落**——初始武器 + 空投池，投放理由参照原作首现节奏（§五）
6. **难度定位**——在关间难度曲线（§七）上的坐标
7. **资产清单**——现有件 / 待产件（注明管线归属：岛壳烘焙 / Blender 手作）
8. **验收标准**——可测条目 + 实拍判据

## 三、数值与规则真源（建关必读）

- **建关约束**：本文 §四（前几条可写进测试，其余为指南）
- **数值锚点**（HP 100 / 武器 size-maxDamage 总表 / 爆炸线性衰减）：
  [参考逆向-静态](../../项目/归档/参考逆向/参考游戏逆向-海盗军团抢宝藏-静态.md) §4-§5（**2D 原版的历史记录，仅作灵感**）；
  本工程实测口径（满力射程 ≈23.5 m、最大跳隙 13 m）见[地图设计审计报告](../../审计/归档/地图设计审计报告.md)（已归档·仅作沿革）
- **尺度常量（全米）**：块高 0.5 m、水面 y = −0.4 m（真源 `LevelGeometry`，口径见
  [3D空间模型对齐.md](../3D空间模型对齐.md)）；**资产与玩法数值一律用米写**，样板关场地 40×30 m、
  废弃化工厂 64×44 m / 六件版 56×40 m。运行时地形数据的 2 m 采样间隔只是数据存储粒度，
  不对玩家、不对资产、不对文档暴露。
- **luck 档位**：参照原版逐角色配 1/2/5/10，越大 AI 试投越多越准——是本工程的敌方难度主旋钮

## 四、建关约束

> 从参照游戏 33 关实算提炼（实算过程已归档，不在此复算），按本工程米制口径改写；
> **单位一律米**。布局形制受 §六 约束，冲突时以 §六 为准。

1. **主战场 ≥16×8 m**，容纳本关全部出生点；每个出生点对应 ≥16 m² 平台面积（防"开局就是靶子"）。
2. **常规关岛间水距 2–10 m**；唯一的例外是"远距对峙"构图（可到 16–20 m），且**该关武器池必须配越水武器**
   （追踪召唤类 / 落点打击类 / 大炮 / 巨浪类）。
3. **单次投掷跨越的水距 ≤ 满力射程的 80%**（本工程实测满力 ≈23.5 m，故上限 ≈19 m），常规关建议 ≤10 m。
4. **每关一个主导形状 + 至多一个次要变奏**，禁止三种母题拼盘。
5. **对称性按目的选档**：公平对枪/决斗 → 完美镜像；教学与主场 → 强镜像；强调机动与高低差 → 不对称。
   "面积公平"可以配"形状不等"。
6. **垂直大关之后必须接一个低平关**——垂直大关 = 岛高差 ≥9 级台阶；低平关 = ≤3 级。
7. **掩体密度用独立平台簇数控制**：教学 5–9 簇、常规 7–12 簇、高密 19–21 簇；掩体靠高度差与可放置物，不靠墙。
8. **抬升台阶的进深 ≥4 m**（太窄抛不准）。
9. **每关必须有且只有一个记忆点**；节奏 = 每 2–3 关一个极端形状，中间夹常规关。
10. **后续关卡优先"复用 + 变奏"而非新造**：改纵深、换出生分布（可交错）、把关键武器加量/∞ 化。
11. **首关（教学）不上多层、水距 ≤6 m**；教学点在"基础投掷 + 小心水"，不在武器多样性。
12. **掩体用高度差不用墙**：引入斜坡 / 单向平台 / 可破坏地形属**超出参照基准的新增**，须显式标注。

## 五、参照经验提炼（灵感库，来自 33 关实算的结论层）

> 以下为参照游戏《Mutiny》全 33 关实算归纳的**设计模式**，只作灵感与配平参照，不是构造依据。

### 5.1 平台形状 = 战术模板（8 个母题）

1. **长条对峙**——两条长条平台夹一段开阔水道；两线平行对枪，水距决定能否"跨线"。
2. **正镜像决斗**——近乎完美的对称台地；绝对公平，胜负只由操作与武器决定（公平关）。
3. **环岛堡垒**——数个环形镂空大岛；岛内可绕、岛间必须用远程武器。
4. **碎岛雨**——大量独立碎块，几乎无主大陆；掷不准就落水，高 luck AI 的主场。
5. **阶梯峰**——单个大盘、顶面多级台阶；高低差压制，抢顶层 = 射程与视野优势。
6. **竖塔**——两根高柱加中间横梯；纯垂直战斗、短距遭遇。
7. **水线步石**——一排小岛一字排开；强制点对点位移，落水风险最高。
8. **单一大船/大岛**——一个整体大平台；出生点全在同场，纯"同场混战"，Boss 关首选。

参照基准**没有**斜坡/单向平台/可破坏地形——掩体的等价物是**高度差**与**可放置木箱**（见 §四第 12 条）。

### 5.2 对称性四档，按"这关想让玩家比什么"选

完美镜像（IoU≥0.95，公平对枪/决斗）／强镜像（0.70–0.90，结构对称+一处微差，比"抢同一点"）／
中等（0.50–0.69，比"利用哪一侧"）／不对称（<0.50，比机动、绕后、高低差）。
**"面积公平"可以配"形状不等"**——参照首关形状不对称但双方平台面积与到水距离对等，仍是平衡的教学关。

### 5.3 水是死亡区，也是配平的"因"

- 水占比：绝大多数关水是**薄底带**，只有"水关"母题才让水吃掉大块画面（此类关极少且分散）。
- **配平规则（最有价值的发现）**：水距一旦拉大，该关武器池**一定**配越水武器——
  **水距是"武器池的因"，不是结果**，重制建关时必须成对设计（见 §四第 2/3 条）。
- 水危险度渐进：教学关只给一道窄沟 → 再给"底部薄水+悬空碎岛" → 顶点才给"水占半幅、只靠小岛落脚"。

### 5.4 内容节奏

- **武器"广而快"**：参照原版把全部武器在前 5 关投放完毕，之后靠**地形/敌人/比例**制造新鲜感，
  而不是"再解锁一件武器"。
- **敌人一关一新脸但零属性差**：换的只是美术 + luck + 初始武器——"一关一新敌人"是**纯视觉新鲜感**，
  不进难度曲线。
- **掩体密度在"碎（多而小）↔ 整（少而大）"两极间摆动**，不是单调递增；**每 3–5 关换一次极性**。
- **高低差节奏 = 大 → 小 → 大**：一次垂直大关后必接低平关（见 §四第 6 条）。
- **极端—缓冲—极端**：每 2–3 关一个极端形状关，中间用常规整块关缓冲。
- **复用变奏公式**：用"改尺寸 + 换出生分布 + 武器池加量"把 15 张图变成 33 关，而不是 33 张独立地图。

## 六、布局形制总纲（优先级高于 §四/§五）

**裁决 1：地图设计总纲（2026-09-14）**

> 原话：「我想象的地图设计是一个糖豆人那种地图……我指的是它到处浮空的。你现在的布局想象力太低了。」

1. **每处 = 一个独立的大空岛**：整块岛体、不规则岛形轮廓（非矩形拼盘）、厚重底部收形（岩锥/船体），
   悬浮在**海面上方**（坠落落水即死）。一张地图 = **多个相互独立的空岛**，各有不同悬浮高度与大小，
   散布在大海上空（阶梯上升/环形/对峙等构图按关卡变化）。**反面清单**：贴水薄甲板、矩形拼盘、
   同层平铺、木板+草方块混搭——全部禁止。
2. **大块可读剪影**：平台 = 一个可读的整体（整船/整岛），底部有船体/岩锥收底，禁止混搭。
3. **层间连接可选**：斜坡/跳板/断桥按关卡节奏加（教学关少、后期多），也允许纯靠落差+跨跳；
   **动态机关不在本裁决范围**（另行立项）。
4. **大色块高可读配色**：能站/会死一眼分清；形状与色彩回到玩具级清晰（美术口径见[美术.md](../美术.md)）。

§四建关约束（武器节奏/水距配对等数值层）继续有效，但**布局形制以上面四条为准**。

**裁决 2：比例与意译总攻（2026-09-14 第五轮）**

1. **平台:角色比例必须对**：格子世界尺寸定 1 格 = 2 世界单位（角色 ≈1 单位级，岛 4-8 格才够厚重）。
2. **中心构图**：每关 3D 化要有圆心——主船/主岛居中，其余岛围绕布置。
3. **真船建模（意译不直译）**：船体有船艏曲线/舷弧/艉楼/多段甲板，不是盒子拼的剪影；船类资产走
   Blender 手作管线（AGENTS 建模分工铁律）。
4. **船上不长草**（任何途径都不行——含全局草散射）。
5. **消灭垂直硬截断**：岛缘/船体与空气的交界必须有收形（倒角/渐窄/悬挑），禁止直上直下的墙。
6. **流程铁律**：重要内容协调者亲自写亲自把关；或先做一个优秀案例（样板关）给用户过目后，
   subagent 才能按样板批量。

## 七、关间难度曲线

设计原则（引用原作实算）：难度不靠数值碾压，靠「编成规模 × 地形母题 × 武器池 × luck」四要素递进；
角色零属性差。现行两关定位为教学（L1）→ 考核（L3），蓝方 luck 走 1 → 5（原版四档 1/2/5/10 的
首档与第三档）——原 1 → 2 → 5 阶梯里的第 2 档随关卡 2（碎岛雨）删除而消失。

```curve 关间难度曲线
level,蓝方单位,蓝方luck,初始武器种数,空投池种数
L01,3,1,1,1
L03,5,5,4,3
```

布局图由 `python tools/level-design/render_layouts.py` 从各设计文档的 ASCII 块渲染
（文档是唯一真源）；本曲线图由 `python tools/level-design/render_curve.py` 从上方 curve 块渲染。

> ⚠ `docs/images/level-design/difficulty-curve.png` **仍是三关版**（含已删的 L02），当前与实际两关
> 不符——需重跑 `python tools/level-design/render_curve.py` 刷新后再引用。
