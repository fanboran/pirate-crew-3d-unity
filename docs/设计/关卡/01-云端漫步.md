## 海面与水下【提案/待定：AI 生成，待创始人过目】

### 海

- 空岛下方是一片没有海岸的清澈浅海。水面透明，岛影在水上落成一整块深青（两档硬边，像素阶梯）；
  阳光区有缓慢漂移的浅色波纹带与零星碎金；水下画面有轻微的、整块缓移的像素晃动。
- 水色几乎不染：不透明度极低，海床和水下物的固有色原样读得出——橙是橙、黄是黄。
- 海床是起伏沙丘（不是平板）：浅处透出暖沙色，越深越偏青；阳光区的沙地上有流动的焦散亮网，
  岛影里没有。沙纹沿场地轴向排成整齐的平行细线。
- **水面不直接画浪线。**水面的动态只有漂移的亮带、碎金和整块的折射晃动；影子是云台轮廓的直投影。
- 没有岸线浪花；水面的动态点缀是云瀑落水点与海面上的像素同心环涟漪。
- 云台、单位、海鸥都投硬阴影（本关专属，由场景件在运行时打开主光阴影）。
- 死亡线与水面高度不变（落水即死的判定不受影响）。

### 水下布景（不动的）

摇曳的海草、成簇的珊瑚（桌珊瑚 / 枝珊瑚）、岩簇、气泡柱、鱼骨。水下布景与生物都不描边。礁石与生物在海床上投出影子。

### 水下生物

- **描边**：水下生物不描边，与海草、珊瑚同一口径；云台、船员的线照常。
- **比例尺**：按「角色身高 1.75 m」换算（1 世界单位约 0.86 m）。真实比例的鱼在屏幕上太小，
  所以整套生物卡通化放大到「小鱼体长约 1 单位、剑鱼约 3 单位、魔鬼鱼翼展约 4 单位」这一档，
  与 1.75 m 的角色站在同一个世界里读得出、又不抢主体。螃蟹不放大：壳宽约 0.35 单位，只是沙面上的一只小东西。
- **造型**：大色块、少量硬边花纹，隔水一眼读得出「这是什么」；放大后读成菱形一类色块的不算过。

| 物种 | 读得出的特征 | 怎么动 |
| --- | --- | --- |
| 小丑鱼 / 蓝吊 / 黄吊 / 银鱼 | 橙身三道白纹 / 宝蓝身黑纹黄尾 / 通体柠檬黄 / 细梭身叉尾 | 成群巡游。群不是一块刚体：每条鱼被拉向自己的位置又互相避让，拐弯时外侧的被甩开再追回；身体被头拖着走，拐弯就弯进弯里 |
| 剑鱼 | 长吻、高帆背鳍、月牙尾 | 单独巡游，大转弯，身体慢悠悠地大幅摆 |
| 河豚 | 金黄圆身、绿斑、一身刺 | 划水、上冲、下沉；隔一阵鼓成刺球，鼓着时游不动 |
| 魔鬼鱼 | 菱形身、头鳍、细尾 | 两翼一道行波，像披风在扇；转弯侧倾 |
| 海龟 | 绿壳盾片、长前鳍短后鳍 | 前鳍交替划水，后鳍打舵；脖子左右张望、偶尔缩一下 |
| 海马 | 直立、卷尾、管吻 | 卷尾定在礁上，身体弯向张望的方向，吻慢慢扫 |
| 水母 | 粉钟、九根触手 | 一收一放：收的时候往上窜、触手张开，松的时候慢慢沉、触手收拢 |
| 章鱼 | 珊瑚红圆头、大眼、八条腕 | 八条腕轮流在沙上迈；总有一条不踩地、贴着沙面伸出去探 |
| 螃蟹 | 红壳、眼柄、双螯、每侧四条腿 | 横着走小碎步：相邻的腿不同时抬；车身随沙面起伏侧倾。有的原地举钳挥 |
| 海星 | 五腕、腕背一列浅色疣点；橙红与金黄两种 | 五条腕依次迈，腕在沙面上被拖着弯、再伸出去，翻着往前挪 |

- **动的方式**：全部是程序化动画，没有一帧手 K 的关键帧。每只生物的肢体每帧由运动学解出来——
  脚要踩在沙上、身体被头拖着走、触手被水推着走。判据是「像活的」而不是「在播循环」：脚不滑、
  肢体连续、停下来时也在呼吸和张望。
- **姿态读得出**：踩地的生物平趴在沙面上，肢体不朝上立成一束；侧扁的生物（海马）横对默认机位，
  只有背面朝镜头时它就是一根竖条。
- **栖位**：水里巡游的（鱼群、剑鱼、河豚、魔鬼鱼、海龟、水母）、沙上走的（螃蟹、海星、章鱼）、
  定住不挪窝的（海葵、海马）。同一物种的各个体节奏不同。
- **摆在哪**：云台的裙摆会挡住它后下方的水，只摆在默认机位下读得到的三片水域——西南前湾、
  东南湾、南侧前带；南侧前带两种机位下都读得到，放重点。
