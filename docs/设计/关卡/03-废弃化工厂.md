# 03-废弃化工厂

> 美术件与成图由 AI 产出、**未经创始人逐项过目**；场地布局与休闲化方向由创始人拍板
> （合并口径：只保留两套化工厂 kit 的建筑零件，布局彻底重构；**提案/待定**）。
> **编成（人数/摆位/武器/luck）与数值尚未设计**——关卡数据里的现值为占位，仅保证可玩。

## 1. 场景概念

一座停摆多年、但被**玩具化重制**的化工厂：两期厂区连成一片，用**奶油色混凝土、软蓝钢、
珊瑚锈、浅苔绿**重新上色，轮廓圆润、明暗柔和，目标是**休闲游戏的可读性与可爱感**，
不是写实废土。

- **干净大板广场**：6~8.5 m 的奶油色混凝土板，板边做 5 cm 倒角台阶；板缝是断续的
  细苔藓段（不是通长绿线），另有排水篦子与圆井盖；没有随机碎板、裂缝、污渍与散落小物件。
- **三处圆形苔藓花园**：西北角、南侧中段、东南角各一处；石砌边圈 + 沙床 + 有厚度的
  苔藓丘 + 浅蓝水洼 + 园景石 + 水边草簇。
- **多瓣圆润植被**：树冠是 12~18 个椭球瓣深度互穿（下暗上亮、可见主枝），草簇是
  “圆草团 + 3~5 片扁圆叶”，灌木 7~11 瓣；全部平滑法线，不做尖草、枯枝、藤蔓乱线。
- **有构造的连续矮墙**：勒脚、墙身分格缝、每 3.2 m 一道壁柱、三层出挑压顶、墙根苔藓带、
  壁灯；西南大门有方门柱 + 三层柱帽 + 金属门扇 + 门楣招牌 + 门卫亭。
- **干净的主厂房**：从零重建的门式刚架厂房——压型墙板 + 横向腰线 + 窗带（深色洞口内衬、
  窗框/中挺/窗台）+ 大卷帘门 + 雨棚斜拉杆 + 双坡金属屋面（24 道细肋/坡、天窗、通风器、
  檐沟/落水管、山墙百叶、检修爬梯）。
- **墙外起伏乡野**：4 m 网格的缓坡地形 + 5~6 块不同色田畴 + 田垄 + 沿田界的树篱 +
  两圈树线 + 近墙灌木/草簇 + 土路车辙 + 草捆/木围栏；最外圈是雾灰绿的远山与远景厂区
  （厂房/冷却塔/料仓/烟囱）——从场内看出去不是空海，也不是废料场。

**元素锚点**（两套 kit 的建筑零件都保留）：
- 单件 kit：四层办公楼、主厂房（补了干净双坡屋面）、冷却塔、围堰罐区、高/矮精馏塔、
  球罐、管廊、泵座。
- 六件 kit：主装置区（精馏塔/吸收塔/卧式反应器/烟囱/框架塔）、罐区（含第二座冷却塔）、
  旁楼 + 仓库、整条管廊。
- 主厂房东山墙三根出墙管经短管桥接回东侧管廊。
- 六件 kit 的「南院杂物」与两套 kit 的碎件/围栏/倒伏电杆等**已退役**：休闲化减量，
  不是遗漏。

## 2. 尺度与布局

可玩区 **96 × 68 m**（关卡坐标原点在西南角，场心 (48, 34)）；合并件总范围约 **412 × 346 m**
（含墙外起伏田野、树线与远景厂区）。俯视布局（+Z 北）：

```
 z=68 ┌────────────────────────────────────────────────────────────┐
      │      [主装置区]      [罐区]        [旁楼+仓库]              │
      │  [烟囱]                                                    │
      │      [办公楼]   ═══════ 管廊（横贯）═══════      [球罐]    │
      │                 [主厂房]  [管廊段]        [精馏塔高/矮]     │
      │  [围堰罐区]  [冷却塔]        [南院花园]            [泵座]   │
 z=0  └──────────── 连续矮墙 + 西南大门 ───────────────────────────┘
     x=0                                                        x=96
```

- **广场**：奶油大板铺满可玩区，板缝细苔藓线；三处圆形花园分别位于西北、南中、东南。
- **道路**：一条东西主路 + 一条斜插支路（干净沥青、浅色路缘），大门外接一条土路。
- **围墙**：连续矮墙（约 2.3 m，含勒脚/壁柱/三层压顶）；西南设大门（方门柱 + 金属门扇 +
  门楣招牌 + 门卫亭）。
- **墙外**：起伏田野（田畴/田垄/树篱/两圈树线）、土路车辙、草捆与木围栏；外围是远山与
  远景厂房/冷却塔/料仓/烟囱，道路从大门向西延伸。

## 5. 实机

- **像素路径试点场景**：`Assets/Scenes/Pixelart/PixelartChemPlantMerged.unity`
  （装配器 `PixelartChemPlantMergedSetup`，取景表关卡号 5；35 个 `Kit_` 槽）
  ——走真管线（物体 pass → 低分辨率域着色 → 屏幕空间描边 → 点采样上屏）。
  出图：开发包 + `-pixelartOut <目录> -pixelartLevel 5`。
- **材质/光照口径**：奶油/软蓝/珊瑚锈的化工厂域板；4 档色带；环境光 `#5C6978`
  （暗蓝灰，本场景不在 `PixelartSceneContract` 的检查清单里）、浅天空蓝背景、
  深蓝灰柔墨线；所有材质关闭“法线边压暗”，只留外轮廓；平贴苔藓/水膜 `Kit_Dec*` 不描边。
  物体 shader 带 `ShadowCaster` pass，太阳投影走真实 shadow map（树冠/檐口/管廊都有影），
  暗面由环境光托底——**先有光比，再谈色带**。
- **成图**：三档（宽 32 m / 中 13.7 m / 近 7 m）+ 描边调试图，见
  [docs/images/chemplant-merged/pixel/](../../images/chemplant-merged/README.md)。
