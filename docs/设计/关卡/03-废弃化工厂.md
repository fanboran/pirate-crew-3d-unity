# 03-废弃化工厂

> 美术件与成图由 AI 产出、**未经创始人逐项过目**；场地布局与休闲化方向由创始人拍板
> （合并口径：只保留两套化工厂 kit 的建筑零件，布局彻底重构；**提案/待定**）。
> **编成（人数/摆位/武器/luck）与数值尚未设计**——关卡数据里的现值为占位，仅保证可玩。

## 1. 场景概念

一座停摆多年、但被**玩具化重制**的化工厂：两期厂区连成一片，用**奶油色混凝土、软蓝钢、
珊瑚锈、浅苔绿**重新上色，轮廓圆润、明暗柔和，目标是**休闲游戏的可读性与可爱感**，
不是写实废土。

- **干净大板广场**：6~8.5 m 的奶油色混凝土板，板缝是 18~30 cm 的细苔藓线；没有随机
  碎板、裂缝、污渍、路坑与散落小物件。
- **三处圆形苔藓花园**：西北角、南侧中段、东南角各一处，浅沙圈 + 苔藓主体 + 浅蓝水洼，
  花园里是圆润草丘与少量小花。
- **圆润植被**：树冠、草丘、灌木一律高分段圆球/圆顶（16+ 段、平滑法线），不做尖草、
  枯枝、藤蔓乱线。
- **连续矮墙 + 干净大门**：墙顶浅色压顶、墙柱圆润，墙根一条苔藓带；没有断壁、锈痕、
  残基与废料封口。
- **墙外浅绿田野**：两排圆树、四面浅色远景厂房、三座料仓、几处缓草坡；从场内看出去
  不是空海，也不是废料场。

**元素锚点**（两套 kit 的建筑零件都保留）：
- 单件 kit：四层办公楼、主厂房（补了干净双坡屋面）、冷却塔、围堰罐区、高/矮精馏塔、
  球罐、管廊、泵座。
- 六件 kit：主装置区（精馏塔/吸收塔/卧式反应器/烟囱/框架塔）、罐区（含第二座冷却塔）、
  旁楼 + 仓库、整条管廊。
- 主厂房东山墙三根出墙管经短管桥接回东侧管廊。
- 六件 kit 的「南院杂物」与两套 kit 的碎件/围栏/倒伏电杆等**已退役**：休闲化减量，
  不是遗漏。

## 2. 尺度与布局

可玩区 **96 × 68 m**（关卡坐标原点在西南角，场心 (48, 34)）；合并件总范围约 **232 × 186 m**
（含墙外绿色田野）。俯视布局（+Z 北）：

```
 z=68 ┌────────────────────────────────────────────────────────────┐
      │      [主装置区]      [罐区]        [旁楼+仓库]              │
      │  [烟囱]                                                    │
      │      [办公楼]   ═══════ 管廊（横贯）═══════      [球罐]    │
      │                 [主厂房]  [管廊段]        [精馏塔高/矮]     │
      │  [围堰罐区]  [冷却塔]        [南院花园]            [泵座]   │
 z=0  └──────────── 连续矮墙 + 西南大门 ───────────────────────────┘
     x=0                                                        x=96
```

- **广场**：奶油大板铺满可玩区，板缝细苔藓线；三处圆形花园分别位于西北、南中、东南。
- **道路**：一条东西主路 + 一条斜插支路（干净沥青、浅色路缘），大门外接一条土路。
- **围墙**：连续矮墙（2.2 m）+ 圆墙柱；西南设干净大门（双圆门柱 + 横梁 + 黄漆牌）。
- **墙外**：浅绿草地、两排圆树、缓草坡、四面远景厂房、三座料仓；道路从大门向西南延伸。
