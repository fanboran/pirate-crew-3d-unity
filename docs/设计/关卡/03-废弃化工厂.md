## 1. 场景概念

一座停摆多年的化工厂——锈蚀的塔罐管廊、掀了顶的厂房、碎窗的办公楼,被荒草和废桶接管。
冷却塔与烟囱是远距地标(落点定位);罐区围堰是天然的掩体沟;办公楼是室内近战笼。

[tools/blender/scene/chemplant/README.md](../../../tools/blender/scene/chemplant/README.md)「场地布局」。

## 3.5 实机观感

**实机图**:[docs/images/pixelart-path/r16/](../../images/pixelart-path/r16/README.md)(七张 + 关卡 1 交叉验证;r14/r15 为中间轮)

**判据全绿**(块边长 2 / 墨线在写缓冲 / 光照未旁路 / 场地在场 78.3%)。打光口径:
**实时投影必须打开**(投影默认关是「没光影」的根源)、主光中性、环境光去藏蓝;
配色限制已从管线删除;弧面平滑+细分(详见 r16 图集 README)。
像素路径试点场景 `Assets/Scenes/Pixelart/PixelartChemPlant.unity`(编辑器装配器搭建),
出图命令 `-pixelartOut <目录> -pixelartLevel 4`。

**实机暴露过的两处美术问题**(Blender 预览看不出,读数见 r14 图集 README):
① 冷却塔的周向棱槽在三档色带下读成棋盘格/镂空壳 → 壳体光滑 + 外凸细肋条 ×16;
② 围栏亮锈橙铺长杆把场地染橙 → 压到暗锈。若判图不过,
优先在这两条上继续调(调参位置见 kit README)。
