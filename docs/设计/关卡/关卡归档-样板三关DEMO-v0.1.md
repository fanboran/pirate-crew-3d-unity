## 一、旧版是什么、为什么存在

2026-09-14 用户裁决（ShowcaseLevels.cs 8590ba7 版:47-49）：关卡号 1/2/3 覆盖为
「云朵场（低模，高低错落）」「双大帆船并列（结构画全）」「山包大岛 + 超美空岛」。
定位是 **DEMO v0.1 美术样板**——目的是验证三条美术方向（低模云 / 程序化船 / 空岛），
不是玩法设计：编成、武器池、luck 都是从旧一代瓦片竞技场顺手带来的占位值，
没有体验目标与难度曲线可谈。入口也只有 `-artReviewLevel 1-3` 出图与 Battle 直玩的兜底，
常规 UI 不可达（交接与恢复指南 §28）。

## 三、带走的教训

1. **美术样板不能长期兼任关卡内容**——占位编成/武器池会伪装成"已设计"被反复复读；
   本轮起玩法数据必须来自设计文档（管线阶段 2 的产物）。
2. **程序化船体放样（放样船壳 + 帆 + 炮的 kit 组合）在低模风格下达不到用户审美线**，
   船类资产此后一律走 Blender 手作管线（建模分工铁律 ②）；SceneKit 目录下现存的
   Flagship.fbx / Dock.fbx 是该管线的试点产物，尚未接入任何场景。
3. 逻辑高度场 + 烘焙摆位表（糖豆人式资产架构）在本轮重构中**保留**——它让"改玩法数据"
   与"重烘美术"解耦，正是关卡管线阶段 3/5 能分开走的架构基础。
