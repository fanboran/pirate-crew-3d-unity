# 参考游戏逆向 · 海盗军团抢宝藏 —— 动态试玩观察

> 静态反编译分析见姊妹篇《参考游戏逆向-海盗军团抢宝藏-静态.md》（ffdec 反编译 AS2）。本篇记录**运行时观察**：菜单流程、交互死点、Ruffle 运行日志与 swf 字符串挖掘。
> 原版身份：Nitrome《Mutiny》(2008) 汉化版（swf 内请求 `www.nitrome.com/php/retrieve_scores.php` 证实）。

## 1. 试玩环境与方法

- 运行环境：Ruffle 0.6.0（wasm，wgpu-webgl 渲染），本地 `http.server` 8000 端口
- 驱动方式：headless Edge + CDP 远程调试（端口 9527），工具链在 `external/tools/`：
  - `cdp.mjs`——CDP 单动作控制器（open/shot/click/drag/move/keypress/eval/console/dimensions）
  - `ocr.ps1` + `prep_ocr.py`——WinRT OCR + 裁剪放大二值化预处理（像素艺术字识别率低，仅辅助）
  - `color_blocks.py`——canvas 区域量化色块连通域分析（找按钮/人物结构）
  - `imgdiff.py`——前后截图差分（>15% 判定界面切换，3-6% 为海面动画噪声）
- 无视觉模型可用（当前会话不支持图片输入、云端视觉 API 够不到 localhost），全部靠上述"盲操作+差分取证"

## 2. 菜单流程实测（index.html 版坐标，canvas 874×656 @ 页面(183.5,105)）

```
主菜单（海面+一排海盗人物）
  ├─ PLAY    (620,440) ✓ → 1P/2P 选择界面
  ├─ SCORES  (620,480) ✓ → 排行榜界面【死点：等 nitrome.com LoadVars，本地 CORS 失败卡死，无返回按钮】
  ├─ HELP    (约620,520) （推断，未验证）
  └─ CREDITS (620,560) ✓ → 制作名单（OCR 认出 CHRIS BURT 等 Nitrome 成员名）
1P/2P 选择（提示语 OCR："CLICK ONE OF THE BUTTONS BELOW … 1 PLAYER … COMPUTER OR … FRIEND"）
  └─ 【死点：全部候选位置点击/hover/键盘均无响应，见 §4】
```

- 主菜单四按钮竖排于中部偏下，按钮与海面背景同为像素风、无明显色块差，靠**逐层点击+差分**定位（620,480 首次命中的其实是 SCORES 不是 PLAY——先后进了 SCORES 与 CREDITS 才反推出 PLAY 在 y≈440）
- SCORES 界面结构：深灰背景 + 顶部标题带 + 两侧对称人物 + 底部信息条，点击无任何响应

## 4. 交互死点记录（Ruffle 0.6.0 兼容性问题）

1. **SCORES 排行榜界面卡死**：Ruffle console 报 `Error during LoadVars load of "http://www.nitrome.com/php/retrieve_scores.php": FetchError`（CORS 阻断）。界面无任何可点元素。已尝试 `allowNetworking:'all'` + 页面 fetch hook mock nitrome 域名返回 200——**仍卡死**（LoadVars 内部失败路径可能仍走 onFail 而游戏未处理）。
2. **1P/2P 选择界面按钮无响应**：提示语明确"click one of the buttons below"，但已扫描候选位置（顶部两牌匾/左右人物/中部多带/行扫 y=480）与键盘（Space/Enter）均无界面切换；hover 亦无高亮差分。放开 `allowScriptAccess:true` 的 debug runner 下依旧。**待静态反编译 OnePlayerButton 的激活条件/onRelease 脚本定位根因**（怀疑：NitromeGame 桥初始化未完成导致按钮禁用，或 Ruffle 对该帧 attachMovie 按钮的 hitTest 实现缺陷）。
3. 已验证可交互：主菜单 PLAY/SCORES/CREDITS 按钮点击均有效（排除输入映射整体故障）。

## 6. 对 Unity 版的移植启示（初稿，静态篇完成后合并修订）

1. 武器清单以本清单为准（17+ 种），Godot 版 6 种是子集——M2 SO 数值资产按全集建表，分批实现
2. 回合状态机命名直接对照 Controller 的方法族（startTurn/finishTurn/isTurnComplete/continueTurn/totalTurnsTaken）
3. 关卡数据内嵌（EmbeddedLevels）→ Unity 版走 ScriptableObject 关卡资产
4. 原版对网站环境的依赖（解锁/分数）在 Unity 版天然不存在，用本地存档替代
5. 自定义光标（CustomCursor）、范围圈（rangeCircle）、瞄准虚线（dottedLine）是核心交互反馈，M2 的 UI/瞄准系统需对应实现
