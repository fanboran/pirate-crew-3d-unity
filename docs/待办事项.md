**M1 沉淀的环境经验**（详见 AGENTS.md 注意事项）：
- batchmode 命令必须显式带 `-projectPath`（缺失会打开 EditorPrefs 最近工程，本次曾导致僵尸进程锁工程）+ 当前环境统一加 `-nographics`
- EditMode 测试 asmdef 必须 `includePlatforms:["Editor"]`；PlayMode 测试 asmdef 留空（全平台）；程序集引用**只写 GUID 或只写 name**，双写会 duplicate
- `SceneLoader` 契约：过渡（含淡入淡出）期间的新切场景请求会被忽略——调用方/测试需等 `IsLoading == false`
