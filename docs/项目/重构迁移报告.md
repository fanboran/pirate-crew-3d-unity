## 3. 分轨交付明细

### 3.1 核心地基（轨道 A）

- **强类型事件总线**：`EventBus` 从 `Action<object>` 改为 `Publish<T>(key, payload)` / `Subscribe<T>(key, handler)`，
  载荷类型不匹配 = **编译错误**。内部按载荷类型路由，空载荷用 `NoPayload` 哨兵。
  **热路径零分配**：快照按订阅变更失效重建（不再每次 `Publish` 都 `ToArray()`），有测试证明
  （`GC.GetAllocatedBytesForCurrentThread()` 前后差为 0）。
- **事件契约登记表** `Core/Events/EventCatalog.cs` + 三道闸门（编译期泛型 / 运行期对拍 / 反射测试）。
  全仓 184 处调用点逐个改造，**唯一逃生口**是 `AudioService` 的动态订阅表（`SubscribeDynamic`，代码里写明代价）。
- **唯一入口** `Core/GameEntryPoint.cs`：全仓唯一 `[RuntimeInitializeOnLoadMethod]`，负责
  ① 清静态 ② 解析命令行 ③ 保证服务宿主存在（从任意场景按 Play 也能跑）。
- **组合根收口**：`Core/Services.cs`（显式服务注册表）+ 模块用 `[GameBootstrap(phase, order)]` 声明接线入口。
  从 UI 层 `Awake` 里接线、各模块自挂初始化回调的隐式层全部收敛。

### 3.2 关卡数据外化（轨道 B）

- **数据模型三层**：纯 C# 载荷（字段真源）← SO 宿主 ← 清单（`Resources/LevelCatalog.asset`）。
  载荷与宿主分开是为了让「资产内容 == golden JSON」这条判据能在**没有 Unity 的无头环境**算得出来。
- **资产**：8 张海图 + 3 张样板关 `.asset` + 11 份 `_golden/*.json` 文本锚点。
- **迁移器** `Editor/Levels/LevelDataMigrator.cs`（golden JSON ⇄ 资产双向，确定性：连跑两次逐字节一致）；
  **校验器** `Editor/Levels/LevelAssetValidator.cs`（连通性/出生点/武器 id/尺度）。
- **旧 C# 硬编码表已删除**（`WorldMapCatalog` 手写表、`ShowcaseLevels` 高度场）——留着会变成
  "跑一次迁移器就静默回退内容"的陷阱。回归锚点是 golden JSON，不是旧代码。
- 内容来源判定抽成 `Battle/Levels/LevelSourceResolver`，`BattleController` 不再是内容路由器。

### 3.3 运行期查找清退（轨道 G）

- 热路径轮询清零：`BattleCameraController` 每帧回退扫 `AimThrowController`（3 处）、
  `WaterSimulationDriver` 的"扫全场找最亮平行光 + 负缓存 + 重扫"（整段删除）、`FxRoot` 的死代码扫描。
- 改为 `[SerializeField]` 注入 + 一次性解析；装配写入 `Editor/BattleLookupWiring.cs`（幂等、字段名漂移报错），
  **接线由 PlayMode 断言钉住**（区分"装配接线"与"兜底也能跑"）。
- 闸门 `Editor/SceneLookupAudit.cs`：扫全仓并分类（运行时/工具），白名单外命中即退出码 1。
  剩余 7 处逐条登记理由，报告落 [审计/专项/运行期查找清退报告.md](../审计/专项/运行期查找清退报告.md)。

### 3.4 美术管线工业化（轨道 D）

- **全局调色板**：59 色 / 19 族，`Assets/Data/Palette/pirate_palette.json` 是唯一真源（LF、规范文本），
  `.asset` 是派生。族内按 OkLCH 明度升序且连续声明，校验器强制。
- **量化工具** `tools/palette/palette_tool.py`：OkLab 加权距离最近邻（不是 RGB 欧氏距离——RGB 距离会毁明度层次），
  可选 Bayer 4×4/8×8 有序抖动，**逐字节确定性**（同输入同输出，已用 hash 证明）。
- **像素纹理导入管线**：`Editor/Art/PixelArtTexturePostprocessor.cs` 对约定目录强制 Point / 无 mip / 不压缩；
  **只对新增资产生效，不回溯改存量 55 张贴图**（否则会破坏现有画面且无法人眼验收）。
- **Blender 导出模板三件** `tools/blender/pixel/`：平滑法线烘顶点色（反壳描边必需）、顶点色量化、
  纹素密度 ±0.5% + Jacobian 校验。已对真实 FBX 实跑。
- **写实栈退役**：全屏 Sobel 描边 Feature 从两档 Renderer 摘除；Volume 六件套全部 `active:0`
  （Bloom/Vignette 是邻域算子，降采会量化成块状辉光；Tonemap/CA/WB 等逐像素算子与点采样可交换，
  停用理由是锁板纪律）。**Depth/Opaque 保留开启**——水面 shader 仍在采样，关掉水面当场变黑
  （依赖关系已写进 `Assets/Art/Rendering/README.md`）。
- **材质工厂** `Editor/Art/ToonMaterialFactory.cs`：扫描/预览/分批换栈，**硬拒"全量换血"入口**。

### 8.4 契约与守它的东西

| 契约 | 守它的 |
| --- | --- |
| 折叠态（0 裸对象 + 1 个实例 + 0 覆盖） | `ScenePrefabCollapse.Verify`（CLI `-collapseMode verify`）+ EditMode `SceneAssemblyContractTests`（加性开场景，用引擎自己的 `HasPrefabInstanceAnyOverrides` 判定） |

### 8.5 本轮引入的纪律（写给下一个改装配链的人）

1. **装配步骤函数绝不终止进程。** 终止进程是顶层 CLI 入口的职责。一个会调
   `EditorApplication.Exit` 的步骤无法被任何流水线组合——它把"我这一小步跑完了"说成了
   "整个批处理到此为止"，而且不报错、不留后手，只能靠人盯着日志发现"后面怎么没了"。
2. **自绘件一律顶级类 + 独立文件。** 嵌套 MonoBehaviour 不会编译报错，
   代价在序列化环节才付：Prefab 存不下、场景重载后组件消失。
3. **"算不算覆盖"问引擎，不要自己在 YAML 里列白名单。** 引擎写实例时总会带几项等值的默认项，
   文本白名单会把它们误报成覆盖；而 TMP 那类"运行期解析后写回实例"的值是真覆盖，
   文本白名单又看不出来。`HasPrefabInstanceAnyOverrides(..., includeDefaultOverrides: false)` 是唯一权威。
