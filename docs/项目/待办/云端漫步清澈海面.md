## 详情

### 1. 鱼身网格重做（创始人 2026-11-24 反馈）

现行鱼身是 6 顶点椭球（8 面），放大后读成一块菱形。重做要点：加断面（吻 / 前段 / 中段 / 后段 /
尾根），断面取六边形，身高大于体宽（侧扁），保住尾鳍 / 背鳍 / 腹鳍与墨线壳，仍是低模平面着色。

改完要同步的地方：跃水鱼的相对体型（`mod_life.FISH_JUMP_SCALE`）、云海.md §3 的尺寸表；
贴床净空用渲染器世界包围盒算，自动跟随，不用改。

### 3. 取色链的双重转换（全场景影响）

`PixelartMaterialFactory.TryGetAlbedo` 取源色时 `GetColor` 返回线性值，随后被原样 `SetColor`，
等于多转了一次 sRGB→线性。影响所有经工厂配方的材质：实际渲染色比 Blender 色卡上写的更深更饱和
（例：`Cloud_FishOrange` 色卡 `#FFA06E`，渲染出来是 `(255,91,38)`）。

- 云海家族里只有墨线色与海床沙色增益在烘焙器里另配，不受影响。
- 修它会连带改变全场景（云、道具、单位）的配色，须创始人裁决后单开任务。

### 4. 浅色鱼配色（观感提案）

鱼群隔水可读目前靠墨线轮廓 + 放大。骨白、米黄的鱼与水下沙面明度接近，珊瑚橙的鱼最跳。
现行群主色「黄白为主、橙做点缀」是按会吃红通道的旧水体定的；清澈水是平色混合、不吃红，
候选做法是把群主色往珊瑚橙偏（`mod_sea.SCHOOL_DOM`）。等创始人实机看过再定。

### 5. Blender 分件预览图未同步

`docs/images/cloudsea/` 里的分件预览（`cloudsea_sea-*` / `cloudsea_life-*` 等）由
`preview_module.py` 单独出图，海床重雕与鱼群放大后没有重渲；总装预览
`cloudsea-{front34,side,top}.png` 随本次改动由 `assemble_cloudsea.py` 重渲过，是同步的。
另外 Blender 的 FBX 导出不是字节确定的（对象 UID 与时间戳每次不同），重跑总装后
Unity 下次启动会重新导入 FBX——几何没变时不需要重烘，子资产 ID 按名字散列、不随之变。
