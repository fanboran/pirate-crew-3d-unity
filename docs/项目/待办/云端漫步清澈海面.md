### 2. 取色链的双重转换（全场景影响）

`PixelartMaterialFactory.TryGetAlbedo` 取源色时 `GetColor` 返回线性值，随后被原样 `SetColor`，
等于多转了一次 sRGB→线性。影响所有经工厂配方的材质：实际渲染色比 Blender 色卡上写的更深更饱和。
云海家族里只有墨线色与海床沙色增益在烘焙器里另配，不受影响。

修它会连带改变全场景（云、道具、单位、水下生物）的配色，须创始人裁决后单开任务。

### 3. 只在默认机位下验证过

出图与 GIF 都是默认机位（特写只改了中心与可见范围，方向不变）。海星的朝向（画面右方 135°）、
海马的侧身是按这个机位定的；转到别的角度后的观感，以及镜头拖动 / 旋转时的像素格稳定性
（PostLine 的亚纹素补偿未接线，见云海.md §7），要实机确认。

### 4. Blender 分件预览图未同步

`docs/images/cloudsea/` 里的分件预览（`cloudsea_sea-*` / `cloudsea_life-*` 等，由 `preview_module.py`
单独出图）还是海床重雕与生物重做之前的画面；总装预览 `cloudsea-{front34,side,top}.png` 是同步的。
生物重做后也没有对应的分件预览。

交界线不动。机制都在（`CloudSeaShadowProbe` 的行波偏移），要不要重新打开、开多大，待创始人看完现行
出图后定。
