# 选中头顶面板 + 镜头居中策略

> 一句话现状：两条同批的选中/镜头口径改动——①选中单位时头顶弹出图标面板（兼作选中标记）；
> ②选中**不再**把镜头居中，改为「开始操作且该操作需要以角色为视角中心时」才居中。

## 详情

### ① 头顶选中面板（含跳跃 / 结束本回合 图标钮）

- 选中角色时在其**头顶弹出一个小面板**，内含两枚**图标按钮**：「跳跃」与「结束本回合」——
  同时承担「当前选中单位」的标记职能（地面八角框 `SelectionOctagon` 已落，二者可并存：
  脚下方框标位置、头顶面板给操作入口；是否保留八角框待观感定）。
- 图标是新增美术件（走 IconBakeTool 像素原生重绘），随「UI 图标丰富」远期线一起排产；
  面板本体布局/命中区先按占位图标做。

### ② 镜头居中策略（改两态现役行为）

- **现役**：选中单位即平滑环绕到该单位（两态重构的 selectionPushIn，镜头全目标化 + 指数平滑；
  瞬切只在开局落位）。
- **新口径**：**选中只标记、不迁镜**；开始操作后按需居中——判断权在操作模组：
  - 需要「以该角色为视角中心」的模组（标准投掷的瞄准、海鸥放飞等）→ 操作开始时平滑居中；
  - 全场型武器（潮汐巨浪等）与放置类中不需要对准的 → **镜头完全不动**；
  - 取消操作/执行落定后的回收路径待定（回自由镜头还是停在原地）。
- 落点：`BattleCameraDriver` 的选中推进逻辑 + 相机行为契约（现役 #9/#B17 口径随动）；
  逐武器/逐模组的「是否需要居中」属模组参数，挂 `OperationModule` 体系。
