# palette-分域色板体系

> 一句话现状：创始人 2026-10-02 提出按域/按关组织色板（限色不按全局总数），方向已定、体系未设计；
> 本任务给出分层提案，待创始人裁决后再动真源结构。**【提案/待定】**

## 详情

### 背景与裁决链

- 创始人 2026-09-29 裁决取消「全局 32~64 色锁板 / 纹理量化入板」机制（[美术风格指南](../../设计/美术/风格指南.md) §3.2），
  色彩纪律改为逐资产在源的槽位色表（权威：`tools/blender/scene/style_tokens.py` 的 `SLOTS`）。
- 创始人 2026-10-02 追加方向（原话要点）：限色单位最多到「一个地图内」——不同地图风格可能很不一样；
  质疑「角色、海洋、地形的色板分开维护」或「每关一板 + 角色 等跨关共用板」哪个更合理；
  组织结构细则（明度/连续）授权管线自行处理（已在 [调色板.md](../../技术/资产管线/调色板.md) §1 落地为阶梯族规则 + 语义族豁免）。

### 分层提案（【AI 提案·待创始人裁决】）

**共享核心板（跨关共用）** + **域板（每关 / 每生物群系）**两层：

| 层 | 内容 | 理由 |
| --- | --- | --- |
| 共享核心 | `INK` 墨线、`UI` 族、`FACTION_RED/BLUE`、`SKY_*`、`WHITE_HOT` 等 | 辨识一致性：同一阵营红、同一 UI 灰、同一条墨线跨关不变，玩家不重学 |
| 域板 | 地形四族（`SAND/ROCK/WOOD/GRASS`）与 `SEA` 的**风格变体**——沼泽关 WOOD 偏绿、火山关 ROCK 偏黑、每个海域有自己的 SEA 阶梯 | 风格随地图分化，这正是创始人「不同地图风格可能很不一样」的落点 |

- 资产实际可用的色 = 共享核心 + 所属域板的合并视图；「单关同屏色数」若要约束，走**美术观感纪律**（出图验收人查），工具不强制——量化锁板机制已取消，不再造回来。
- `UI` 令牌取色路径不受影响（UI 属共享核心），[UI九宫格.md](../../技术/资产管线/UI九宫格.md) 的 tone 表继续从共享核心取。

### 落地面（裁决后按序做）

1. 真源结构：单文件分 namespace 或分文件（`pirate_palette.json` + `palette_<域>.json`），`palette_tool.py check/fmt/strip` 适配；
2. Unity 侧：`PaletteAssetBuilder` 构建合并视图（共享 + 当前域），`PiratePalette.asset` 消费方不感知拆分；
3. Blender 侧：`style_tokens.py` 的 SLOTS 按域引用色值（kit 脚本不感知）。

### 先决

等关卡风格真正分化（现役加勒比一套打天下）再动真源，避免过早抽象；触发点 = 第二种地形风格进生产的立项。
