# 出生站位单源化（第 2 关）

> 一句话现状：像素化着色路径本体早已收官（唯一渲染路径，三关与游戏本体全接，口径权威
> [渲染管线.md](../../技术/渲染/管线/渲染管线.md)）；本条是它唯一的遗留活——第 2 关「可见表面 = 可站立表面」的兑现。

## 详情

- [ ] **第 2 关出生站位两步走（创始人已裁「类体素」方案）**：空岛面是**穹顶**（岛根 y=13.3：
      崖沿 13.3 → 中心 14.65），逻辑高度场是**平顶 14.0**——按现几何逐点算，9 个出生点偏差
      **−0.11 ~ +0.69 m**（多为 +0.2~0.36，即脚被草皮埋住/悬空）。裁决不变式「可见表面 = 可站立
      表面」（两者水平投影必须重合）；第 1 关已由 `IslandShellGeometry` ±0.02 保证，穹顶是唯一破坏者。
  1. **短期**：装配器已算好的穹顶出生点表（`FloatingIslandSpawnTable`，逐点贴地 Y 至今只打
     日志未接线）接进出生链，悬空即消；
  2. **中期正解（类体素）**：烘焙视觉时同步采样逐格高度写入 LevelData（全米 `TerrainShape`
     schema，与地图全米统一口径衔接）——微体素台阶口径与 t3ssel8r 引擎同构（草丛几何已用其
     口径），渲染可保留平滑壳也可离散成台阶（台阶立面高度取整艺术像素，30° 俯角 2:1 对齐更干净）。
     **警示**：物理/raycast 贴地只能当短期补丁——投掷弹道、爆炸遮蔽、视线判断仍吃逻辑高度场，
     单靠贴地会出现「看着炸得到、判定炸不到」的视觉与逻辑错位。

  - 内线归属（v3 蓝本 §8 待定点 3）：外轮廓与连通域内线现役并存生效，就此定案还是改走纹理
