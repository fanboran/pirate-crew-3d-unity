# 水体表现口径

> 一句话：水体在像素化路径的材质口径待创始人裁决，一次裁决收敛瀑布背光、海面重构、环境水体构想三处。

## 详情

### 核心裁决（口径冲突，须先裁）

- **现役口径**：[像素海面](../../技术/渲染/管线/像素海面.md) 两条现役裁决——
  「水体**不透明**」（半透明 + 点采样 = 与地形色混出板外色）、「**不做白帽粒子**」（其 §4 明确不做清单）。
- **创始人构想**：浪打沙滩/水泥柱的受力反馈、白色泡沫、半透明感、把真实水体动态做成像素风格化
  （记录于 [场景.md 环境表现](../../设计/场景.md)；[像素海面 §5.1](../../技术/渲染/管线/像素海面.md)
  已开「提案/待定」小节登记这处冲突）。
- **根因轴（两场景一致）**：`PixelartContentConverter`（战斗场景运行时）把世界内容——包括配方里
  名义半透明的水/沫/云——统一转成**不透明受光像素材质**；调试场景的
  `PixelartStageKit.SwapMaterials` 派生路径同样转不透明。动这条口径，Battle 与调试场景观感连带同变。

### 落点①：瀑布背光读作深色板

天空之岛三挂瀑布逆着主光的水帘读作深色板（实测色 `(13,42,46)` ≈ 水反照率 × 环境光档），没有水感；
经全图建模 Bug 排查确认为**唯一遗留观感项**（破面/漏光/碎片均为零），Battle 与调试场景观感一致——
口径代价，非场景装配缺陷。两案待裁：

1. **把水从「转不透明」里豁免**（参照 `IsEffectMaterial` 的特效豁免口径给水体单独放行）——
   瀑布从任何方位读作水色半透，黑板消失；代价：水面失去明暗档，且调试场景观感连带改变。
2. **只抬水色亮度**（`FloatingIslandMaterials` 水配方基色 `#55CFE4` 提亮）——
   治标，黑板变浅板，不动架构。

成图基线不入库，观感复核时按 `BattleHudScreenshot` 截图链重拍即可复现。

### 落点②：Battle 海面系统性重构

像素化路径下 Battle 海面是**平色替身**（`Water_Ocean` 材质取不到本路径源色，按设计不画，日志已降 Warn），
无波纹/岸线/泡沫等表现；技术方案与实现清单见 [像素海面](../../技术/渲染/管线/像素海面.md)。

- 已并入子项：**海面色带 2→3 档 A/B**——工厂侧警告 3 档可能把平色打成条纹
  （`PixelartMaterialFactory.cs` 的 `SeaBandCount` 注释），改档须出图对照。
- 范围：待创始人开线时圈定。

### 落点③：环境提案的水体表现构想

创始人环境构想中的水体块（浪拍受力反馈/白沫/半透明）即上文构想侧的完整内容，裁决后转为可施工设计；
半透明读感的实现建议优先走 [像素海面 §5.1](../../技术/渲染/管线/像素海面.md)
的岸线带两色带伪造路线（保锁板），而非真 alpha 混合；拍击反馈是否重开白帽粒子随核心裁决一并定。

### 一次口径裁决，三处收敛

核心裁决定案（维持不透明还是转半透明、白沫/拍击做不做）后三处一并收敛：
落点①选定豁免/抬色方案，落点②的泡沫与半透明表现层定稿，落点③构想转施工；
裁决结果回写 [像素海面 §5.1](../../技术/渲染/管线/像素海面.md) 与本条各落点。
