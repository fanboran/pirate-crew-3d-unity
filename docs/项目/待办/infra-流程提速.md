## 详情

**【流程提速】Unity 协作摩擦收账**（走查批次被 Unity 冷启动、缺常驻驱动、残锁卡出的账）——

① **驱动开着的编辑器**执行菜单/装配（不再要求关编辑器）：工程里 `McpBridgeKick` 已埋 stdio bridge
自启垫片，但**目标实现改走 Unity CLI**——官方 `Unity MCP Server` 已被标记废弃，明示改用 CLI；
② **单入口编排**：一次 batchmode 启动串跑多件装配（字体重建 → Battle 管线 → 菜单场景），
省下多次编辑器冷启动；
③ **编辑器退出补清锁兜底**（残锁连害两轮）。

**为什么要做**：单次 Unity 冷启动 ≈2.5 分钟，而用例本体只有十几秒——见该文档 §1 的实测表。
