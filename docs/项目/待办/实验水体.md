  范围 W1–W3；与像素海面 F1–F7 为姊妹线，不动 Battle 现役。
- **主参考**：[Sandcastle 水体逆向](../../技术/渲染/调研/Sandcastle水体逆向.md)（§4.1 水 PS

  **实施设计**：[实验水体](../../技术/渲染/管线/实验水体.md)；
  **交接**：[交接/实验水体](../交接/实验水体.md)（第八/九轮根因清单与方法论教训）。
- **已落地**：SWE 六 kernel + 纯 C# 规则单源（harness 全绿）+ 水/沙 shader + 装配器；
  长涌浪主份波列（λ40 m）+ 浅水色散 + 带内速度配对；**深度比例潮位松弛（权重∝水深，
  UpdateAmount 同构）+ Shapiro 网格滤波（ε=0.08）+ 速度阻尼 0.02**——涌浪跨域、波包
  ~9s 向岸、列项明暗调制峰值 30–42%；水底波影=沙侧「原值阴影×exp(−0.721×水深)」+
  闪沙项；碎金=细节法线×pow1500×原值阴影；出图必带
  `PC3D_CAPTURE_SRGB=1 PC3D_WATERLAB_TIME_SCALE=30 PC3D_CAPTURE_MIN_SIM_TIME=46`
  （截图链等模拟稳态才开拍，转储 36–44.4 s 细采样；`$TEMP` 旧转储先清）。
- **余项**：波组节奏（四列互拍的平静窗 vs 原作单涌浪连续 bore，次级列幅可削）、
  近岸奶白与影带深度的同一旋钮（alpha 下限/σ_red）、ambient 配比、主光阴影未配置——
  皆待创始人 Play 验收后裁决；W4 GPU indirect 浪花粒子未开工（原作白水=Whitewater
  粒子，水体 PS 无泡沫项）；像素化收口另裁。
