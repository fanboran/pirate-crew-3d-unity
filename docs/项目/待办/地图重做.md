## 详情

### 创始人裁决（2026-10-23）

- **关卡只有一个概念**。不存在「样板关 / 海图」两种关卡——那是 09-18~09-22 重构层积出的实现分叉（`23d3d4d2` 样板三关 → `c4458eb6` 收敛世界图单通道 → `a47e53ed` 数据外部化时分出两个目录），从未有过产品裁决背书。「样板」一词系创始人随口所说，被代码固化为 `ShowcaseLevels` 分类。
- **单一数据目录**。全部关卡数据住 `Assets/Data/Levels/`；`Assets/Data/WorldMaps/` 已删。
- **重做本意**：更新生成方法、把 Blender 加进环节，重画那 8 张图（`b012ff05` 删除时的内容太空：14-46 个地形件摊在 150-280u 跨度）。重做的图**就是普通关卡资产**，与现有 4 张同管线。原 kit 运行期拼装通道（`WorldMapComposer` 等）已整链退役；若重做想借「零件拼装」提效，做成**生成期工具**（生成时组装出完整关卡资产），不再保留运行期第二装配通道（提案/待定，重做开工时定）。
- **星级 / 战役结算 / 跨关卡进度 = 占位冻结**。创始人从未设计过星级与跨关卡玩法；`Campaign/*`、结算弹窗、星级 UI 属占位实现，冻结不动：不投新功能、不当设计依据引用，待创始人设计跨关卡玩法时再定去留。
