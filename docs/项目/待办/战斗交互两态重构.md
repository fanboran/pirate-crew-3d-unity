## 详情

**裁决（创始人 2026-10-03）**：

- 两态制取代三模式：`自由镜头`（未选中，编辑器飞行式相机）⇄ `选中`（唯一单位为视野中心、可环绕）；
  选中态内子状态 浏览 → 操作中（模组激活、相机锁定）→ 执行中（跟随）。
- 操作模组制：标准投掷模组先行（A/D 方向角、W/S 仰角、Space/Shift 力度、回车/屏幕确认钮执行），
  预留轨道轰炸等专用模组接入位。
- 投掷数值**米制重立**：退役 Flash 0.25/twangMax 换算口径；常量单源 `StandardThrowRules`
  （提案 MaxLaunchSpeed=30 m/s、LaunchGravity=−30 m/s²、ThrowOriginHeight=1.0 m）。
- 未行动可换人；ESC 矩阵唯一裁决表（确认弹窗>暂停>操作中>已选中>自由镜头）；P 键常驻暂停。
- 预览重做：落点终止弧线、不入地、落点标记恒显、起点抬至投掷手高度。
- 相机平滑禁瞬跳（位姿全目标化 + 指数平滑，唯一瞬切点=开局落位）。
