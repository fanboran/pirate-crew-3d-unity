# 渲染·叠加档不判遮挡（统一处理）

> 一句话现状：叠加档（Overlay 相机、全分辨率）画 FX / 投掷预览 / 危险虚线时**不做深度测试**
> （其自建深度缓冲为空），崖后的爆炸会画在崖前——遮挡关系错。创始人 2026-10-09：单开一条统一处理，「得判断」。

## 详情

- **现象**：叠加档效果件画在像素化成图之上、全分辨率、无遮挡判定；复杂地形（崖/楼）后的爆炸与预览会穿透到前面。
- **真解**：把这类效果件挪进**像素化域的透明趟**——用现成的细像素深度缓冲做遮挡、在艺术画布上画，而不是全分辨率盖在最上面。
- **涉及件**：爆炸/命中 FX、投掷预览（`TrajectoryPreview`）、危险虚线。
- **关联口径**：`渲染管线.md` §4（主相机侧 `PixelartScreenCopyFeature` 上屏；叠加相机为栈内 Overlay）、§5 缓冲（细像素深度）。
- **范围**：待开线时圈定（只做遮挡判定，还是连「效果件也走像素材质」一并做）。
