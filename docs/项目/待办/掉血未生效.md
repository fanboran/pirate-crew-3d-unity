# 掉血未生效排查

> 创始人实机打中单位后血量未减少;掉血**表现层**代码完整,疑点在伤害是否真的发生(命中判定 / 爆炸覆盖)。

## 详情

**现象**:创始人实机命中单位后观察不到血量变化,自述「血没有变少……还是爆炸范围的问题?」——待复现实测分清两案。

**表现层已排除**(代码完整、非本条范围):掉血反馈链挂在 `crew_damaged` 事件上共六样——伤害数字(`DamageNumberFx`,Damage<0.5 不弹)、命中火花+脚下尘土(`HitFx`)、受击闪白(`UnitOutlineBinder.SetColorFlash`)、按伤害比例震屏(`BattleCameraDriver.OnCrewDamaged`)、受击音效(`AudioService`)、顶栏血条段扣减动画(`UiMotion.SetFillPairTarget`)。若实测这些反馈**都没出现**,说明事件根本没发布,伤害在上游就断了。

**两案待分**:
- **伤害链断**:爆炸命中后 `PirateBase.SubtractHealth` 未被调用(命中检测 / 伤害应用路由断链);
- **覆盖未罩住**:标准炸弹空壳期占位大覆盖档(`BalanceConfig` 标准炸弹口径段:尺寸 100 → 半径 70px)与实弹观感不匹配,炸点看着命中、判定圈没套住单位——即创始人猜的「爆炸范围的问题」。

**排查入口**:
- `pirate-crew/Assets/Scripts/PirateCrew/Battle/PirateBase.cs` 的 `SubtractHealth` / `PublishHealthChanged` 调用链(谁在爆炸结算时调它);
- `pirate-crew/Assets/Scripts/PirateCrew/Combat/StandardBombRules.cs` 覆盖判定(规则单源)与 `Data/BalanceConfig.cs` 标准炸弹占位数值;
- 实测:打一发空炸看六样反馈是否出现——出现而血不变 = 伤害值为 0/未应用;全无 = 链断。

**边界**:本条只排查「伤害有没有发生/生效」;命中后的**表现增强**(头顶血条之类)与武器数值重裁归 [武器系统重做](武器系统重做.md)。
