# 船员描边 + 伤害数字（单位表现同批）

> 一句话现状：两件合成一条同批做——① **船员描边**：船员仍走 `PirateOutline` 内置反壳描边
> （配 `UnitOutlineBinder` 写 `_OutlineState`），没吃像素路径的屏幕空间描边；② **伤害数字**：已实现
> （`DamageNumberFx` + `FxDigitFont`），创始人要「跳炫酷、像合金弹头那种」的增强版。
> 创始人 2026-10-09：这两件是**同一个任务**。

## 详情

本条是「船员反壳件迁像素」话题的**唯一正主**：着色路径、PBR 根除批次等待办中涉及的
反壳件纠缠均以本条为准。

### ① 船员描边（反壳件迁像素路径）

- **现状**：`Crew.prefab` 两 renderer 各单材质槽（`Body`=CrewTeamCloth、`Head`=CrewWood）；
  描边不是独立材质槽，而是 `PirateOutline.shader` 内置的反壳 Pass；`UnitOutlineBinder` 靠
  MaterialPropertyBlock **逐 renderer** 写 `_OutlineState` 做逐单位描边开关/选中变色。
  （接触阴影件已根除：prefab 无 ContactShadow 子物体、`CrewContactShadow.mat` 不存在；
  `PixelartStageKit` 会主动查找并删除残留的 ContactShadow 节点。）
- **要迁成什么**：走像素路径材质（`PixelartCrew_*` / 屏幕空间 4 邻域描边）。难点：**破 `_OutlineState` 契约**，
  且「反壳骨架」属保留基座（AGENTS「角色模型不许改」）。
- **前提**：现役只剩**一个** `Crew.prefab`（不再 7 职业）；`CrewVisualPrefabBuilder.BuildAll` 仍可重生成。
- **落点**：`CrewVisualPrefabBuilder` 重生成时换材质，或 shader 收编批次统一处理。
- **关联**：`渲染管线.md` §6.1、`UnitOutlineBinder.cs` 文件头、`v3蓝本.md` §8 待定点 3。

### ② 伤害数字（合金弹头式跳动增强）

- **现役**：`Scripts/PirateCrew/Fx/DamageNumberFx.cs`（世界坐标弹出 + 上浮淡出）、`FxDigitFont.cs`（3×5 点阵字模）、
  `FxSpriteFx`（billboard 四边形、池化）、`HitFx` 命中触发；`DamageNumberCache` 上限 64。
- **口径**：伤害数字走像素化层、用像素数字（`渲染管线.md` §3.1）——
  [美术.md](../../设计/美术.md) §4「画面元素规格总表」第 8 条。
- **目标观感**：合金弹头式——弹跳/放大、分档配色、暴击强调等；**先定「炫酷」的具体规格**再动手。
