# 游戏特效重做（旧 FX 模块已整删退役）

> 一句话现状：旧 `PirateCrew.Fx` 模块（粒子/爆炸/命中/水花/弹道尾迹/伤害数字）因质量不达标经创始人裁决整体删除，重做未开线——新特效从设计出发重建，不参照旧实现。

## 详情

### 已删除面

- **源码**：`Assets/Scripts/PirateCrew/Fx/` 全目录（`FxRoot` / `FxBootstrap` 粒子池 / 爆炸 / 命中 / 水花 / 弹道尾迹 / 伤害数字 / 位图字体 / 材质与贴图规则），删后全仓编译与测试通过。
- **测试**：`Assets/Tests/Fx/` 三文件；`GameBootstrapTests` 与 `BattleSceneWiringTests` 中的 Fx 断言同步摘除。
- **产线**：`Editor/FxAssetBuilder.cs` + `ArtGate` 流水线步骤③ + `GraphicsSettings.asset` 两条 Always Included 登记（`PirateCrew/Fx/Additive`、`PirateCrew/Fx/Alpha` shader 已删）。
- **资产**：`Art/Shaders/Fx/`、`Art/Materials/Fx/`（14 mat）、`Art/Textures/Fx/`（5 png）。
- 场景与 prefab 对 Fx 脚本零序列化引用，删除后无需重烘场景；四个战斗事件（BattleStarted / CrewDamaged / CrewDied / ProjectileDetonated）均另有订阅者，EventBus 契约不变。

### 删除时一并接受的表现退化（重做时接回）

- 海鸥俯冲触水无水花（`SeagullAgent` 俯冲动作保留，触水调用点已摘）。
- 船员落水无水面涟漪（`WaterSimulationDriver` 的 `CrewDied` 注入路径已摘；弹体落水涟漪走 `ProjectileDetonated`，不受影响）。
- 战斗无爆炸/命中粒子反馈，弹体无拖尾。
- 战斗无伤害数字（见 [船员描边与伤害数字.md](船员描边与伤害数字.md)）。

### 重做约束

- **渲染口径**：像素化着色路径本体不画半透明（无混合能力，见 [渲染管线.md](../../技术/渲染/管线/渲染管线.md) §3/§10）——透明效果件要么继续走叠加档（全分辨率、无遮挡判定），要么等像素化域透明趟；建议与 [叠加档遮挡.md](叠加档遮挡.md) 一并圈定范围，避免重做完再返工遮挡。
- `PixelartContentConverter.IsEffectMaterial` 的 `PirateCrew/Fx/*` shader 前缀与 `Fx_` 材质名前缀豁免判据已保留（防御性，现役无资产命中）——新特效若复用该命名即自动豁免像素材质转换。
- 抖动/色带/描边等像素语言口径见 [美术.md](../../设计/美术.md)；旧「平滑扩散圆环与像素语言不符」一类的裁决仍有效（归档于 WaterSplashFx 的 git 历史）。
