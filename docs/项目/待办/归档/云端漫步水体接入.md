# 云端漫步水体接入（WaterLab 复刻水替换简版水）

> 一句话现状：**已被清澈海面方案取代并归档**——第 1 关海面改走自研清澈水 shader（`CloudSeaClearWater`），WaterLab 复刻水不再接进 CloudWalk（现行口径见 [云海.md](../../../技术/渲染/管线/云海.md)，余项见 [云端漫步清澈海面.md](../云端漫步清澈海面.md)）。本文件只作 WaterLab 接入线的沿革查证，以下为归档时的现状原文。
> 归档时的现状：**水 Shader 已 1:1 回到沙堡原作 + 海床浅海化 + 沙堡焦散**（2026-11-22 二轮）。前几轮不像 Demo 的根因全在我方补偿层：σ 被关（T≡waterColor，没有深度吸收）、alpha/tint/假波浪/折射×2.5/水面焦散近似把原作模型盖掉；且水深 1.6–2.5 m，而原作是 0.1–0.6 m 浅滩（σ=1 在 2 m 下是深海军蓝）。本轮：`_SigmaScale=1`、`_AlphaGain=1`、折射 0.0121、镜面 1500、删 tint/假波浪；海床抬到 −1.15..−0.75（水深 0.35–0.75 m，Blender/C# 双源同步），水下件缩尺；焦散按 WaterLabSand 公式（沙图 G 相位 + 3D 焦散体 + `exp2(−1.731·depth)`）加到沙面。实拍：`temp/cloudsea-round21-postline/battle-hud-1.png`、`temp/cloudsea-round21-cellshade/battle-hud-1.png`。剩余差距：Demo 最亮浅滩 0.1–0.3 m + WaterLabSand 湿沙响应；CellShade 画布偏暗（像素路径色调）。**待创始人过目**。

## 详情

### 目标

第 1 关「云端漫步」的海面换成 water-lab 复刻的水（`Assets/Scripts/PirateCrew/WaterLab/`
+ `Assets/Art/Shaders/WaterLab/`，Sandcastle 主菜单逐指令移植，验收帧
`export/waterlab-r110-final/battle-hud-1.png`）。水下白沙/海草/鱼群/岩簇保持现状，
透过复刻水的折射可见。

### 现有件（全部已入库）

- 模拟核：`WaterLabSimulation`（高度场 A↔B / 湿度 / 泡沫 / 焦散，compute
  `WaterLabSim.compute`，发布全局 `_WaterLabHeightTex/_WaterLabWetTex/_WaterLabCausticTex/
  _WaterLabGroundTex/_WaterLabOrigin/_WaterLabSimEnabled`）。
- 着色：`WaterLabOcean.shader`（Lit/Water 逐指令移植：折射 UV = 屏幕UV + 法线×0.0121
  带深度安全门，底色 = `_CameraOpaqueTexture`×T，散射/太阳高光按 C 表）；
  `WaterLabSand.shader`（湿沙/焦散）、`WaterLabWhitewater.shader`（白水粒子）。
- 装配器：`Assets/Editor/WaterLabSetup.cs`（水面网格 = DomainSize 见方网格 +
  `WaterLab_Ocean` 材质 + `WaterLabSimulation` 驱动物体，三件套口径）。
- 域常量：`WaterLabRules.DomainSize = 30 m`（水面网格/模拟域同尺寸）。

### 接入步骤

1. **域与水位**：`WaterLabSimulation` 挂场景件，域中心 = 竞技场中心 (20, ·, 15)，水面
   y = −0.4（现役死亡线，η 位移 ±cm 不影响落水判定）。30 m 域只盖住可玩区——域外
   （±45 m 可见海面）沿用现 `CloudSeaWater` 简版水面，域边界处用 WaveBand 幅度渐隐
   衔接（不出现水形接缝）。
2. **初始条件**：不挂 Menu 快照（Sandcastle 主菜单有岸线，云海是满水均质域），走
   程序剖面：groundHeight = 海床高度场采样、waterAmount = 满格。`_WaterLabGroundTex`
   一次性上传海床高度（现 `bed_z` 公式采样）。
3. **双渲染风格收件（最大风险项）**：`WaterLabOcean` 只验过普通 URP 前向（PostLine ✔
   直接可用，需开 `OpaqueTexture`）；CellShade 像素化域要走 `PixelartTransparent`
   （LightMode + 队列 [3000,5000]），且折射底色不能再采 `_CameraOpaqueTexture`——
   要在像素化透明趟前把艺术画布拷到临时 RT 并全局绑定（新增小 Feature，参照
   `WaterLabRefractionFeature` 的拷贝口径），深度安全门改采 `_PixelartDepthBuffer`。
   产出 = CloudSea 版双趟 ocean shader（结构同 `CloudSeaWater.shader` 的两趟口径）。
4. **渲染队列/半透明序**：水 `Transparent+10`、ZWrite 按 WaterLab 抓帧口径（TODO 未定，
   集成时抓帧定）；与云台投影（云影落在水面上）共存验证。
5. **旧件退役**：`Cloud_Sea_Surface` 的 `CloudSeaWater` 换装跳过水面槽（保留水洼/玻璃）；
   域外简版水保留（见步骤 1）。`WaterLabRefractionFeature` 加进两套 Renderer
   （PostLine_Renderer / CellShade Cast 渲染器）。
6. **白水/植物/GI**：v1 不接（战斗海面无岸线白水场景；海草已有网格版）；v2 再议。

### 风险/开放项

- 像素化域折射：艺术画布低分辨率下折射偏移量（0.0121 屏幕 UV）是否还成立，需实拍定。
- `FixedStep = 0.5·cellSize/√g` 随域尺寸走——域外简版水的波纹相位与域内不一致，
  接缝渐隐半径需实拍调。
- PostLine 开 `OpaqueTexture` 的帧成本（全屏拷贝）与像素域 RT 拷贝成本，抓帧看。
- 两风格的吨位（CellShade 色带）作用在水色上的观感，需创始人选型。

### 验收

- 双风格全场实拍：水有 Sandcastle 波纹/折射观感、水下海草鱼群可见、域界无接缝、
  角色落水判定不受影响（水面 y 仍 −0.4）。
- 创始人实机验收通过后本件移 `docs/项目/待办/归档/`。
