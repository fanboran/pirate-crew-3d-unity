# 验收·用户实玩与出图

> 二屏观感与手感、r13 出图与仓库级拍板项均卡在用户实玩/人工验收这一环。

## 详情

### 用户实玩验收

**用户实玩验收**：设置面板/暂停菜单/结算画面/返回确认的观感与手感；
HUD 动效手感（r13 遗留）；下调后的背景音量是否合适。

### r13 出图验收

**r13 出图验收**：ArtGate → 播放器 → 8 机位截图 → 人工观感验收（HUD 动效为运行时表现，
静帧只能验证面板/横幅状态正确，手感待实玩）。

### 用户实玩验收 HUD 动效手感

**用户实玩验收 HUD 动效手感**：面板滑入速度、血条滚动节奏、按钮 punch 幅度均为提案/待定
（见 `UiMotionRules` 常量注释），按实玩反馈调参。

### 用户拍板项

**用户拍板项**：仓库 LICENSE；关卡数 33 vs 18 核对。
