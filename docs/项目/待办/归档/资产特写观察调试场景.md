## 详情（原始需求）

做一个**游戏内资产的特写观察调试场景**：可切换各个游戏内资产（角色 / 云朵 / 岛体 / 装饰件等）、
对选中资产**各种旋转观察**（环绕 / 缩放 / 灯光档）。

- 价值：渲染 / 建模 / 描边调参不再依赖进战斗场景拍图，单件特写即看即改。
- 实现：复用试点场景与 `PixelartPilotScene` 的机位口径（30°/45° 常量同源）、
  `CharCamDebugController` 的旋钮面板与 URP 对照档机制、`SceneAssetManifestBuilder` 的目录扫描口径。
- 附带修复：`PixelartStageKit.CrewPrefabPath` 指向已删除的 `Sailor.prefab`（`3fb1b152` 起应为
  `Crew.prefab`）——`PlaceCrew` 四个装配器在用，坏一次烘焙即静默少摆角色。
