# 环境小动态收口

> 一句话：AmbientDirector 已实现并接线，余像素化路径材质口径收口与观感复核。

## 详情

### 已实现口径

环境与活物总控 `AmbientDirector`（`Assets/Scripts/PirateCrew/Ambient/AmbientDirector.cs`，
场景里唯一需要挂的 Ambient 组件）已实现并接线战斗场景，动态件清单：

- 海鸥（李萨如盘旋 + 拍翅 + 偶发俯冲 + 爆炸惊飞）；
- 螃蟹（岸边横爬 + 钳子摆动 + 遇单位/爆炸缩沙）；
- 鱼群（水下 boids）；
- 远景海鸟剪影；
- 植被/旗帜顶点风摆（`AmbientWindBinder` 换装，见下节衔接）；
- 灯笼（悬挂摆动 + 自发光 + 可选点光）；
- 燕尾旗绳（缆绳 + 六面垂旗随风摆）；
- 近岸浮标（随波起伏）；
- 昼夜/天气档位（默认正午与现状逐值一致，切档才改氛围）。

接线纪律与可玩性红线（引用全靠 `[SerializeField]` 注入、不进竞技场近侧带、不碰寻路与出生位等）
见该文件头注释。

### 剩余缺口

1. **像素化路径下的材质口径收口**：动态件渲染走叠加档还是像素化域，与
   [叠加档遮挡.md](叠加档遮挡.md) 是同一口径问题（叠加档全分辨率、无遮挡判定；
   真解是把这类件挪进像素化域透明趟）。
2. **观感复核**：出图确认动态件在像素化成图中的观感（非从零新建，只验不重做）。

### 衔接：风摆本体空转

`AmbientWindBinder` 对无风属性的像素材质摆动空转（`AmbientLibrary.cs` 风摆模板段自注：
材质无风属性时摆动自然空转）——绑定逻辑照常执行，只是摆不动。风摆本体待
[草丛风摆wind变体.md](草丛风摆wind变体.md) 的 `_WIND` keyword 变体落地。
