> 三项修复已落（`381aa4d3`：预览吃真实地形 / 右列补订阅 / 结算诊断日志）；碰撞箱高度与爆炸判定圈
> 属手感/表现调优，按收录口径不挂账。

## 详情

**现象**:创始人实机命中单位后观察不到血量变化,自述「血没有变少……还是爆炸范围的问题?」——待复现实测分清两案。

**表现层已排除**(代码完整、非本条范围):掉血反馈链挂在 `crew_damaged` 事件上——命中火花+脚下尘土(`HitFx`)、受击闪白(`UnitOutlineBinder.SetColorFlash`)、按伤害比例震屏(`BattleCameraDriver.OnCrewDamaged`)、受击音效(`AudioService`)、顶栏血条段扣减动画(`UiMotion.SetFillPairTarget`);第六样伤害数字旧 `DamageNumberFx` 已随 FX 模块删除(`2e78f640`),重做前实测无此项,判读时按五样算。若实测这些反馈**都没出现**,说明事件根本没发布,伤害在上游就断了。

**排查结论（静态结案）**:
- **①伤害链断：不成立（≈10%）**——ExplosionResolver→SubtractHealth→CrewDamaged 路径完整、无静默过滤；
  `Combat` 89/89、`Battle` 303/303 绿。
- **②覆盖档太小：算术上否掉（≈5%）**——判定半径 70px=4.375 m，是角色视觉身高（2.03 m）的 2.15 倍；
  现役根本没有 4.375 m 的视觉爆圈可比（FX 已删，落点环只有 0.45 m）。
- **③观感与判定不同源：主因（≈85%）**——③a 预览落点按 `GroundTopY=0` 预测、实弹在真实地形高度落地
  （空岛 14 m/云场 2.5~8 m → 实弹早落 2.8~13.9 m，远超判定半径：看着命中、实弹落空，但 boom/震屏照常）；
  ③b 单位物理碰撞箱仅 0.375×0.5×0.375 m（视觉 2.03 m），平抛弹可从身体穿过不触发碰撞；
  ③c 右列单位血条只在选人/回合事件刷，受伤事件只推顶栏。
- **实测判读（只认这四样）**：爆炸 boom / `FleshHit` 音效 / 受击闪白 / 顶栏血条段
  （HitFx 与伤害数字已随 FX 删除，不要再等）。

**修复清单**:
- [x] ③a 预览落点吃真实地形高度（`ThrowTrajectory` 采样器注入 + `HeightfieldGrid.SurfaceWorldYAtWorld`，含落水格；+3 测试）；
- [x] ③c 右列血条在受伤事件刷新当前选中单位（`BattleHud.RefreshUnitHpBar` 共用单源）；

- [待排] 爆炸判定圈的可视化（否则“爆炸范围”永远不能眼睛验收）。

**一步实测判别法**（修复前/后都可用）：第 2 关打落单敌兵，仰角 85° 力度最低垂直砸脚边——
若这发掉血正常，则为落点/命中体积问题；若仍无血肉音/闪白/顶栏变化，则另案查弹体生命周期。
