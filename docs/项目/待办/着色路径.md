## 详情

**口径**（权威：[管线/渲染管线.md](../../技术/渲染/管线/渲染管线.md)；实现索引与字面量表：

- **唯一渲染路径**：像素化着色路径是本项目唯一渲染路径。旧视觉链（`PirateToon` shader /
  `PixelationRendererFeature` / `PixelationInstaller`）已整条根除、两档 URP 渲染器上的
  Feature 已摘净——「唯一」以此为基础（渲染管线.md §10）。
- **相机**：正交投影；俯角固定 **30°**（菱形宽:高 = 2:1 的经典像素等距网格；真等距
  35.264° 与像素网格无整数比、阶梯长短不一，已废）——游戏内与出图读同一份常量；
  俯角锁死、方位可自由旋转（45° 为烘焙基准机位方位）；平移 snap 到整艺术像素
  （渲染管线.md §1）。
