## 详情

### 已收口（一行一件）

- `test` 档结果缓存 + 过滤器透传——同 HEAD + 同工作区限时缓存直回放，第 2 参数透传 `-testFilter`；
- 测试/运行日志落 `$TEMP`（WSL/Git Bash 未导出时兜底）；
- harness `Battle` 域补目录（补 Settings，缺它编译报 CS0234）；
- `run.sh chain` 单入口编排档（`pirate-crew/Assets/Editor/HeadlessChain.cs` 反射编排器：

  2022.3 装不进，裁决不可用，退常驻 Editor + 自建命令桥（证据记技术文档 §2）；
- 冷启动大头逐项分解（每进程固定税、重编双重载牵连；Library 预热副本日常收益 ≈ 0，不做），
  结论记技术文档 §1.1。
