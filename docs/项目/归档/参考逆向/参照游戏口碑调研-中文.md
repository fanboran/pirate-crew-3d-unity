## 3. 中文玩家的记忆点（带原话）

### 3.1 玩法记忆：回合制、抛物线、一人一次

- "**这是一个回合制的投掷小游戏。**和一般的这类游戏相比，这个在数量上多很多，而且地图比较大，需要切换视角……要赢除了投得准以外，还得合理利用好道具，派兵布阵一下。" —— 4399 `一叶而知秋~~~~`（福建）
- "**我们的跳跃和投掷炸弹的方式都是同一种操作方式**，拉动小人模型，拖动选择拉伸的力度和角度，松手即可完成你的移动和投掷。" —— 4399 `魔人布欧的脚`（福建）
- "话说**投炸弹的弧度，居然让我想起了数学抛物线**，也是挺逗的。" —— 4399 `帅到掉渣额`（福建）
- "点击自己右边格子里有**无限炸弹**可以用……我们**是一人发射一次**所以把握还机会，我个人比较推荐把他**往水里炸**那样比较容易赢。" —— 4399 `莫拉蒂要走`（河南）

## 5. 对重制的可执行启示（**AI 提案/待定**）

> 以下每条都绑定来源，可直接进 `docs/项目/待办事项.md` 评审；未确认前不得当作设计基准。

1. **核心手感必须 1:1 保真：回合制 + 一人一次 + "拖动定角度/力度 + 松手" 的统一操作同时承担位移与投掷。**
   来源：4399 `一叶而知秋~~~~`、`魔人布欧的脚`、`莫拉蒂要走`；B 站 V4 简介。3D 化时若改成两套操作（走位一套、瞄准一套），就丢掉了被最多人记住的东西。

2. **"隐藏操作"首次出现时必须给教程/提示——尤其是香蕉炸弹的二次点击引爆。**
   来源：B 站 V5 `传奇弑君者柳德米拉`（151 赞，"不知道香蕉炸弹可以再按一次鼠标引爆"）、4399 `3870617250`；海鸥/海啸同类问题（`2346706070`）。这是**低成本、高收益**的 UX 修复。

3. **AI 要"强但可读"：可以难，但不要用"超远精确 + 随机"制造不可预判的失败。**
   给 AI 的香蕉/炮弹加**弹道/落点预兆**，限制其命中精度与回合随机性，或把"AI 强度"做成可调难度。
   来源：4399 `山东`、`私人老爷`、`3827141517`；B 站 V6 `-BloodMoon-`、V4 `右移轨迹`（"攻略意义不大"= 随机性抹杀策略感）。

4. **难度曲线重做，把"第 12 关墙"拆成可攀登的坡：把"人数压制(5v9~5v11)"与"AI 必中"解耦，提供中途存档/难度选项。**
   来源：4399 `870897632`、`泪奔又细致的盒饭5tma`、`←_←tfb`、`1880843468`；B 站 V4 `右移轨迹`。12 关是全社区唯一"没争议"的痛点。

5. **做**全中文叙事 + 玩梗本地化**（含配音/字幕 + 梗注解），把原版英文笑话和结局伏笔补回来。**
   来源：A1 专栏、B 站 V5（54,654 播放的翻译注解视频本身就是"需求证明"）、4399 `1221218471`（"我是橡胶你是胶水"困惑）。这既是还原也是对中文玩家的直接差异化。

6. **双人本地同屏热座是口碑资产，必须保留并前置宣传。**
   来源：B 站 V4 简介（"和小伙伴 1v1"）、V12（"带女朋友一起玩"）、V7（"菜鸡互啄"46,212 播放）、4399 `左人明煦成`（"友尽玩法……已经失去一个朋友了"）。

7. **给"通关 / 满血 / 高分 / 速通"配可见成就与排行榜（含计时）。**
   中文圈已自发形成速通（V3/V9、speedrun 认证）、分数攀比（1775/1132）、无伤挑战；显式化这些目标能把"通关即弃"变成"可反复刷"。
   来源：B 站 V3、V9、`隐行仁` 评论；4399 `不具名的滑稽`、`左人明煦成`。

8. **为中文玩家保留"点开即玩"的 Web/云入口思路。**
   这批玩家的接触场景是 4399、7k7k、学校机房（4399 `-玖别`"电脑课"、官方云游戏推送、V16 模拟器）。纯桌面安装会丢失"碎片时间/课间"这一记忆场景。
   来源：S1/S4 评论、B 站 V16。

9. **美术上做"角色符号辨识度"优先于画面规格。**
   玩家记的是船长/大帽子 Boss/彩虹胡子/鹦鹉/骷髅/猴子/螃蟹/香蕉等**功能化人设**，而不是像素密度（§3.3）。
