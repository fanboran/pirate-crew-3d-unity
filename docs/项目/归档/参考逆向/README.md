## 与 Aseprite 参考库的分工（避免再次误引）

- **UI 外观 / 组件 / 排版 / 列表与对话框结构** → Aseprite 参考库（theme.xml 是唯一可量的真源）。
- **玩法数值 / 回合规则 / 武器机制** → 本目录静态档（历史记录，已实现部分以代码与
  [参考逆向](../../../技术/参考逆向/)→现 [归档](.) 的对照表为准）。
- **关卡设计灵感** → 本目录（可参考，非依据）。**原版的界面组织方式不是我们的依据**——
  例如原版选关是 15 关网格 5×3、点格直进，我们不做界面照搬。
