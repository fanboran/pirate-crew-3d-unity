### 2.2 菜单跳转机制：`_root.tt.doTween(label)`

**所有界面切换都不是直接 `gotoAndStop`，而是通过 `_root.tt`**：

- `_root.tt` = sprite **406**（`com.nitrome.game.TransitionTween`），在 root depth **210** 常驻（矩阵 (5500,4000) = 舞台中心）。另有 depth 429 的实例仅存在于第 9 帧，第 19 帧被移除。
- 该 sprite 共 18 帧：f1 `stop()`（内含 char405 **全屏白矩形 0,0–11000,8000，alpha=0**）；f2–f9 alpha 0→256 淡入；**f10 = `performTask()` → `this._parent.gotoAndStop(next_frame)`**；f11–f17 alpha 256→0；回到 f1。
- `TransitionTween.doTween(label)`：记 `next_frame`，`gotoAndPlay(2)`。变体 `doTweenWithFunction(fn)` 用于"切帧后再执行闭包"（换关/重开）。

```pseudocode
// com.nitrome.game.TransitionTween
doTween(next_frame)          { this.next_frame = next_frame; this.next_frame_function = null; gotoAndPlay(2); }
doTweenWithFunction(fn)      { this.next_frame = null; this.next_frame_function = fn; gotoAndPlay(2); }
performTask()                { if (next_frame) this._parent.gotoAndStop(next_frame);
                               if (next_frame_function) { next_frame_function(); next_frame_function = null; } }
```

## 3. 回合流程（状态机）

### 3.1 主循环

```pseudocode
// Controller.enterFrame  —— 挂在 _root.holder.onEnterFrame
enterFrame():
    inactivity++                                   // 全局"空闲帧"计数
    for t in teams:            t.advance()          // 含 AI 时间片与角色物理
    tileSystem.advance()                            // 相机、滚动、鼠标悬停、范围圈
    for m in mines:           m.advance()
    for c in chests:          c.advance()
    for a in avatars:         a.advance()
    for b in boxes:           b.advanceMotion()
    water.advance()
    map.drawActive()                                // 刷新小地图活动点

    if inactivity > 10:                             // ≈0.4s 无任何活动
        inactivity = 0
        if currentTeam.isTurnComplete(): nextTurn()
        else:                            continueTurn()

    if speechBubble:                                // 对白
        speechBubble.advance()                      // 逐字打字机
        if speechBubble.completeTime > 160:          // 读完停留 160 帧
            speechBubble.destroy()
            // speechLineNumber 1→2→null 的链式推进；3 = 关卡结算后台词
```

`inactivity` 被清零的来源（任何"有事发生"都推迟回合推进）：
`Team.advance`（当前队且未选角色）、角色在动 / 武器在飞、地雷 armed（`Mine.advanceMotion`）、宝箱下落或开启中、`SweepingFlame.createNext`、`BoxWeapon` 放置等。

### 3.2 队伍状态机

```pseudocode
// com.nitrome.throwgame.Team
Team(n):                                     // n = 1 或 2
    number = n; characters = []
    aiControlled = (_root.game_type == 1) ? (n == 2) : false   // 1P → 2 队归 AI

startTurn():
    totalTurnsTaken++
    selectedCharacter = null
    for c in characters: c.mc.num.text = index(c)          // 显示编号
    if aiControlled:
        aiFinished = false
        for c in characters: c.aiStart()                   // 清空 aiMoveList
        aiCanBailOut = false
    for c in characters:
        c.mc.num._visible = false
        if c.hasWeapons.length < 1: c.hasWeapons.push("cannonball")   // 保底武器
        c.canShoot = true; c.canThrow = true
        c.weaponSelected = false; c.weaponLocked = false
        c.evilness = 0
        // 选一个"离相机中心最近"的角色作为默认镜头目标
        if c.alive and dist2(c, cameraCenter) < best: best = c
    if !selectedCharacter:
        panToCharacter = nearestToCamera
        cap = getCaptain()                                  // 名字含 "Captain" 或 "tribeChief"
        if totalTurnsTaken == 1 and cap: panToCharacter = cap // 首回合先看船长
    _root.weapons.gotoAndStop(number != 2 ? "red" : "blue")
    text.say(aiControlled ? "Computer, take your turn" : "Player "+number+", take your turn")

select(character, again):
    if !character.alive: return
    selectedCharacter = character
    character.thrown = false; character.throwFinished = false; character.weaponSelected = false
    if !again: playSound(getTeamType())                     // 台词/音效

isTurnComplete():
    if !selectedCharacter.alive: return true
    return !(selectedCharacter.canThrow || selectedCharacter.canShoot)

continueTurn():                                             // 同一角色做第 2 个动作
    select(selectedCharacter, true)
    if aiControlled:
        aiFinished = false
        for c in characters:
            c.aiStart()
            c.canShoot = (c == selectedCharacter)           // 只允许已选角色用武器
            c.canThrow = false
        aiCanBailOut = true

finishTurn():
    selectedCharacter.thrown = false
    selectedCharacter.throwFinished = false
    selectedCharacter.weaponExpired()                       // 消耗本次武器（infinite 除外）
    selectedCharacter = null
```

### 3.3 回合推进与胜负

```pseudocode
// Controller.nextTurn
nextTurn():
    currentTeam.finishTurn()
    if !teams[0].anyAlive() || !teams[1].anyAlive():
        if teams[1].aiControlled:                           // 1P 模式
            if teams[0].anyAlive():                         // 玩家赢
                getLine(2) 对白（3 秒后弹结算）
                NitromeGame(ng).setLevelUnlocked(selected_level + 1)
                _root.score += get1PLevelScore()
            else if teams[1].anyAlive(): getLine(3)         // 输
            else: popup.gotoAndStop("level_failed_1p")      // 全灭（极少见）
            return
        // 2P 热座
        if teams[0].anyAlive(): _root.won_p1++; popup("vs_1p_wins")
        else if teams[1].anyAlive(): _root.won_p2++; popup("vs_2p_wins")
        else: popup("vs_draw")
        return
    currentTeam = (currentTeam.number == 1) ? teams[1] : teams[0]   // 交替
    if selected_level == 2 and ng.avatarAvail: Avatar.dropNew()    // 第 2 关掉落彩蛋
    else:                                       TreasureChest.dropNew()
    currentTeam.startTurn()
```

1P 模式帧末结算（`Controller.enterFrame` 内 speechLineNumber==3 分支）：
`selected_level == 15` → `popup("game_complete_1p")`，否则 `popup("level_complete_1p")`；若玩家全灭 → `popup("level_failed_1p")`。

**回合数经济**：`get1PLevelScore() = floor(team0.getAverageHealth()*20 - team0.totalTurnsTaken*25)`，下限 `selected_level*10`。

### 3.4 单回合操作流程（人类玩家，严格两阶段）

```pseudocode
// 阶段 A：点击选中己方角色（TileSystem.mouseDown，挂在 Controller.content.onMouseDown）
if speechBubble: 跳过对白; return
if _root.weapons._visible and weapons.hitTest(_root._xmouse,_root._ymouse): return   // 点在面板上
if currentTeam.aiControlled: mouseButtonDown = true; return

if !currentTeam.selectedCharacter:
    best = null; minD2 = 900                     // 隐式阈值 = 30px
    for c in currentTeam.characters:             // ← 只在本队里找
        d2 = dist2(c, content._xmouse/_ymouse)
        if d2 < minD2: minD2 = d2; best = c
    if best: currentTeam.select(best)            // select() 内部拒绝 !alive
    return

// voodooDoll 专用：选敌人作为目标（同样 30px 阈值，遍历敌方 characters）
if voodooDoll equipped and !fired: pickNearestEnemy(30px) -> setTargetCharacter(); return

if !selectedCharacter.weaponSelected: return     // ★ 未选动作前，世界点击全部无效

// 阶段 C：按下准备拖拽
obj = selectedCharacter.equippedWeapon                                  // 有武器
      ?? selectedCharacter                                              // 否则抛角色自身
if obj.fired or obj.placeableWeapon: return       // 已发射 / 放置类武器不拖拽
if obj是角色 and (obj.thrown or !obj.canThrow): return
if !obj.draggable and !obj.twangable: return
if dist2(obj, content._xmouse/_ymouse) < 900:     // 30px 内
    if obj.twangable: Controller.twanging = obj   // 角色/多数武器都是 twangable
    else:             Controller.dragging = obj
    obj.dragStartX = obj.x; obj.dragStartY = obj.y

// mouseUp
if Controller.dragging: dragging.release(); dragging = null
if Controller.twanging: twanging.twang();   twanging = null
```

阶段 B（选动作）来自武器面板按钮 `WeaponSelectButton.onPress()`（要求 `panel.contentsActive == true`，即面板已淡入完成）：

| 按钮 | 效果 |
| --- | --- |
| `button_throw`（"throw character"） | `unequip(); weaponSelected = true` → 进入阶段 C 抛角色 |
| `button_endTurn`（"end go"） | `canThrow = canShoot = false; unequip(); thrown = true; throwFinished = true; weaponSelected = true` → 立即结束本回合 |
| `button_<weaponId>` | `equip(firstIndexOfWeapon(w)); weaponSelected = true` |

**动作次数规则**：角色每次回合可做「抛自己一次」（可选）+「用一件武器一次」。
- 抛自己：`Character.twang()` → `thrown=true; canThrow=false`（`canShoot` 仍为 true → 回合继续）
- 用武器：`Weapon.twang()` → `fired=true; owner.canShoot=false; owner.canThrow=false` → **用武器即结束回合**
- 点 end go：两者置 false → 直接结束

面板显示条件（`WeaponSelectPanel.onEnterFrame`）：`currentTeam.selectedCharacter && !selectedCharacter.weaponSelected && !currentTeam.aiControlled` 时 `_alpha+=25` 淡入（到 100 时 `contentsActive=true`），否则 `_alpha-=25`，≤0 时 `_visible=false`。**面板不会自动出现，必须先成功选中角色。**

### 4.3 队伍归属（`TileSystem.readXML` 硬编码）

```pseudocode
// 关卡 XML 的 <obj type="..."> 解析
teamIndex = (type == "redPirate" || type == "redPirateCaptain") ? 0 : 1
character.team = Controller.teams[teamIndex]
character.x = (xmlX + 0.5) * 32
character.y = (xmlY + 0.5) * 32 + 16 - bottomExtent
character.setWeapons(xmlAttrs)     // 见 §5.5
```

- **team1 = 红队（玩家）**：`redPirate` / `redPirateCaptain`
- **team2 = 蓝队**：其余全部（含 `bluePirate` / `bluePirateCaptain`）
- 队伍血条颜色：`_root.weapons` 与 `Team` 均以 `number != 2 ? "red" : "blue"` 取色

**队伍规模**：没有"队伍人数"参数——**队伍人数 = 关卡 XML 里属于该队的 `<obj>` 数量**，双方 1:1 对称（如关卡 7 是 2 红 vs 1 bossGuy，关卡 22 是 14 vs 14，关卡 27 是 1 vs 1）。等级差由"角色数 + 初始武器 + luck"三者共同体现，而不是靠属性差。

**每回合只有 1 个角色行动**（`Team.selectedCharacter` 是单值；`isTurnComplete()` 只检查它）。玩家可点击己方任意存活角色来决定本回合由谁行动；AI 则通过 `aiMoveList` 全局比较，自动挑"最划算的角色+动作"组合。角色的 `mc.num`（编号文字）在 `startTurn` 时写入、随即隐藏，用于调试/回放识别。

### 4.4 死亡与落水

```pseudocode
subtractHealth(amount):
    health -= round(amount)
    if health <= 0: health = 0; alive = false

// 死亡表现（Character.advance，仅在角色静止时推进）
if shownHealth != health and velocityX == 0 and |velocityY| < 0.2:
    shownHealth = slide(shownHealth, health, 1)      // 每帧滑 1（血条动画）
    if shownHealth < 1:                              // 血条走空 → 真正死亡
        mc._visible = false
        生成 "deadCharacter" 挂在 y + bottomExtent
        alive = false
        playSound("die")

// 落水即死
if y > Controller.water.y:
    health = 0; shownHealth = 1; alive = false
    velocityX *= 0.8; velocityY *= 0.8
    if velocityY > 1.5: velocityY -= 4 (下限 1.5); rotation += (vx+vy)*4

// 受击表现
if hit: (移动中) mc.gotoAndPlay("hit")；静止后 hit = false
```

## 5. 武器 / 道具

### 5.1 投掷机制（弹弓 twang）——所有"拖拽发射"的统一公式

```pseudocode
// Solid.twang()  松开鼠标瞬间
vx = (Controller.content._xmouse - obj.x) * -0.25
vy = (Controller.content._ymouse - obj.y) * -0.25
if vx*vx + vy*vy > twangMaxForce*twangMaxForce:      // 限速
    s = sqrt(vx*vx + vy*vy); vx *= twangMaxForce/s; vy *= twangMaxForce/s
obj.velocityX = vx; obj.velocityY = vy
```

- **初速 = 0.25 × 拖拽距离；方向与光标偏移相反（向后拉 = 向前射）**
- **满力拖拽距离 = twangMaxForce / 0.25**：默认 `20/0.25 = 80 px`；`twangMaxForce=30` 的武器为 120 px
- 拖拽过程中 `Solid.drawTwangLine()` 画弹弓线 + 15 段虚线轨迹预测（每步 `vy += weight`，衰减 alpha）
- `dragRange`（130 / 地雷 180）**只用于画半径圈**，与力度无关
- 速度上限汇总：角色 20；cherryBomb 20；dynamite 20；boulder 20→`release()` 再 ×0.5；mine 20；cannonball 由 cannon 决定；banana / parachuteBomb / rumBottle / piecesOfEight 30；cannon 发射速度 = `fireStrength`（≤30）；anchor 恒 `vy=40` 从 y=-200 下落

### 5.3 爆炸伤害/击退公式（`Explosion.as`）

```pseudocode
// new Explosion(x, y, size, maxDamage, caster)
radius = size/2 + 20
// 对每个存活角色
for team in teams:
    for char in team.characters:
        if !char.alive: continue
        d = dist(char, this)
        if d <= radius:
            falloff = 1 - d/radius                         // 线性衰减
            nx = dx/d; ny = dy/d
            dmg = maxDamage * falloff                      // ← 伤害
            char.velocityX += nx * 5 * (0.06 * falloff * maxDamage)   // 击退
            char.velocityY += ny * 5 * (0.06 * falloff * maxDamage)
            char.velocityY -= (0.06 * falloff * maxDamage) * 6         // 额外上抛
            char.subtractHealth(dmg)
            caster.evilness += falloff                      // 施暴者"邪恶度"
            char.hit = true
// 对箱体：以箱体 AABB 最近点距离判定，命中即 box.explode()（火药桶连锁）
```

要点：
- **伤害/半径**：`radius = size/2 + 20`（px），`damage = maxDamage * (1 - d/radius)`，**中心无倍率、边缘趋 0，无最小伤害保底**
- **击退**：`k = 0.06 * falloff * maxDamage`，水平 = `dir * 5k`，垂直 = `dir * 5k - 6k`（总是额外上抛）
- **evilness** 累加 falloff：AI 后续会更优先攻击被打疼过的敌人
- 墙/地弹跳与摩擦来自 `Solid`：撞地 `vy *= -bounce`（默认 -0.2）并 `|vx| -= friction`（下限 0）；撞墙 `vx *= -0.4`

### 5.4 物理（`Solid.advanceMotion`）

```pseudocode
advanceMotion():
    velocityY += weight                       // 重力（每帧，25fps）
    if vx==0 and vy==0: return
    // 分轴 AABB 扫掠：先 Y 后 X
    // Y 轴：检查 (x±extent, y±extent) 覆盖的瓦片格（>>5）与 boxes
    //   命中 → vy *= -bounce; y = 贴边坐标; 若落地(vx方向) → |vx| -= friction
    //          contact(FLOOR) / contact(CEILING)
    // X 轴：同理 → vx *= -0.4; contact(WALL_RIGHT/WALL_LEFT)
    // 落水检测：overWater 变化时生成 splash 并让水面重播动画
```

- 瓦片坐标一律 `>>5`（32px）
- `hitsTiles` / `hitsBoxes` 决定是否参与碰撞：角色 `hitsBoxes=true`；tidalWave / seagull `hitsTiles=false`
- `contact(side)`：角色落地时把旋转归一到 (-180,180] 并 `rotation *= 0.5`（<1° 归零），并触发 "hitwall" 音效

## 6. AI（`Character.aiThink` + `Team.advance`）

> 这是 Godot 版 `ai_controller.gd`（空 TODO）最需要补的部分。原版 AI 是**穷举模拟 + 启发式打分**，全部通过 `randomThrows()` 预演物理轨迹。

### 6.1 调度（`Team.advance`，非 Controller）

```pseudocode
advance():                                     // 由 Controller.enterFrame 每帧调用
    if aiControlled and !aiFinished and Controller.currentTeam == this:
        for c in characters:                   // 只推进第一个未完成的角色
            if !c.aiFinished:
                t0 = getTimer()
                do { c.aiThink() } while (!c.aiFinished && getTimer() < t0 + 30)  // ★ 每帧 30ms 时间片
                break
        aiFinished = characters[last].aiFinished
        if aiFinished:
            all = concat(所有角色的 aiMoveList)
            best = argmax(all, m => m.success)
            if best.success > 0 or !aiCanBailOut:      // ★ 无明显收益且允许放弃 → 跳过回合
                select(best.player); aiMoveDetails = best
                tileSystem.panToCharacter = best.player    // 先给镜头
            else:
                Controller.nextTurn()
    else if aiMoveDetails and tileSystem.panToCharacter == null:   // 镜头到位后执行
        if aiMoveDetails.weapon >= 0:
            player.equip(weapon); player.equippedWeapon.aiPerform(aiMoveDetails)
            player.canThrow = false; player.canShoot = false
        else:                                        // weapon == -1 → 抛角色自身
            player.unequip()
            player.velocityX = details.vx; player.velocityY = details.vy
            player.thrown = true; player.canThrow = false
        aiMoveDetails = null
```

### 6.2 角色自身投掷评估（`aiThink` 第一块）

```pseudocode
if !aiThrowChecked:
    if canThrow:
        if !aiThrowsToCheck: aiThrowsToCheck = randomThrows(50)   // ★ 一次性生成 50 个随机自抛
        t = aiThrowsToCheck.splice(0,1)[0]
        // ---- 打分 ----
        s = 0
        s += (t.ey - this.y) * -0.003                              // 落点越高越好
        s += (|t.ex - enemyAvgX| - |this.x - enemyAvgX|) / -500     // 落点比现在更靠近敌方质心
        s += (|t.ey - enemyAvgY| - |this.y - enemyAvgY|) / -500
        if t.ey >= water.y: s -= 2                                 // 别落水
        for e in 敌方存活:
            d2 = dist2(t, e); d = sqrt(d2)
            if d2 < 40000 (200px):
                k = 0.2 * (1 - d/200)
                if d2 < 10000 (100px): k *= d/100; s -= (1 - d/100) * 3   // 太近会自伤/暴露
            else:
                k = 0.3 * 0.75^(d/200)
            s += k
            s *= (1 + e.evilness)                                  // ★ 优先打 evilness 高的敌人
        for ally in 本队存活:
            if ally == this: if d2 < 6400 (80px):  s -= 1   * (1 - d/80)
            else if        d2 < 1600 (40px):  s -= 0.1 * (1 - d/40)
        for chest in 未完成宝箱: if dist2 < 1600 (40px): s += 0.5      // 顺便捡箱子
        // ---- 用 cherryBomb 做一次"落点收益"复核 ----
        equip(firstIndexOfWeapon("cherryBomb")); sim = equippedWeapon.randomThrows(10); unequip()
        for m in sim:
            g = 0
            for e in 敌方: if dist2(m,e) < 10000: g += (1 - d/100) * (1 + e.evilness) * 0.5
            if dist2(m,this) < 6400: g -= (1 - d/80)
            if g > 0: s += g; if s > bestSoFar: aiRemember = m       // 记住最优点（后续武器评估复用）
        d = dist(t, this)
        s += (d2 < 90000) ? 0.3*d/300 - 0.3 : -0.3                   // 落点别太远
        t.success = s; t.player = this; t.weapon = -1
        aiMoveList.push(t)
    else:
        aiMoveList = []; aiThrowChecked = true; aiFinished = (hasWeapons.length < 1)
    return
```

`randomThrows(count)`（`Character` 版）：`angle = 180 + int(random*180)`（**180°–360°，即永远向上抛**，因为 Flash y 轴向下、`sin(180..360) ≤ 0`），`force = 5 + random*15`，然后逐帧 `advanceMotion()` 到静止或落水，记录 `{vx, vy, ex, ey}`。

### 6.3 武器评估（`aiThink` 第二块）

每个角色按 `hasWeapons` 顺序、对每个**不重复**的武器名逐个评估（`aiWeaponsChecked` 游标）。通用武器的尝试次数：

```pseudocode
count = floor(luck * team.characters.length / team.countAlive())   // ★ luck 越大、活着越少 → 试更多次
equip(index); throws = equippedWeapon.randomThrows(count)
if aiRemember and aiRemember.weapon == index: throws.push(aiRemember)   // 复用 6.2 记住的最优点
for t in throws:
    s = -0.01
    for e in 敌方存活:
        if dist2(t,e) < 4900 (70px):
            s += 1.5 - d/70
            s *= (1 + e.evilness)
    for ally in 本队存活:
        if dist2(t,ally) < 1600 (40px): s -= 1.5 - d/40
    if 武器 == "anchor":         s *= 0.5                          // 锚：收益减半（不好控）
    if 武器 == "piecesOfEight":  s = (s - 0.5) * 1.2               // 八币：更激进
    t.success = s; t.player = this; t.weapon = index
aiMoveList = concat(aiMoveList, throws); unequip()
```

特殊武器走专门分支：

| 武器 | AI 评估逻辑 |
| --- | --- |
| `tidalWave` | `s = Σ(敌方且 y >= waterY-300) health/maxHealth * 0.5  −  1.5 × (本队且 y >= waterY-300 的人数)`；`aiPerform` 直接 `startWave()`（浪从左侧自动扫） |
| `voodooDoll` | 对**每个存活敌人**调它的 `randomThrows(2)`；若该敌人被模拟投掷后**落水** → `s = 1 + random*0.2`，否则 `s = random*0.2 - 0.5`；记录 `{success, vx, vy, target}`。即"把敌人扔下水"是最高收益 |
| `seagull` | `Seagull.aiSimulation()`：高度 = 敌方最高 y − 100 − random*100；随机 10 个 x 落点，逐点模拟坠弹，命中敌人（<40px）得 `1 - d/40`，误伤队友扣 `1.5 - d/40`；只保留得分为正的落点，返回 `{success, shots[], height}`；要求 `shots.length > 1` |
| `woodenCrate` / `gunpowderBarrel` | `BoxWeapon.aiSimulation()`：在敌方角色附近取 10 个候选放置点（x 沿"本队质心→目标"方向偏 16–64px，y 偏移 ±50），过滤 `canPlace()`；要求 **≥3 个可行点**；**`success = Math.random()`（纯随机）** |
| `cannon` | `Cannon.randomThrows(count)`：随机角度 0–360 + 随机拖拽距离（≤dragRange/2）决定炮位，再模拟炮弹以**速度 30** 沿随机角度飞出；`aiPerform` 摆位、设角度、`aiFireTime = 25` 后发射 |

### 6.4 随机数使用点（AI 的随机性）

| 位置 | 用途 |
| --- | --- |
| `Character.randomThrows` | 自抛：角度 `180+rand*180`，力度 `5+rand*15` |
| `Weapon.randomThrows` | 通用武器：角度 `180+int(rand*180)`，力度 `5+rand*(twangMaxForce-5)`；**最多模拟 100 步** |
| `Seagull.aiSimulation` | 高度 `-rand*100`、10 个随机 x |
| `BoxWeapon.aiSimulation` | 10 个随机偏移点 |
| `BoxWeapon` 分支 | `success = Math.random()`（**完全随机**，即 AI 对箱体基本不做评估） |
| `VoodooDoll` 分支 | 落水判定成功值 `1+rand*0.2` / 否则 `rand*0.2-0.5` |
| `Cannon.randomThrows` | 随机角度 + 随机炮位 |
| `Controller.startGame` | **2P 模式** 50% 概率让 team2 先手（1P 固定 team1 先手） |
| `TreasureChest` | 1–3 件随机武器、随机落点列 |
| `SweepingFlame` | 受击者随机击退 `(rand-0.5)*8` / `-(rand*2+6)` |
| `Seagull` 音效 | `"poop" + (1..3)` 随机挑一个 |

### 7.1 胜负判定

## 附录 B：逆向方法与坑

1. **Java 环境**：`C:\Program Files\Common Files\Oracle\Java\javapath\java.exe`（PATH 里的那个）本机**段错误**（exit 139）。JDK 本身正常：`C:\Program Files\Java\jdk-21\bin\java.exe`（21.0.1）与 jdk-17 都可用。**直接用绝对路径调 java**。
2. **FFDec 下载**：GitHub release 资产域名（`objects.githubusercontent.com`）被重置，多次直连失败（curl exit 56）。改用镜像前缀 `https://ghproxy.net/<原始URL>` 成功；19.8MB 下载很慢，用 `curl -C -` 断点续传循环。放 `external/tools/`。
3. **FFDec 用法**：
   - `java -jar tools/ffdec/ffdec-cli.jar -export script,frame <outdir> <swf>` → 反编译 AS + 逐帧 PNG
   - `java -jar tools/ffdec/ffdec-cli.jar -swf2xml <in.swf> <out.xml>` → 带坐标的完整结构
   - 中文路径会导致部分子命令报 `File not found.`，**先把 swf 复制成 ASCII 名**（`game.swf`）再处理。
4. **自写 AVM1 反汇编器**（`external/swf-decompile/scripts-python/avm1_disasm.py`）：作为 FFDec 就绪前的兜底，也用于交叉校验。踩到的坑：**本 SWF 的零操作数动作（GetVariable/SetMember/CallMethod 等）省略了 UI16 长度字段**，只有带数据的动作（Push/ConstantPool/DefineFunction2/Jump/If/Call…）才有 `code + UI16 len + data`。按标准格式硬解会在 `1C`（GetVariable）处立刻错位。最终以"172/172 个 DoAction 标签体被精确消费完"作为校验通过标准。
5. **PlaceObject2 旗标**：JPEXS 的 XML 里 `placeFlagHasCharacter(0x02)/HasMatrix(0x04)/HasColorTransform(0x08)/HasRatio(0x10)/HasName(0x20)/HasClipDepth(0x40)/HasClipActions(0x80)` 顺序与文件字段顺序一致；手写解析时容易把 bit 顺序搞反，**建议直接用 `-swf2xml` 的结果**。
6. **游戏逻辑实际在标签帧之后一帧**：`frame 119` 是 `game` 标签，`frame_120/DoAction.as` 才调 `Controller.startGame`。分析时别把两者当不同帧。
7. **反编译代码的可读性**：FFDec 对 AS2 的局部变量命名是 `_loc3_/_locN_`，需要结合 `Push` 常量与上下文自行还原语义；本文档的伪代码均已人工重命名。
