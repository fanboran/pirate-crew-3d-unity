# Pirate Crew 3D v0.1.0 — 发行说明

**把敌人的浮空岛轰进海里。** 回合制弹弓投掷对战——Unity 2022.3 写实 PBR 重制，向 Nitrome《Mutiny》致敬的非商业学习项目。

## 三个样板关卡（自由几何，告别方块拼接）

1. **云端漫步** —— 低模云朵平台场，11 朵云高低错落，主角云可驻一队
2. **双雄并舷** —— 两艘 28×14 放样大帆船并列，放样船体+双桅+帆装+索具，结构画全
3. **天空之岛** —— 超美浮空岛：草皮穹顶、半塌遗迹+悬浮主晶、水潭、瞭望台、浮石与云；专用碰撞壳，真站得上人

## 系统一览

- **三模式操作**（顶栏可点击 / 快捷键 1/2/3）
  - 移动：左键选角色，拖动环绕角色转视角，A/D 转向、滚轮力度、空格跳跃
  - 操作（炮台）：A/D 转向、W/S 力度、滚轮微调、回车开炮（左键只点按钮，防走火）
  - 观察：我的世界同款——鼠标转视角、WASD 平移、Space/Shift 升降；点击准星选角色即返回
- **17 种武器**：加农弹/樱桃炸弹/炸药/巨石/地雷/降落伞炸弹/朗姆酒瓶/加农炮/香蕉/八枚金币/船锚/海鸥/潮汐巨浪/巫毒娃娃/扫射火焰/木箱/火药桶（可连锁殉爆）
- **回合规则忠实原版**：每回合一名角色，可先跳一次再攻击；用武器即结束回合；落水即死
- **AI 对手**：原版 §6 行为模型（50 次自抛模拟落点 + 武器采样 + evilness 记仇加权），可切真人 2P 热座
- **预览=实弹**：轨迹预览与弹道逐步严格相等（固定时间步半隐式欧拉配平）
