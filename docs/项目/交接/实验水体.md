## 第二轮亲眼调试的根因清单（2026-10-14，供追溯）

1. **vDotN 符号反**（`dot(-viewDir,N)`）→ 菲涅尔恒 1 → 整片水=天空色；改正为 `dot(viewDir,N)`。
2. **法线 y 增益 ×6 过猛**：±0.12 的真实坡度被放大成 60° 斜法线 → 与视线点积归零 → 同样
   菲涅尔恒 1；降到 1.5。
3. **波太陡生成水跃（bore）**：λ10/幅 0.34 让无粘性 SWE 出现相邻格 0.5m+ 水深跳变 →
   法线编码饱和到 ±1 → 全片法线报废；波放缓（λ12/幅 0.26）+ 法线编码钳制 ±0.6 +
   渲染侧 slope 钳制三重防御。
4. **材质序列化陷阱**：改 shader 属性默认值对已存在的 .mat 无效（见上）。
5. **取景迭代**：侧透视 → 40° 俯视 → 48° 俯角中心压岸线向海侧；地形改两段式
   （缓坡浅水架 4.4% + 滩面 8%，收窄浪爬升带）。

## 第五轮：不规律波列 + 波影 + glitter（2026-10-14 深夜）

创始人反馈：水面太规律 + 要「阳光下波浪的影子」和「水面太阳高光」。

- **继续逆向实锤了波浪生成机制**（全 kernel 反汇编 + level0 场景实例裸字节直读，见
  [Sandcastle 水体逆向 §8/§9](../../技术/渲染/调研/Sandcastle水体逆向.md)）：
  环境浪 = 涌浪泵（spawnMap 带 `amount += 0.15·sin(相位)·dt`）+ 潮位松弛（全场向
  `seaLevel + amp·sin(t)` 松弛、每格 8bit 权重）；场景真值 gravity=16 / evap=0.1 /
  spawnRate=20 / floorBlur=3。五档 `WavesType` 预设的 a/b/c/d **定性不可恢复**
  （无 bundle、纯运行时构造，Cpp2IL v39 方法体乱码）——结构照抄、数值自推。
- **波列改造**（`WaterLabRules.WaveTrains`）：单正弦 → 四列波（λ 12/8.6/6.2/3.9 m，
  方向 ±25° 扇形展开、波长互质，深水色散 ω=√(gk)）+ 潮位呼吸（0.05 m / 9 s）。
  **顺带修了波源带 bug**：旧条件 `worldX < 4` 把半张域钉死在理想波上（「太规律」根因），
  改回 `x < -28` 真域边条带，浅化/干涉交给物理。
- **波影**：水面 renderer 开投影 + Ocean 加 ShadowCaster pass（顶点位移同主 pass）；
  沙/水两个 forward pass 采样主光阴影（`Shadows.hlsl` + `multi_compile _MAIN_LIGHT_SHADOWS*`；
  **CommonMaterial.hlsl 要先 include**——Shadows.hlsl 的 `LerpWhiteTo` 不在 Core 链里，
  实测 undeclared identifier）。ShadowCaster 片段里 `clip(eta - 0.12)` 只让波峰脊投影、
  干区与平坦水面 discard——否则整张水面网格在沙滩投死灰平面影（第一轮灰沙滩根因）。
- **glitter**：太阳方位转到相机对面（L=(-0.525,0.669,-0.525)，同侧时反射路径 dot≈0.026
  整条在画外——第二轮海面无闪点根因）；Roughness 0.08→0.06、GlitterPower 48→90、
  强度 3.2→3.6、微法线 0.09→0.11；BuildScene 先删材质目录再重建（新默认才吃得到）。
- 出图组合入口：`WaterLabSetup.BuildSceneAndCapture`（单次 Unity 带图形 batchmode：
  重建场景→武装截图器；**不能走 HeadlessChain**——截图器异步武装会被链式器提前收口）。
- harness：WaterLab 域 9/9 绿（新增波长互质/方向展开、深水色散/高程有界两条）。

## 第五轮调试追加教训（实拍 8→15 轮，2026-10-15 凌晨）

1. **【最重要】截图链 linear-as-sRGB 缺陷**：Linear 工程下 `BattleHudScreenshot` 的
   `ReadPixels`+`EncodeToPNG` 把 linear 值直写 PNG（诊断帧实证：shader 输出 0.70，
   字节恰为 178=0.70×255）→ **所有历史出图系统性偏暗偏灰，一直在误导调参方向**。
   已加 `PC3D_CAPTURE_SRGB=1` 选通修正（默认关，战斗截图链不动）。此后 WaterLab 出图
   一律带这个变量；对着无修正旧图调的参数全部偏亮，本轮已按真彩视图回调。
2. **水面不能采自己的阴影**：水面网格是波峰 ShadowCaster，水面像素再采主光阴影时
   视线里全是自己的浪脊 → sunAtten≈0 → glitter/GGX 全灭（第七轮无闪点根因）。
   波影只落沙床/滩面（Sand shader 采样 + 水下沙不采——水下变暗由水体吸收承担）。
3. **glitter 波瓣宽度必须盖住法线散布**：四列波法线扰动 ±30°，`pow(dot,60)` 时
   dot 只到 0.95-0.98、0.95^60≈0；诊断帧（glitter/dotRS/sunY 三通道出图）实锤后
   降到 pow12 + 中频波纹（~2.4m，全距离无淡出）幅度加倍，碎金闪出得来。
   太阳耀斑是**加法项**（×菲涅尔会被正入射的 fresnel≈0.03 压死）。
4. **两组等权交叉正弦沙纹 = 波腹节点格架**，滩面满场静态软点阵（放大实证）；
   改单向为主（0.75/0.25 权重）后消失。
5. 太阳方位角必须与相机对侧（L=(-0.525,0.669,-0.525)），否则反射闪耀路径整个在画外。

- **细节法线贴图**：`WaterLabDetailNormal.cs` 程序化生成（256² 可平铺值噪声六倍频 →
  法线 xy，带 mipmap），shader 双尺度 0.05/0.20 + 时间×0.8 动差混合（原作同参数）；
  碎金 = pow(NdotH,600) 镜面瓣（原作 1500，因贴图密度 1/16 放宽）+ 次级宽瓣 0.02。

### 未决问题一/二：已逆向闭环（第八轮，2026-10-15）

两条未决问题已按「逆向工具链」对原作拿到实锤，完整证据与公式落
[Sandcastle 水体逆向 §10](../../技术/渲染/调研/Sandcastle水体逆向.md)：

1. **水底波影真机制**：原作水面**没有 ShadowCaster**（Lit_Water blob 全量扫描只有
   2 VS + 2 PS）——波影不在水体侧。它在 Lit_Sand PS 的直射项：
   `ndl × 太阳 × (阴影原值 × exp(−0.721×水深))`，其中水深是**逐像素双线性**采的
   水侧模拟场（22bit 定点；Ground 全 24bit，排除地面 AO 误读）。波浪经过 → 水深
   振荡 → 水下沙直射光明暗带；天光第二盏不采影不衰减（浅水亮绿松石的原因）。
   阴影无软化——`min(sh+0.25,1)` 只存在于水体 PS 的散射项。
2. **浪形真机制**：Lit_Water VS 全文无三角函数——顶点 Y = 高度场 4 邻盒式平均，
   法线 = 格子速度字节。浪面轮廓 100% 来自 SWE；原作泵源是 **λ≈41.6 m 单条长涌浪**
   （spawnMap 相位 0.0378 rad/格），「不规律」= 长涌在缓坡浅化陡化成 bore +
   细节法线 + Whitewater 白水粒子（W4）。此前本仓 λ3.9–12 m 相对 64 m 域太短，
   是「正弦感」的根因。

**本仓已按证据对齐**：沙 shader 直射项改「原值阴影 × exp(−0.721×水深)」+ 闪沙项
（干沙噪声闪烁，原作 Lit_Sand 实证）；水体 shader 删 ShadowCaster、散射权重改
NdotV⁵ / 底色曲率 ndv⁶ / 镜面乘原值阴影（§4.1 三处误记已原位修正）、解析折射底色
补「阴影@折射点 × 水柱透射」（原作底色=沙渲染纹理，等价物必须同光）；波列改
λ 40/21/11/5.9 长涌主份；装配器恢复细节法线绑定（排查态遗留）、水面 renderer
关投影。

### 第九轮待办：还差什么没抄（创始人 2026-10-15 问，只列差异不做决定）

**直接嫌疑——水底波影为什么还看不见（按嫌疑排序）：**

1. **海底可见路径不同构**：原作水体是**不透明队列**，水底 100% 由水 PS 折射采样画出——
   沙侧 exp(−0.721×水深) 明暗与水侧 8.656σ 吸收在同一条路径叠加，对比全额保留；
   本仓 URP 透明队列，真实沙网格以 (1−alpha)=minT 权重直接漏出，波带对比被亮沙冲淡
   （近岸奶白同一根源）。这是当初定的 URP 约束（`_CameraOpaqueTexture` 自采样），
   但有没试过的替代路（自定义 opaque-only 捕获、双 pass 等）——做不做是裁决。
2. **浅水水深振幅比**：原作浅水架是卷浪 bore，水深 0→0.3 m+ 摆动，exp(−0.72d) 给
   ±20%+ 直射调制；本仓 λ40/幅 0.16 在 0.3–0.5 m 水深只有 ±12%，影子对比先天弱。
   WavesType 数值抄不到（§8），幅值/周期需按 bore 观感自推。
3. **体素 GI（Gi 8 kernel）完全未逆向未复刻**：原作沙的天光/间接项真值未知，本仓
   Flat ambient 的 ambient/sun 配比是拍的——ambient 偏强会冲淡直射项明暗带。
4. **后处理链**：自研 SRP 的 HDR/曝光/tonemap——同线性值过他们的曲线对比度不同；
   本仓 URP 直出。
