## 实机走查清单（创始人验收用）

1. 开局自由镜头：按住右键飞行观察（横纵灵敏度应一致）；左键点己方单位 → 镜头**平滑**环绕该单位（无瞬跳）。
2. Esc 矩阵五情形：自由镜头按 Esc 开暂停 / 暂停中按 Esc 恢复 / 选中按 Esc 取消选中 / 操作中按 Esc 取消操作 / 确认弹窗开时按 Esc 关弹窗。
3. 换人：未行动时点另一己方单位应切换；跳跃落地后（已消耗移动）点别人应无响应。
4. 操作中相机锁定：按住右键转视角应无响应；A/D/W/S/Space/Shift 调三参数，操作 HUD 读数同步刷新。
5. 预览：弧线积分到落点截断（不入地）；落点环恒显；起点约在单位胸口高度。
6. 执行：回车发射 → 相机跟随弹体/角色 → 落定后（跳跃）回到该单位浏览态；（武器）回合推进回自由镜头。
7. 暂停期间预览隐藏、参数保留（恢复后继续瞄准）；P 键任何状态可暂停。
8. 手感调参点（数值全部提案/待定，验收后定案）：`StandardThrowRules` 常量区 /
   `BattleInputReader` 灵敏度 / `BattleCameraDriver.freeFlySpeed` / `orthoSmoothingPerSecond`。
9. 状态条与两档取景（2026-10-05 反馈轮新增）：底部状态条两行随状态刷新（操作中第一行含
   「跳跃」或武器名，第二行键位提示）；Tab 或滚轮在自由镜头/浏览态切近景⇄远景（平滑无跳变），
   操作中/执行中锁定当前档；预览珠点沿弧线由大到小、落点环带指向箭头且被角色正常遮挡。
