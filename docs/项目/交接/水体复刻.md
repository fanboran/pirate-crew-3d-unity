## 6. 已知坑

- **frida 17**：`Memory.readX` 已删→用 `p.readFloat()` 等原型方法；`NULL` 是保留标识符（用 NULLP）；`il2cpp_class_get_method_from_name` 的 argc 按 il2cpp 计数（`*_Injected` getter=2，普通属性 getter=0）；console.log 要 `script.set_log_handler` 才进输出文件。
- frida attach 报 `VirtualAllocEx 0x5` = 游戏没开；bridge 库（frida-il2cpp-bridge）对 Unity 6.2 metadata v39 初始化挂起，**不可用**，一律手写 il2cpp 导出（模板 rt/agent.js）。
- typetree：sharedassets0 的 MonoBehaviour 3679 个仅 189 可读；**原生类（Transform/Mesh/Light/GameObject）可读**。MonoBehaviour 解不了走 ①C# 字段偏移（cpp2il diffable）②frida 运行时 ③裸字节+已知布局。
- npm 坏（代理证书链）；要 JS 库直接 npmmirror tarball。
- Unity batchmode 必须 `-projectPath`；WaterLab 出图**必须带图形**（禁 -nographics）；一次只能一个 Unity 进程。
- 材质序列化陷阱：.mat 不跟 shader 默认值走；`Color` 属性在 Linear 工程会被再 gamma 一次（物理量用 Vector 下发）。
- 仓库 autocrlf=CRLF；worktree 检出后 AmbientAssetBuilder 已在分支内修复（f6b98059），纯 HEAD 可编译。
