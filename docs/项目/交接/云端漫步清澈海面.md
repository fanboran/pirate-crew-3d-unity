## 实机走查清单（验收看什么）

1. 进第 1 关：无洋红、Console 无 shader 报错；描边与像素化（PostLine）与改动前一致。
2. 水面：海床透得出、水色是青绿的一层；岛影在水面上是一整块深色、海床上同位置也偏冷；
   阳光区有漂移的浅色亮带与零星碎金，岛影里没有焦散和碎金。
3. 水下：沙丘起伏读得出（脊顶暖沙、洼地偏青）、沙纹是平行细线；海草摆动且**没有墨线**；
   珊瑚、海星、螃蟹、气泡读固有色；鱼群只有自带的深色轮廓，隔水看得出是鱼。
4. 鱼群：都在水下（没有露出水面的鱼），游过沙脊时抬、游进洼地时沉；螃蟹贴沙横爬。
5. 投影：云台、单位、海鸥在云面与水面上有硬影；鱼在沙面上有影。
6. 涟漪：云瀑落水点与海面上有扩散的像素同心环。
7. 镜头拖动 / 旋转：水下画面不闪烁、墨线不抖。

## 排查记录（下次别再踩）

- **鱼群「浮在水面之上、水盖不住」**：不是渲染顺序。`CloudSeaLife` 算贴床净空时用了
  `sharedMesh.bounds`——FBX 鱼群对象带 90° 旋转与 100 倍缩放，本地包围盒是 0.0x 的小数，
  乘缩放后把水平半宽当成了半高，整群被顶到水面上方。改用 `Renderer.bounds` 换算回根空间。
  **判据**：先读运行时坐标（探针/日志），别从画面反推管线。
- **`[Header(中文)]`**：ShaderLab 只接受 ASCII，中文标题让整段 Properties 解析失败，
  表现是 shader 名为空、全场景不渲染、没有编译报错。
- **目测不可靠**：缩略对比图上误判过「岛影丢了 / 水变灰」，逐像素采样后与基准完全一致。
  颜色类结论一律采样，暗色「鱼形块」要先放大看形状（那批是海鸥的影子）。
- **出图取景**：`PC3D_CAPTURE_ORTHO` 受相机驱动的正交下限约束，拉不进到下限以内；
  特写用默认机位出图后裁切放大。
- **FBX 导出不是字节确定的**：Blender 每次导出都重分对象 UID 与时间戳，重跑总装后 Unity
  下次启动必重导入。几何没改就不用重烘（子资产 ID 按名字散列）；改了几何才需要跑烘焙链。
