## 一、裁决落成的目标架构

```
删除前（四代同堂）                     删除后（单一内容路径）
─────────────────────                ─────────────────────
L1 M2瓦片竞技场（33关+战役3×5）   →    【删除】
L2 Showcase样板三关               →    保留（美术样板/宣传层）
L3 WorldKit 8张海域图             →    保留（唯一战斗内容）
L4 Blender管线样板                →    保留（岛体升级主线）
战斗进场五级分发                   →    世界图单路径
战役元循环挂 level_01..15          →    改挂海图 id（wreck_hymn…）
```

**两个既定设计决策**（执行者不必再问）：
1. **Battle = 世界图单路径**：`BuildPlan` 的
   `ArtReview覆盖 > 世界图 > 场景level资产 > 战役注入 > fallback` 五级链，
   前四级中一代相关的三级全删，世界图成为唯一来源。
2. **战役元循环重指向海图**：星级/经验/招募/存档（M3 闭环）保留，
   结算 key 从 `level_01` 改为海图 id（如 `wreck_hymn`）；
   `CampaignCatalog`（3 章×5 关）删除，存档键 `campaign_level_stars` 的值域变为海图 id 集合
   （旧档不迁移——项目未发布，弃档即可，SaveManager 版本号+1）。
