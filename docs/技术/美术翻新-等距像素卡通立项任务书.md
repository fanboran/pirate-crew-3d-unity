## 0. 立项定位

### 0.1 目标一句话

把现有游戏的**全部视觉层**重建为「等距像素卡通」（**俯角固定 30° 正交＋方位角可自由旋转**〔2026-09-22 裁决〕+ 赛璐璐色带 + 反壳描边 + 像素纹理 + 全屏像素化 + Beveled Pixel UI），玩法、数值、架构零改动，终态以一屏样张确认、以全场景实拍收口。

### 0.2 范围声明

**不动（受保护资产）**：战斗纯逻辑与 17 武器数值（1161 EditMode + 7 PlayMode 测试）、纯 C#/MonoBehaviour 两层与五程序集、EventBus/存档/音频、M2 空间契约（XZ + 45°）、8 世界图 + 样板两关内容数据（L1/L3）、烘焙器三层分离架构（[管线合并任务书](架构/管线合并-糖豆人式资产架构任务书.md)）、ArtGate/播放器/判据脚本机器、`PixelationRendererFeature` 与 `PirateOutline` 反壳 pass 骨架。

**重建（本立项工作量）**：11 个自写 shader 的观感层（赛璐璐化/减配/退役）、132 个材质重生成、写实观感栈退役（后处理六件套/SSAO/昼夜雾氛围/写实水体）、49 件 FBX 分批翻新（平滑法线 + 像素纹理）、UI 第二轮换装（Beveled Pixel）、验收判据体系重建。

**不做（明确排除）**：海战/大世界（AGENTS 远期）、33 关全量重制（远期）、FLIP 交互液体（候选）、任何玩法数值改动、关卡设计文档终审（独立线，不因视觉翻新阻塞）。

### 0.3 执行支柱（五条，全计划由此推导）

1. **样张先行**：新观感先在垂直切片上试点并过审，旧观感栈才批量退役——项目任何时刻都有「能看的画面」，不存在中间裸奔态。
2. **调色板是全局风格令牌**：一张 32~64 色板同时约束 3D 色带/暗部选色、资产量化、UI 浮雕与 INK——风格统一靠板（3D 侧的 StickTokens 思想）。
3. **演进式量产**：像素化兜底全局观感，资产分批翻新、每批评估降档，不回头重做存量。
4. **判据自证**：每条验收判据先用正反对照校准（能区分目标效果与其它成因），证据无损入库——步骤 1「口头完成」事故的制度化纠正。
5. **会话收口即提交**：每个里程碑拆到「单会话可收口」粒度，收口即提交——配额中断保险（交接 §24 教训）。

## 2. 技术方案总纲（六个子系统一页纸）

| 子系统 | 方案 | 规格出处 |
| --- | --- | --- |
| 赛璐璐着色 | 新 `PirateCrew/Toon`：显式非等宽阈值阶梯（2~3 档，每档阈值+颜色独立暴露）＋**替换式预制暗部色**（板内选色，非 shader HSV）＋`step()` 硬切主路径+羽化参数＋Bayer 4×4（中点归一化，作用于档位选择值）＋单光静态 uniform（跳过 shadow variant）＋顶点色 R 阈值偏移（Xrd） | 渲染篇 §4 / 调研-赛璐璐 |
| 反向壳描边 | 现有 `PirateOutlineHull` 骨架常驻化：INK 墨色＋ToonRP 正交线宽公式（`2/RT高 × px`，C# 下发 RT 高，xy 不二次归一）＋`Offset 1,1` 防 z-fight；平滑法线=角度加权+位置容差，程序化件 Unity 侧烘焙、Blender 件文件名后缀自动烘焙 | 渲染篇 §5 / 调研-反向壳 |
| 像素化与相机 | 已落地两段 nearest blit（CoreBlit pass 0）；**补相机 snap 两步法**（视空间 snap 到 texel 网格＋上采样 UV 反向补偿，接进 `BattleCameraController`）；**俯角固定 30° ＋ 方位角可自由旋转**（2026-09-22 裁决）；四条顺序红线（含「一切颜色处理在 360p 域内完成」） | 渲染篇 §1/§2/§2.1/§3/§3.1 / 调研-全屏像素化 |
| 调色板与量化 | 32~64 色板（OkLCH 明度阶梯 + 加勒比色相档案，png+json 双产出）；锁板映射在 OkLab（加权距离、暴力纯函数）；抖动仅 Yliluoma ordered 且**默认关**；误差扩散禁用；PNG 编码参数与输入哈希锁定（重跑逐字节一致）；帧级锁板为演进项（渲染篇 §7） | 资产篇 §4/§5 / 调研-量化 |
| 纹理与导入 | 纹素密度 32px/m ±0.5%＋每面 Jacobian 长短轴比 <1.01（texel 方正）；Point / mip off / **固定 RGBA32（BC7 除名）**；结构线 2px 画进纹理 | 资产篇 §1/§3/§6 / 调研-量化 |
| UI | Beveled Pixel 生成器（九宫格：基色+上左高光/下右阴影+INK 外描边+按压 1px 位移与明暗对调）；令牌从调色板派生；StickUI 底座沿用换皮不换骨 | 美术指南 §5 / UI设计语言（待重写） |

## 4. 里程碑 M0–M5

> 度量单位=会话（非承诺工期）。每格含：目标 / 工作项 / 交付与门禁 / 裁决点。

### M0 · 基线纠偏（1 会话）

**目标**：让「像素化在跑」成为创始人亲眼确认的事实，并把验收判据体系换成能自证的。

- 0.1 配置漂移销号（清单与证据见[美术翻新技术口径审计报告](../审计/专项/美术翻新-技术口径审计报告.md) §1）：~~MSAA~~ **已修**（两档 `m_MSAA: 0`，`UrpSetup.cs` 写入值同步为 `hdr: false, msaaSampleCount: 0`——否则重跑安装脚本会静默翻回 4x/HDR；改后无头验证退出码 0、零编译/shader error）；**待修**：①Battle 场景 Bloom/Tonemap/Vignette 实开（随 M2a，须先定裁决 D1 柔光机制）；②全屏 Sobel 描边 Feature 仍在两档 Renderer 挂载（Performant 档 `maskLayer=Everything`）；③Depth/Opaque Texture 双开（Opaque 无消费者）；④两档不一致（shadowDistance 224 vs 25、ColorGradingMode HDR 与 HDR 关矛盾）。
- 0.2 台阶周期判据工具化入库（强边缘列间距 mod 3 均值：像素化=0.00 / 连续≈1.0，已用正反图校准）；入库证据规范补「原生分辨率 PNG 无损裁剪样张」（JPEG 仅浏览图）。
- 0.3 用户路径复现验收：编辑器 Play（Game 视图）+ 播放器双路径各出一组图，创始人亲眼确认；顺带确认此前查看路径（Scene 视图被 Feature 显式排除，是「看不到效果」的候选原因之一）。
- 0.4 与创始人对齐预期：像素化/正交是**不可见基座**，观感转折点在 M1 样张。

**门禁**：EditMode 全绿；创始人确认基座在跑。**产出**：判据工具 + 修订判据下的基线截图组。

### M1 · 风格样张（2-3 会话）【项目级门禁：过审才开 M2/M3/M4】

**目标**：一个岛台 + 一个船员 + 海面同屏的一张图，让「方向公式」从文档变成看得见的画面。规格全部来自 §2 总纲。

- 1a Toon shader（§2 规格，含 DebugMode 分层与硬切/羽化参数）。
- 1b 反壳描边常驻化（INK + ToonRP 线宽公式 + Offset；平滑法线烘焙 v0：程序化件 Unity 侧角度加权+位置容差；顶点色通道分配按裁决点 #8 定案）。
- 1c 相机 snap 两步法（`PixelationRendererFeature` 放大 blit 加 UV 偏移入口；正交 size 按整数像素步进）＋按裁决重烘机位：俯角 45°→**30°**（值引用像素化口径 `PixelartPilotScene.PitchDegrees`）、方位角 45° 作为**基准**由 `M2BattleSceneSetup` 烘进 FollowOffset（走装配链重烘）、`BattleCameraController.OrthoPitchDegrees` 同步、**右键环绕保留为现役玩法**（2026-09-22 裁决「左右可以随便旋转」）、`BattleSceneWiringTests` 相机断言改写。
- 1d 调色板 v0（OkLCH 阶梯 + 加勒比档案；png+json 入库）。
- 1e 同屏样张：岛台 + 船员 + 海面（海面用减配占位——色带平涂或关掉写实特性，真方案 M2f 裁决）；样张**含一个世界图机位**（全景档可读性预检，风险 R9）。
- 1f **对照出图包**（一次会话收齐创始人裁决所需全部对照）：硬切 vs 羽化、SSAO 开/关、后处理栈开/关、描边 1px/2px、正交 size 现档 vs 重定档、**俯角旧 45° vs 裁决档（30°；35.264° 一版已废）**、天空盒三档色板形态。

**门禁**：read_console 零 shader error（play mode 后）；出图判据（贴图/色带唯一色数 ≤ 板色数、洋红 0、台阶判据、UI 不块化）；**创始人样张过审**。
**裁决点**：#1 方向确认、#2 硬切/羽化、#3 描边粗细、#4 正交 size（俯角已裁决固定 30°、方位可自由旋转）、#5 雾与天空、#8 顶点色通道、#9 全景档可读性。

### M2 · 观感栈退役 + 管线工程化（2 会话，依赖 M1 过审）

**目标**：全游戏切到像素卡通基底，资产量产管线就位。M1 已用开关对照证明的退役项在此批量执行。

- 2a 后处理六件套拆解（Bloom/SMH/WB/Vignette 删；tonemap/CA 按裁决 #6）。
- 2b SSAO + 全屏 Sobel 描边 Feature 退役（含两档配置不一致修复）。
- 2c Opaque 关、阴影死配置清理、Depth 按海面方案定。
- 2d AmbientDirector 收编（单光左上 + 扁平环境光 + 三档天空色板；雾按裁决 #5）。
- 2e 材质工厂换血：两个工厂 + 两处运行时兜底 Lit→Toon；`Kit_*.mat` 28 个重生成；`PirateSurface` 减配为过渡 shader；四步装配链重烘。
- 2f 像素海面落地（按裁决 #7；Gerstner 骨架去留随之定）。
- 2g 量化链工程化：Blender 导出模板三件（平滑法线/量化并入/密度校验 ±0.5%+Jacobian）；OkLab 转换单测（Ottosson 官方测试表）；确定性纪律（输入哈希/PNG 编码锁定）；调色板 v1 定稿（吸收 M1 反馈）。

**门禁**：EditMode 全绿 + 播放器 shader error 0（构建日志当场存文件）+ 8 世界图与样板两关全量出图判据 + 重烘焙逐字节回归零漂移。
**裁决点**：#6 tonemap、#7 海面方案、待定项 #5（纹素密度试产校准）。

### M3 · 资产量产（4-6 会话，分批推进，可与 M4 并行）

**目标**：49 件 FBX 按「视线焦点 > 单位 > 远景」顺序分批翻新。

- 每批标准流：Blender 重导（平滑法线 + UV 密度达标）→ bake→量化→png → 导入（Point/mip off/RGBA32）→ Toon 材质接纹理 → 重烘 → 出图验收。
- 单位翻新特殊约束：**模型不改铁律**——只加顶点色/纹理数据不动网格；帽/身独立网格的接缝断线按 M1 试点结论处理；朝向档（待定项 #8）随本批裁决。
- 每批后像素化强度评估降档（待定项 #3 演进）。
- 若待定项 #1 裁「逻辑格子+视觉软化」：边缘扰动/装饰压缝在本里程碑落实。

**门禁**：每批出图（唯一色数 ≤ 板色数、无洋红、块化判据）；批间回归零漂移。

### M4 · UI 换装 Beveled Pixel（2-3 会话，可与 M3 并行——UI 域文件独立）

- 4a 生成器（九宫格程序化 + 按压 1px 位移与明暗对调）；Beveled 令牌从调色板派生（与 3D 板同源闭环）。
  **参照与几何已备齐**（2026-09-22）：创始人指定的三张图入库 `docs/images/ui-pixel-ref/`（两张 Terraria 截图片段 + 一张像素工具对话框，后者提供控件明度分级与焦点态词法），并已逐像素量出斜面结构（2px 基本单位、外圈暗环→斜面→**内侧暗线**→填充、框架只用同色相三档明暗、格子件字形单元 16px）——**生成器照那张几何表写，不要重新猜**。参照素材另有 137 张成就图标与 41 张 UI 原始件在 `external/terraria-ref/`（版权原因不入库）。

## 9. 判据三律（步骤 1 事故的制度化）

1. **自证**：判据先用正反对照校准——必须能区分「目标效果生效」与「其它成因」（台阶判据：像素化图 mod3=0.00 vs 连续图 ≈1.0；块内方差教训：区分不了像素化与画面本平）。
2. **无损**：入库证据保留原生分辨率 PNG 无损裁剪样张；JPEG 仅作浏览图（1280 宽 JPEG 会把 3px 台阶抹掉）。
3. **在用户路径验收**：Game 视图/播放器出图有效；Scene 视图被 Feature 显式排除，永远看不到像素化——验收与排障不得以它为准。
