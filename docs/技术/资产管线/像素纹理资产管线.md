# 像素纹理资产管线

> **这份文档是什么**：新美术方向（[美术风格指南.md](../../设计/美术风格指南.md)）的**资产生产口径**——纹理规格、量化流程、导入设置与 Blender 管线适配。归属"烘焙器岗位"（[管线合并-糖豆人式资产架构任务书.md](../架构/管线合并-糖豆人式资产架构任务书.md) 的三层分离不变，本文为烘焙器新增步骤的规范）。
> **调研依据**：[调研-调色板量化与纹素密度](调研-调色板量化与纹素密度.md)（色彩空间选型/抖动方式/密度校验/压缩格式的核验结论；本文条款与其冲突时以裁决为准并回写调研文档）。

## 1. 纹素密度（Texel Density）

- **全项目锁一个值：每 Unity 米 = 32px**【AI 提案·待首轮试产校准】。
- 含义：1m 见方的表面分配 32×32 纹素。船员（约 1m 出头）→ 全身贴图 32~48px 覆盖；岛台主结构按此换算贴图尺寸。
- 建模/UV 展开时就按该尺度铺——**密度不统一 = 点采样下闪烁与粗细不均的直接来源**。
- **这个值必须与目标档位的屏幕像素密度对齐**：`ppm = RT高 ÷ (2 × 正交size)`（[渲染篇 §3.1](../渲染/渲染管线-等距像素卡通.md)）。`1 纹素 = 1 屏幕像素` 是像素质感成立的条件；现役特写档（size 5、RT 高 360）= 36 px/米，与 32 同档（纹素略密 12%）；全场档 10.6、全景档 3.8——**那两个档位下纹素被缩到 1/3~1/8，纹理里的结构线与砖缝必然消失**。翻新验收按目标档位复算 ppm，不按 32 单值验收【AI 提案】。
- 由此**结构线宽度按屏幕像素定、不按绝对纹素定**：§5 的"2px 深色线"在 36 px/米 下是 2 屏幕像素（比手绘像素画的砖缝粗一档），在 10.6 px/米 下只剩 0.6 像素（丢掉）。统一口径写成 **1 屏幕像素 ≈ 1/ppm 米** 的线，密度档变化时随板重画【AI 提案】。

## 2. 尺寸规范

| 用途 | 尺寸 |
|---|---|
| 主结构贴图（岛台/船体/地面块） | 64 / 128（POT） |
| 小物件（箱/桶/道具） | 32 / 64 |
| UI 图标 | 32（逻辑 1x，见美术指南 §5 整数倍纪律） |

## 3. 导入设置（Unity 侧，三条关键 + 一条隐藏坑）

| 项 | 值 | 理由 |
|---|---|---|
| Filter Mode | **Point** | 像素硬边 |
| Generate Mip Maps | **Off** | 正交固定相机无"远处"；mip 只带来闪烁与糊 |
| 压缩格式 | **固定不压缩（RGBA32）** | BC1/BC3/DXT 把 4px 以下色块压脏；**BC7 也除名**——端点插值的解码色必然落在调色板外（破「全局锁板」+ 破坏字节级回归 diff，调研 §5）；64/128 尺寸下不压缩内存完全可接受 |
| sRGB | 勾 | — |

## 4. 生成路径（接现有 Blender 无头管线）

```
Blender 材质照常制作（平涂色块风格）
  → 无头脚本烘焙到低分辨率
  → 量化减色（锁进全局调色板，见 §5）
  → 输出 png（确定性：固定种子/无随机，重跑逐字节一致）
```

- 量化脚本做成**确定性**的——复用仓库既有的 diff 工具即可做纹理回归对账（改了烘焙参数，diff 产物像素级可查）。
- **锁板映射在 OkLab 空间做**（调研 §1）：加权距离 `ΔL² + w·(Δa² + Δb²)`、暴力 O(N×板色数) 纯函数匹配（无数据结构差异 = 跨机器逐字节一致）；RGB 欧氏距离系统性偏色；转换用 Ottosson 公开矩阵并以官方测试表做回归单测。
- **抖动只允许 ordered（Bayer / Yliluoma 任意板混合模型）且默认关**（调研 §2）：手绘按板色作画时映射误差≈0，flat 纹理上的抖动在点采样下是永久噪点；误差扩散（Floyd–Steinberg/Riemersma）全线禁用——顺序敏感 = 像素级回归 diff 的大敌；混合必须在线性光内。
- **确定性收尾**：锁 PNG 编码参数、量化前校验输入文件哈希；k-means 只许用于「一次性生成板」且固定 random_state——**锁板之后整条链零随机数**。
- 法线/金属/粗糙度贴图**全部不要**：Unlit 或自定义 lit + 平涂像素纹理就是全部。

## 5. 调色板纪律（3D 侧的"令牌"）

- 全局主调色板 **32~64 色**（明暗各档 + 主题色相，色相取向见美术指南 §3.2），存为可共享的调色板文件（如 png/ase/gpl 任一，脚本可读即可）。
- **板内结构用 OkLCH 明度/彩度阶梯生成**（保证明度梯队均匀，抖动/明暗过渡干净）；现成板素材走 Lospec JSON API（`lospec.com/palette-list/{slug}.json`，调研 §3）。
- 所有资产量化时**锁进这张板**——风格统一靠板，不靠逐图手调。
- **内部结构线画进纹理**：船舷棱线、甲板边缘、木板缝等深色结构线直接画在贴图上，不靠 shader 判定（稳定且省事）；线宽不锁绝对 2px，按屏幕像素定（1 屏幕像素 ≈ 1/ppm 米，换算见 §1）。

## 6. Blender 导出模板新增（一次性，全资产受益）

> **执行体已落地**：`tools/blender/pixel/`（工具用法、参数、实测口径与版本差异见
> [Blender导出模板使用说明.md](Blender导出模板使用说明.md)）。本节是**规格**，那份是**用法**；
> 三条与本节的差异以那份为准并已在其中说明：① `mesh_smooth_type` 在 Blender 5.2 的枚举里
> **没有 "Normals Only"**（2.8x 时代的选项名），自定分裂法线改经 `SMOOTH_GROUP` 传递；
> ② 顶点色数据通道导出必须选 `colors_type = SRGB`（实测 `LINEAR` 会做强制的 sRGB 线性化、污染数据）；
> ③ 现有 FBX **没有 UV**，密度校验落在"缺工序"而非"密度不对"上。

1. **平滑法线烘进顶点色**（custom split normals → vertex color）：反向壳描边的外扩方向数据（渲染篇 §5）；硬边模型不处理会在描边 pass 上裂开。算法=角度加权平均+位置容差合并；编码与通道选型见渲染篇 §5 / 调研-反向壳 §3（8bit 必须 `×0.5+0.5` 编码；顶点色属性名 `SmoothNormal`，与平涂色属性 `Col` **互斥不可混用**）。
2. 量化步骤并入烘焙器（§4 流程）；bake 用 Diffuse→仅 Color、1 sample、固定视图变换（Standard）——纯色传递天然确定（调研 §6）。
3. 导出 FBX 的纹素密度检查：`density = tex_size × √(uv_area ÷ world_area)`（px/米；**必须开方**——`uv_area × tex_size ÷ world_area` 的量纲是 px²/m²，只在 world_area=1 时数值碰巧相等），断言 **32px/m ± 0.5%**，外加每面 Jacobian 长短轴比 < 1.01（texel 方正性——点采样下非方形 texel 比密度误差更显眼）【AI 提案·Blender 侧无头校验脚本，可进 CI（调研 §4）】。**区间口径**：聚合密度与每面 Jacobian 是硬失败；单面密度对聚合值的偏离只计数（非均匀 UV 展开天然有分布）。

## 7. 资产翻新策略（演进式，不求一步到位）

- **存量资产不回头重做**：像素化后处理先兜住全局观感（渲染篇 §3），存量 PBR/平涂材质在像素化下已可接受。
- 新资产/翻新资产按本篇规格走；每翻新一批，全屏像素化强度评估调低一档（终点可能是轻像素化或纯像素纹理，美术指南待定项 #3）。
- 优先翻新顺序【AI 提案】：玩家视线焦点资产（岛台地面/船体）> 单位（贴图小、翻新快）> 远景装饰。

## 8. 验收判据

- 单资产：导入设置三项齐全（Point/mip off/不压缩）、纹素密度达标、量化锁板（贴图唯一色数 ≤ 调色板色数）。
- 回归：量化脚本确定性（重跑 diff 零差异）；出图判据走 AGENTS.md 程序化判图纪律。
