> 现行实现口径——相机怎么定、两个分辨率域怎么分、后处理链各趟干什么、缓冲怎么分、

## 1. 相机与投影

| 项 | 值 | 说明 |
|---|---|---|
| 投影 | **正交**（Orthographic） | 消灭 LOD/透视校正；屏幕空间描边与像素网格稳定的前提 |
| 俯角 | **固定 30°** | 菱形宽:高 = **2 : 1**（sinθ = 0.5 → 地面轴横移 2 像素 / 下降 1 像素的规则像素阶梯）——经典手绘像素等距网格。游戏内与出图**同一个定义**：`BattleCameraController.OrthoPitchDegrees` ← `PixelartPilotScene.PitchDegrees` |
| 旋转 | **俯角锁死 + 方位可自由旋转**（右键拖拽环绕是现役玩法） | 0 方位 = 45° 对称菱形；自由方位下两条地面轴的屏幕斜率不等、阶梯长短不一——明确接受的取舍 |
| orthographic size | 由**可见米数**反推（§3.1 取景锚）；游戏内取景常量以 `CameraFraming` 为准 | 像素网格与世界空间对齐 |
| 平移 | 相机本身**不做像素对齐**；世界空间叠加件（弹道预览 / 选择框）按 `PixelartCameraRig.SnappedViewOrigin` 对齐到艺术像素格网 | 像素完美平移两步法尚未接线（§10） |

### 1.1 投影比：俯角是唯一决定「像不像」的量

正交 + 方位角 45° 时，边长 s 的地砖投影为菱形，宽:高 = **1 : sinθ**——30° 给 2:1 的经典像素等距网格。

- **俯角与玩法零耦合**：弹道与落点判定全在三维空间语义上表达（[3D 空间模型对齐](../../3D空间模型对齐.md)），不含任何俯角量——改俯角只改画面、不改规则。
- **地面纹素在屏幕域纵向压缩**（30° 时 1:0.5）：全场景一致，读作等距风格本身；出图判读勿把该压缩误判为贴图做错。
- 场景烘焙 FollowOffset 由 `BattleCameraController.OffsetDirectionForPitch` 单向提供，走 `BattleScenePipeline` 重烘，不手改场景。

## 2. URP Asset 与全局设置

| 项 | 值 | 理由 |
|---|---|---|
| HDR | **关** | HDR 下色带渐变脏 |
| MSAA | **0** | 边缘平滑与像素化冲突（"灰边"头号来源） |
| Bloom | **关** | URP Bloom 跑在全分辨率域，光晕会被降采量化成块状辉光 |
| 深度纹理 / 不透明纹理 | **开** | 描边读 `_CameraDepthTexture`；透明水折射读 `_CameraOpaqueTexture` |
| 多光源 | ToonLit **只吃主光** | URP 原生多光源逐像素光照不参与色带 |
| 实时阴影 | 机制齐全：ToonLit 带 ShadowCaster pass，前向 pass 采主光阴影衰减；**战斗主光创建时不投影**（`BattleSceneLighting`） | 需要投影的关卡由场景件在运行时开（§6；第 1 关是 `CloudSeaSunShadow`，见 [云海.md](云海.md)） |
| Color Grading / Vignette | URP 后处理排在像素化**之前**（事件位见 §4）；LUT 可轻用，Vignette 慎用 | — |

资产分 **Balanced / Performant** 两档，按画质档选用（两档的阴影距离、级联数、软阴影支持不同）；
具体取值以 `Assets/Settings/URP/` 下的资产为准，不在这里抄数。

## 3. 这条路径是什么

**一句话：几何与着色都在全分辨率正常跑（ToonLit 前向），然后把颜色点采样降到低分辨率「艺术画布」，
在这一档上做屏幕空间描边，合成后用锐利放大上屏。描边在画布上算，所以线宽恒等于 1 个艺术像素。**

### 3.1 两个分辨率域

| 域 | 尺寸 | 谁在这里算 |
|---|---|---|
| **屏幕档** | `FineW × FineH`（= 艺术画布 × `pixelScale`） | **几何 + ToonLit 全分辨率着色 + 深度 / 法线缓冲** |
| **艺术画布**（低分辨率域） | `ArtW × ArtH`（= 屏幕 ÷ `pixelScale`） | **降采 / 描边 / 合成**（结果再锐利放大） |

**像素档位**：`pixelScale` 锁"一个艺术像素占几个屏幕像素"这个**整数倍数**（`PixelartCameraRig.PixelScaleDefault`），
画布尺寸由实际屏幕反推，与风格无关的档位规则在 `PixelScaleService`。
**不要退回"锁画布高度"**：那套只在屏幕高恰好是画布高的整数倍时成立，非整数倍时块边长在
相邻整数之间混排，症状是"全屏像素不齐、放大到 1:1 看却正常"。

**取景锚**：`worldPerPixel`（每艺术像素多少米）= 可见米数 × k ÷ 1080（`WorldPerPixelFor`）；
**可见米数是美术锚、不随 k 变**——换档取景不动、只变颗粒粗细。

**代码位置**：`pirate-crew/Assets/Scripts/PirateCrew/Rendering/PostLine/`（`PostLineRendererFeature` /
`PostLineEnvironment` / `PostLinePath` / `PostLineMaterialSwapper`）；两套风格共用的底座
`PixelartCameraRig` / `PixelartPath` / `PixelartShaders` 在同级的 `Pixelart/`；shader 在
`Assets/Resources/PixelartShaders/PostLine*.shader`。

### 3.2 物体材质（过渡形态，随 CellShade 线退役改掉）

- 现役材质资产以 CellShade 的物体 shader `PixelartObject` 为**本体**，而它没有标准前向 pass——
  PostLine 下物体能画出来，全靠 `PostLineMaterialSwapper` 在运行时把这类材质换成 `PostLineToonLit`
  的**派生材质**（取源材质的 `_BaseColor` / `_MainLightLevel → _Cuts` / `_DitherStrength`）。
- 派生时按材质名加两档 Palette 影调：**云体**（冷蓝灰暗面 / 暖白亮面 + 双层 Patch 噪声）与
  **海底自然物**（中性冷灰暗面）；判定名单在 `CloudSeaPath.IsCloudBodyMaterial`。
- 派生材质只存在于运行时，不污染场景序列化；运行时新生成的物体由 rig 定期调 `Refresh()` 补换装。
- **自带标准前向 pass 的 shader 不经换装、原样渲染**（云海家族、WaterLab 家族）。
- 新写的物体 shader 一律自带 `UniversalForward` pass，不要再依赖换装器。

## 4. 执行顺序（单相机 + 一个 Feature）

PostLine 下主相机就是正常的前向渲染相机（相机装配器把它的渲染器索引指到 `PostLine_Renderer`，
并停用 CellShade 专用的 Cast / 叠加透明相机）。

| 序 | 阶段 | 干什么 |
|---|---|---|
| 1 | 深度法线预通道 | 只画带 `DepthNormals` 通道的**不透明**物体，一趟同时产出 `_CameraDepthTexture` 与 `_CameraNormalsTexture`（§5） |
| 2 | 主光阴影图 | 画带 `ShadowCaster` pass 的物体（主光开阴影时才有） |
| 3 | 不透明 | ToonLit 的 `UniversalForward` pass 全分辨率出色 |
| 4 | 透明队列 | 水面 / 雨 / 光柱 / 涟漪等自带前向透明 pass 的 shader，按 URP 标准透明排序画 |
| 5 | URP 后处理 | 本仓关着（Bloom / HDR 均关） |
| 6 | **`PostLineRendererFeature`**（`AfterRenderingPostProcessing`） | 四趟后处理，见下表 |
| — | UI / HUD | 独立的全分辨率层，不进像素化链 |

`PostLineRendererFeature` 的四趟（同一个 `Execute` 里顺序录制，GPU 按序执行）：

| 趟 | 产物 | 干什么 |
|---|---|---|
| Pass1 降采 | 画布色 `_PostLineLowResColor` | 相机色点采样降到画布（取每块一个角纹素，不做块平均） |
| Pass2 Outline | 描边遮罩 `_PostLineLowResOutline` | 画布上算剪影 + 棱线 → RGBA 遮罩（§6.1） |
| Pass3 Composite | 合成色 `_PostLineLowResComposite` | `lerp(画布色, 遮罩色, 遮罩 alpha)` |
| Pass4 SharpUpscale | 相机色目标 | 锐利放大写回（§6.2） |

参照库的 Pass0（全分辨率颜色快照）在本仓省掉：渲染器的中间纹理恒在，相机色目标可读可写。

**入队门控**：只对 Game / SceneView 相机入队；Overlay 相机与（过渡期的）Cast 相机不像素化。

**先后是契约的一部分**：Outline 必须早于 Composite，且两趟在同一次 `Execute` 里录制——
Composite 读的描边遮罩是按全局名注入的，不在渲染图依赖里，分两次录制就可能出现读未写。

## 5. 缓冲

画布上三张临时纹理（尺寸随画布变化自动重建）：

| 缓冲 | 格式 | 过滤 | 语义 |
|---|---|---|---|
| `_PostLineLowResColor` | 继承相机目标（HDR 关 → 8 bit LDR） | Bilinear | 画布色 |
| `_PostLineLowResOutline` | **R8G8B8A8_UNorm** | **Point** | RGB = 线色，**A = 线强度**（合成趟的混合因子） |
| `_PostLineLowResComposite` | 同画布色 | Bilinear | 合成结果，交给 SharpUpscale |

遮罩用 Point 是为了合成时不串色；Bilinear 留在色图上是为了锐利放大时的边界过渡。

**两张输入是全分辨率引擎缓冲**：`_CameraDepthTexture` / `_CameraNormalsTexture`。本链声明要法线纹理，
URP 因此走**深度法线预渲染**（`DepthNormalOnlyPass`）而不是只写深度的 DepthOnly 预通道——
这一趟只收带 `DepthNormals` 通道、队列在不透明区间的物体。所以**深度纹理里只有写了 `DepthNormals`
通道的物体**，不是"不透明之后拷一份"；只写 `DepthOnly` 通道的物体同样不在里面。
这决定了描边能看见谁（§6.1），也决定了依赖场景深度的透明 shader 能"看穿"谁（§8）。

## 6. 着色数学（ToonLit）与描边

### 6. ToonLit 前向（`PostLineToonLit.shader`）

```
albedo = _BaseColor；Patch：世界 XZ 噪声过阈值 ⇒ _Color2 / _Color3（后判优先）
diffuse = (dot(N, L) + _Wrap) × _Steepness
diffuse = min(diffuse, 云影光值)                       // 云影先于色带
diffuse += (Bayer4×4(画布像素坐标) − 0.5) × 2 × _DitherStrength × 0.5 / _Cuts   // 开关 _UseDither
stepped = 色带量化（向上取档 + 档边界平滑带 _ThresholdGradientSize）
lit     = stepped × shadow                             // 主光阴影在量化**之后**乘
颜色    = albedo × (stepped × 光色 × shadow + _GlobalAmbientColor)   // 或 Palette 分支
```

- **主光方向 / 颜色**以每帧下发的 `_PixelartLightDirWS` / `_PixelartLightColor` 为准（与真实主光同源），
  在 `GetMainLight()` 之后覆盖它的方向与颜色；**阴影衰减始终来自 URP 阴影图**。
  未下发时回退 URP 主光 + 球谐环境光（材质预览不至于全黑）。
- **阴影在色带量化之后乘**：影子不会被色带"吃掉"，影深由主光的阴影强度决定。要做硬边两档的
  像素风投影，把主光的阴影强度拉满，衰减值才是 0 / 1 两档。
- **云影**：把世界点沿投影方向投到云层高度平面，采 `CloudNoise` 两层错开并随时间平移，
  整形后作为该点光照的**上限**取 min。常数（尺度 / 高度 / 速度 / 对比度 / 阈值 / 影底）在
  `PostLineEnvironment`，由它每帧兜底下发；它是飘动的噪声云影，不是云台自身的投影。
- **抖动**：4×4 Bayer，索引取**画布像素**（不是全分辨率像素）；满幅 = ±0.5 个色带档间距。
- **四 pass 共用一份 `UnityPerMaterial`**（HLSLINCLUDE 里定义一次）：UniversalForward / ShadowCaster /
  DepthOnly / DepthNormals；DepthNormals **直写归一化世界法线**（不写 `n × 0.5 + 0.5`）。
  其中真正让物体进深度纹理与描边的是 **DepthNormals**；DepthOnly 只服务于别的渲染器配置。
- **噪声图导入硬要求**：`_Noise2` / `_Noise3` / `_CloudNoise` 必须 sRGB + Bilinear + Repeat——
  阈值作用在线性域，导入组合错了覆盖率差数倍。

### 6.1 描边（画布上的屏幕空间描边）

每个画布像素取 3×3 邻域的视图空间深度与世界法线，做两条独立的线：

- **剪影（轮廓线）**：8 邻域里有邻居比中心**近**超过阈值 ⇒ 本像素出线。阈值随中心面的掠射角放大
  （防斜坡全长出线）；比较发生在**视图空间米**，与分辨率无关。
  **线色 = 最近邻像素色 × `_LineDarken`**——线自带物体固有色，不是固定墨色。
- **棱线（面转折线）**：4 个正邻的法线差做**方向对比度**（对面两邻差值取 max——曲面两侧等量变化 ≈ 0，
  真折痕单侧剧变才大），过阈值把中心色提亮。近剪影带内抑制。
- 邻域步长写死为 **1 画布纹素**，所以线宽恒为 1 艺术像素；剪影优先于棱线。
- 参数值以 `PostLine_Renderer` 资产为准（名字契约在 `PostLinePath`）。

**谁会被描边**——由物体 shader 带不带 `DepthNormals` 通道决定（且队列须在不透明区间），没有逐材质开关：

| 物体 shader 的通道 | 在深度纹理里 | 在法线纹理里 | 描边结果 |
|---|---|---|---|
| 带 `DepthNormals`（ToonLit） | ✓ | ✓ | 剪影 + 棱线 |
| 只带 `DepthOnly`，或两个都不带（透明件；刻意隐藏的水下生物） | — | — | 对描边隐形，但仍参与硬件深度测试 |

细碎物体（海草、鱼群、珊瑚）进描边会被画成噪点——给它们写不带 `DepthNormals` 通道的专用 shader
即可整体关掉描边，而不影响遮挡关系。

### 6.2 锐利放大（SharpUpscale）

```
uv      = texcoord + 平移补偿.xy              // 平移补偿未接线时恒为 0
px      = 画布纹素
fw      = clamp(fwidth(uv) / px, 1e-5, 1)    // 屏幕像素 : 画布纹素的密度比
blend   = smoothstep(1 − fw, 1, frac(uv / px − 0.5·fw))
color   = 采样(合成色, floor(grid) + 0.5 + blend)   // 块内取中心、边界 1 屏幕像素内过渡
```

整数倍放大（本仓 2:1）时过渡窗口宽恰为 1 屏幕像素——介于 Point 与 Bilinear 之间的"数学上平滑的锐利边"。
平移补偿量接的是 rig 预留的 `_PixelartSnapOffsetUv`，由相机 snap 的第二步下发；**本仓尚未接这一步**。

## 7. 出图与判据

**出图**：`PirateCrew.EditorTools.BattleHudScreenshot.CaptureHeadless`（**带图形**的 batchmode——
`-nographics` 不编译 shader）。进 Battle、按当前关卡连拍缩放档，PNG 无损落
`$TEMP` 或 `PC3D_CAPTURE_DIR` 指定的目录。出图风格恒为 PostLine。
常用环境变量：`PC3D_CAPTURE_LEVEL`（拍哪一关）、`PC3D_CAPTURE_CENTER_XZ` / `PC3D_CAPTURE_ORTHO`
（特写取景）、`PC3D_CAPTURE_HIDE`（隐藏指定对象做隔离对照）、`PC3D_PIXEL_SCALE`（像素档）、
`PC3D_CAPTURE_MIN_SIM_TIME`（等实验水体模拟到稳态）；全表以脚本为准。

**关卡出图口径**：机位只给"可见米数"，取景表是 `PixelartLevelScene`（一行一关）；各关同一组数、
不随地图跨度缩放（**人物大小才是锚**，否则"横向比观感"不成立）。游戏内取景见 `CameraFraming`。

**小地图顶视出图**（`-minimapOut <绝对目录> -minimapLevel <1..4>`）：为 HUD 小地图窗烘**顶视缩略底图**——
正上方正交一帧、场景 renderer 临时换平色材质（`PirateCrew/Minimap/TopFlat`，取色单源
`PixelartMaterialFactory.TryGetAlbedo`），纹素数 = 窗体内容区的艺术像素数（`TopViewFraming.TopViewTex*`），
PNG 落 `Assets/Resources/Minimaps/level-<关卡号>.png`。**这是出图期的平色直渲旁路，不参与像素化链**。

**判据**：`python tools/pixel-review/judge_pixelart_pilot.py <图片目录>`（在**无损 PNG** 上跑，别用入库 JPEG）。
判据项里依赖 CellShade 缓冲的几项（内线 A/B、连通域分布等）已随退役线作废；
块边长、跳变率、色数、亮暗跨度几项对 PostLine 仍然成立。

## 8. 改这条路径之前：静默失效点

这条路径的失效方式**很少报错**，多数表现为"某类物体不出现"或"画面不对"。已踩过的点：

1. **`PixelartObject` 材质在 PostLine 下必须经换装才可见**（它没有前向 pass）。换装器只认 shader 名
   恰为 `PixelartObject` 的材质；材质名字换错、或新建物体在补换装之前就上屏 = 整件消失且无报错。
   新物体 shader 自带 `UniversalForward` pass 就不依赖这条路。
2. **相机色目标必须是中间纹理**。PostLine 渲染器的中间纹理恒在；一旦变成后台缓冲，feature 跳过整条链
   并只告警一次（画面不像素化，但照样能跑）。
3. **全局量缺省不报错**：`_GlobalAmbientColor` 缺 ⇒ 未受光面纯黑；云影族缺 ⇒ 护栏退化为无影。
   两者由 `PostLineEnvironment` 每帧兜底下发，云噪声图必须在 `Resources/PixelartNoise/`。
4. **`SetGlobalColor` 不做 sRGB→线性转换**：全局颜色一律显式 `.linear` 后 `SetGlobalVector`；
   配色对账按线性语义读值。
5. **深度纹理来自深度法线预渲染**：不给物体写 `DepthNormals` 通道，它就不在 `_CameraDepthTexture` 里——
   折射深度门、按深度重建位置的效果会"看穿"它。刻意隐藏描边的同时要记得这一点。
6. **噪声图导入参数**（sRGB + Bilinear + Repeat）是着色正确性的一部分，不是美术偏好。
7. **shader 取用口**：shader 由 Resources 持有、经 `PixelartShaders` 取用；管线材质是资产、挂进
   feature 的序列化字段——只靠 `Shader.Find` 的 shader 在播放器里会被构建剥离。
8. **出图的世界相机是主相机**（不是已停用的 Cast 相机）：用 `Camera.main` 可能解析到停用相机，
   抓到空画面。
9. **叠加透明相机是 CellShade 专用件**：PostLine 下必须停用，否则它会把 feature 写回的颜色再覆盖一次。

自检：`PixelartCameraRig` 首帧打一行装配自检（相机、层掩码、两档尺寸、渲染器索引）。
这一行在、且出图有描边，才算这条路真的在跑。
