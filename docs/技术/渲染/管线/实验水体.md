## 2. 模拟层（W1）：浅水方程 compute

### 2.1 数据与分辨率

- **双分辨率**（Sandcastle 实证做法）：水域 256×256 格 @ 0.25 m（域 64 m），地形 128×128 @ 0.5 m；
- `RWStructuredBuffer<float4> _WaterCells`：x=水深 h、y/z=速度 vx/vz、w=泡沫浓度；ping-pong 双缓冲；
- `StructuredBuffer<float> _GroundCells`（地形高）、`RWStructuredBuffer<float> _Wetness`（湿沙）。
  湿沙与地形同分辨率即可（湿沙无高频行为）。

### 2.2 kernel 表（`WaterLabSim.compute`）

| kernel | 语义 | 依据 |
| --- | --- | --- |
| `HeightIntegration` | h += −dt·∇·(h·v)，干湿阈值以下格不流动 | Sandcastle 同名 kernel + 干湿 0.05 |
| `VelocityIntegration` | v += −dt·(g·∇h + damping·v)，速度限幅 | 同上 + `maxVelocity` 常量 |
| `AdvectFoam` | 泡沫半拉格朗日回溯 + 破碎生成 + 衰减扩散 | Sandcastle Advection + Whitewater 输入侧 |
| `WaveSource` | 域边条带行波注入 + 全场潮位松弛（见下） | Sandcastle UpdateAmount 实证机制（逆向档案 §9） |
| `WetnessStep` | 湿沙浸润 + 蒸发 + 邻域扩散 | Sandcastle Ground 读 waterCells 的湿沙渗透 |
| `OutputField` | η/法线/泡沫打包 ARGBHalf 写 RenderTexture | WaterSimulationDriver 发布模式 |

调度序（固定步长 1/60 累加器，沿 `WaterSimulationDriver` 先例）：
`WaveSource → HeightIntegration → VelocityIntegration → AdvectFoam → WetnessStep → OutputField`。

**波源机制（复刻 Sandcastle 实证结构，参数自推）**：`WavesProperty` 预设的 a/b/c/d 四列
Vector3 数值不可恢复（运行时构造，Cpp2IL v39 方法体损坏）——本仓按同构自推：
- **四列入射波**（`WaterLabRules.WaveTrains`）：主涌浪 λ 40 m（对齐原作泵源的
  λ≈41.6 m——逆向档案 §9/§10：渲染端无程序浪形，「不规律」=长涌在缓坡浅化陡化成 bore），
  次级 λ 21/11/5.9 m 互质小幅纹理、方向扇形展开；
- **浅水色散**：相速 ω=k·√(g·h带)（h带=波源带静水深）。域内全是浅水长波，SWE 特征速
  √(gh) 不色散——用深水色散 ω=√(g·k) 会把长波相速强迫到特征速之上（超临界），带内激波化；
- **带内速度配对**：行波深度平均速度 u=c/h·(η−潮位)。直接钉 celerity=√(gh) 是 ~8× 过驱，
  30× 快进长时程实拍爆成全场短波垃圾+泡沫满格（二者均为 capture 46/47 实证）；
- **域边条带松弛**：`x < −32+4` 带内向波列目标强松弛（带外自然传播，浅化/折射交给物理；
  曾误写 `x < +4` 钉死半张域，实拍修正）；
- **潮位松弛（权重 ∝ 水深）**：带外全场向 `SeaLevel + 0.05·sin(2πt/9s)` 松弛，权重 =
  潮位松弛深度系数 × 局部水深 × dt——原作 UpdateAmount 的结构（`amount += 水场×(1/15)×间隙`，
  干处权重 0）。均匀权重对行波是指数阻尼（旧值 0.25/s → 衰减长度 ~14 m，λ40 涌浪没到岸
  就被吃光、水底波影调制 <1%，第九轮解析+转储双实证），改深度比例后浅水架近乎无阻尼，
  涌浪活着冲上滩；代价是潮位呼吸在浅水跟踪率大降，swash 群性改由涌浪本身承担。
- **Shapiro 网格滤波**：带外全场每步 `h -= ε×(h − 4邻均值)`（`GridFilterEps=0.08`）。
  弱阻尼 + 弱松弛下 2 格棋盘模无人压制（旧体系两阻尼项恰好兼职压着它），η 场长出
  ±0.5 m 级逐格锯齿——破碎判据全场误触发 → 泡沫饱和成白幕、相干长波被散射殆尽
  （近岸时域波幅 0.010 m，Python 实验室与 GPU 稳态转储双实证）。滤波对 2dx 模半衰
  4 步、对 λ40 每秒仅损 0.4%、质量严格零和。

### 2.3 数值纪律（纯 C# 单源 `WaterLabRules`）

规则全部写成不依赖 Unity 的静态类（本仓铁律：核心逻辑无头可测）：

- **CFL**：dt·√(g·h_max)/dx ≤ 0.5 断言（`WaterSimRules` 同思路的保守系数）；
- 域边海绵层（offshore 出流 + 三侧反射按需），σ 平方曲线沿 `WaterSimRules.SpongeSigma`；
- 破碎判据、湿沙渗透/蒸发系数、地形剖面公式、波源参数（波长/周期/振幅）全在参数表；
- compute kernel 的算子与这些公式**双写但公式单源**：C# 侧同一组公式以小规模 CPU 参考实现
  存在（harness 测试用），compute 是吞吐版——两者由测试钉住同一组数值契约。

## 3. 渲染层（W2）：URP 前向单 pass 水体

`WaterLabOcean.shader`（单文件，本仓惯例），LightMode=UniversalForward，透明队列：

1. **VS**：世界 XZ 采样 `_WaterLabHeightTex`（RGBA32：R=水面高程）顶点位移；
2. **PS**（Sandcastle 指令流还原 + HPWater 增强）：
   - **深度安全屏幕折射**：偏移 = N.xz × `_RefractionFactor`；采 `_CameraDepthTexture`
     线性化比对，仅当折射点更远才采用（防采到前景）；
   - **光程**：InvVP 重建折射点世界坐标，d = |worldRefract − worldSelf|；再叠加
     **HPWater thickness 项**：d' = d·(1 − 波峰因子·crest)，波峰处光程缩短（薄层透亮）；
   - **Beer–Lambert 吸收**：T = exp(−σ_t·d')，三通道 σ_t 材质参数（起点 R≈0.5 G≈0.12 B≈0.06 /m
     【提案】）；折射色 = 背景色 × T + `_ScatterColor`（暖橙，Sandcastle 实测 (0.57,0.36,0)）× (1−T)；
   - **菲涅尔** pow5 混天空色（环境色近似，不做反射探针）；
   - **GGX 太阳高光**（阴影本实验场单光源直射，不做 shadowmap 采样——地形自遮挡不存在）；
   - **泡沫混合**：模拟泡沫浓度 w 通道 → 白水色 lerp（浓度高处偏 `groundColor` 灰调）。
3. 前提：URP `m_RequireDepthTexture/m_RequireOpaqueTexture` 现役开 → 折射直接可用；
   Linear 色空间。

## 4. 海滩层（W3）：湿沙与泡沫观感

- `WaterLabSand.shader`：地形着色 = 干沙 albedo 与湿沙 albedo 按 `_WetnessTex`（模拟输出）lerp
  （湿沙深且饱和），沿高度叠 2–3 条层理色带（Strata 思路的程序化版）；
- 水下地形透过水体折射可见（吸收着色），水线以上湿沙带随浪线移动；
- 泡沫场在水体 shader 内渲染（单 pass，不做独立透明层——避免透明排序问题）。
