> **本文是什么**：海浪模拟实验线的技术方案——以 [Sandcastle 水体逆向](../调研/Sandcastle水体逆向.md)
> 的架构（GPU 浅水方程 + 海滩耦合 + 泡沫场）为主参考、HPWater 的 BSDF 技法为质感增强，
> 在本仓 URP 管线上做「沙滩 + 海浪 + 湿沙 + 泡沫」的高度实验性场景。
> 与[像素海面](像素海面.md)（F1–F7，现役像素化路径的海面翻新线）是**姊妹线**：本线验证
> 模拟与质感，**不动 Battle 现役**；像素化收口（SWE 输出 × 锁板色带如何融合）是将来的一次独立裁决。
>
> **已裁口径**（创始人 2026-10-14）：实验场景走 **URP 前向写实直渲染**（独立相机，不接
> PixelartCameraRig 三相机栈）；本轮范围 **W1–W3**（模拟内核 + 水体渲染 + 海滩交互），

## 2. 模拟层（W1）：浅水方程 compute

### 2.1 数据与分辨率

- **双分辨率**（Sandcastle 实证做法）：水域 256×256 格 @ 0.25 m（域 64 m），地形 128×128 @ 0.5 m；
- `RWStructuredBuffer<float4> _WaterCells`：x=水深 h、y/z=速度 vx/vz、w=泡沫浓度；ping-pong 双缓冲；
- `StructuredBuffer<float> _GroundCells`（地形高）、`RWStructuredBuffer<float> _Wetness`（湿沙）。
  湿沙与地形同分辨率即可（湿沙无高频行为）。

### 2.2 kernel 表（`WaterLabSim.compute`）

| kernel | 语义 | 依据 |
| --- | --- | --- |
| `HeightIntegration` | h += −dt·∇·(h·v)，干湿阈值以下格不流动 | Sandcastle 同名 kernel + 干湿 0.05 |
| `VelocityIntegration` | v += −dt·(g·∇h + damping·v)，速度限幅 | 同上 + `maxVelocity` 常量 |
| `AdvectFoam` | 泡沫半拉格朗日回溯 + 破碎生成 + 衰减扩散 | Sandcastle Advection + Whitewater 输入侧 |
| `WaveSource` | 域边条带行波注入 + 全场潮位松弛（见下） | Sandcastle UpdateAmount 实证机制（逆向档案 §9） |
| `WetnessStep` | 湿沙浸润 + 蒸发 + 邻域扩散 | Sandcastle Ground 读 waterCells 的湿沙渗透 |
| `OutputField` | η/法线/泡沫打包 ARGBHalf 写 RenderTexture | WaterSimulationDriver 发布模式 |

调度序（固定步长 1/60 累加器，沿 `WaterSimulationDriver` 先例）：
`WaveSource → HeightIntegration → VelocityIntegration → AdvectFoam → WetnessStep → OutputField`。

**波源机制（复刻 Sandcastle 实证结构，参数自推）**：`WavesProperty` 预设的 a/b/c/d 四列
Vector3 数值不可恢复（运行时构造，Cpp2IL v39 方法体损坏）——本仓按同构自推：
- **四列入射波**（`WaterLabRules.WaveTrains`）：主涌浪 λ 40 m（对齐原作泵源的
  λ≈41.6 m——逆向档案 §9/§10：渲染端无程序浪形，「不规律」=长涌在缓坡浅化陡化成 bore），
  次级 λ 21/11/5.9 m 互质小幅纹理、方向扇形展开；
- **浅水色散**：相速 ω=k·√(g·h带)（h带=波源带静水深）。域内全是浅水长波，SWE 特征速
  √(gh) 不色散——用深水色散 ω=√(g·k) 会把长波相速强迫到特征速之上（超临界），带内激波化；
- **带内速度配对**：行波深度平均速度 u=c/h·(η−潮位)。直接钉 celerity=√(gh) 是 ~8× 过驱，
  30× 快进长时程实拍爆成全场短波垃圾+泡沫满格（二者均为 capture 46/47 实证）；
- **域边条带松弛**：`x < −32+4` 带内向波列目标强松弛（带外自然传播，浅化/折射交给物理；
  曾误写 `x < +4` 钉死半张域，实拍修正）；
- **潮位松弛（权重 ∝ 水深）**：带外全场向 `SeaLevel + 0.05·sin(2πt/9s)` 松弛，权重 =
  潮位松弛深度系数 × 局部水深 × dt——原作 UpdateAmount 的结构（`amount += 水场×(1/15)×间隙`，
  干处权重 0）。均匀权重对行波是指数阻尼（旧值 0.25/s → 衰减长度 ~14 m，λ40 涌浪没到岸
  就被吃光、水底波影调制 <1%，第九轮解析+转储双实证），改深度比例后浅水架近乎无阻尼，
  涌浪活着冲上滩；代价是潮位呼吸在浅水跟踪率大降，swash 群性改由涌浪本身承担。
- **Shapiro 网格滤波（四阶、x/y 两轴分离）**：带外全场每步逐轴施加
  `h -= ε/16×(h₊₂ − 4h₊₁ + 6h − 4h₋₁ + h₋₂)`（`GridFilterEps=0.16`）。弱阻尼 + 弱松弛下
  2 格棋盘模无人压制（旧体系两阻尼项恰好兼职压着它），η 场长出 ±0.5 m 级逐格锯齿——
  破碎判据全场误触发 → 泡沫饱和成白幕、相干长波被散射殆尽（近岸时域波幅 0.010 m，
  Python 实验室与 GPU 稳态转储双实证）。传函 `T = 1−(ε/4)(1−cos k)²` 单调不放大：
  λ2 保留 0.84/步、λ40 每秒损 <0.1%、质量严格零和。
  【为什么必须四阶】旧二阶 `h−ε(h−4邻均值)` 对 λ4–8 格每步衰减 8–2%，恰好把涌浪浅化
  陡化出的 **bore 陡 front 当噪声吃掉**——波到水线摆幅 0.50→0.21 m 腰斩（r11 转储），
  水底波影随之微弱；四阶在 λ2 同杀（0.84/步）前提下 λ4 保留 0.96、λ6 保留 0.99，
  front 幸存、bore 成立（r12 出图：陡浪锋 + 跨枪移动的水底暗带）。

### 2.3 数值纪律（纯 C# 单源 `WaterLabRules`）

规则全部写成不依赖 Unity 的静态类（本仓铁律：核心逻辑无头可测）：

- **CFL**：dt·√(g·h_max)/dx ≤ 0.5 断言（`WaterSimRules` 同思路的保守系数）；
- 域边海绵层（offshore 出流 + 三侧反射按需），σ 平方曲线沿 `WaterSimRules.SpongeSigma`；
- 破碎判据、湿沙渗透/蒸发系数、地形剖面公式、波源参数（波长/周期/振幅）全在参数表；
- compute kernel 的算子与这些公式**双写但公式单源**：C# 侧同一组公式以小规模 CPU 参考实现
  存在（harness 测试用），compute 是吞吐版——两者由测试钉住同一组数值契约。

## 3. 渲染层（W2）：URP 前向单 pass 水体

`WaterLabOcean.shader`（单文件，本仓惯例），LightMode=UniversalForward，
**不透明队列**（Geometry+2400，排在沙 2000 之后；ZWrite On，无 Blend、无 ShadowCaster）——
与原作同构：水色是连续颜色项而非 alpha 混合层（原作 Lit_Water blob 只有 2 VS + 2 PS，
无深度-only pass，水面不投影）。

1. **VS**：世界 XZ 采样 `_WaterLabHeightTex`（RGBA32：R=水面高程）顶点位移；
2. **PS**（Sandcastle Lit/Water PS 逐指令还原，逆向档案 §4.1）：
   - **法线** = 模拟坡度场 + 细节法线贴图双尺度（20m/5m 平铺）**相加**合成
     （lerp 会把两套标定梯度各稀释一半），远端淡出兜摩尔（贴图自带 mip）；
     贴图为程序化**域扭曲+脊状 fbm**（`WaterLabDetailNormal` 生成器：长程蜿蜒连通脊线
     与原作抽图形态同型，R/G std 自标定到原作同统计 33/255；四版对照记录见交接档）；
   - **解析水底**：视线水下段延伸至地形，折射扭曲后读地形/湿沙纹理，用与
     `WaterLab_Sand` 同式的沙光照出「透过水看到的底」——直射项乘
     「阴影@折射点 × exp(−0.721348×水深)」（水底波影机制，常数精确到反汇编字面量）；
     **焦散**按原作 Lit_Sand 输出结构加法叠加（`+ albedo×焦散`，不经阴影，随 T 衰减）：
     原作为引擎侧焦散 RT（材质槽 causticsMap，按水模拟域 UV 采样），本仓用真实水面的
     η 拉普拉斯聚焦因子现算（凹面亮/凸面暗，图案与浪同源同频，增益 0.2 有界不削顶）；
     不采样任何屏幕捕获纹理（Depth/Opaque 纹理零依赖）；
   - **Beer–Lambert 吸收**：T = exp(−8.65617·σ_rgb·dist) × 水色（8.65617 为原作 PS
     字面量；dist 是视线水下段真路径长度，不是 depth/vDotN 近似）；
   - **基底/散射混合**：col = lerp(底色×T×(0.9+0.2·NdotV⁶), 散射色,
     NdotV⁵×阴影软化×0.75)——散射权重随俯视增大，阴影软化只接在散射项；
   - **太阳镜面**：单瓣 pow(NdotH,1500) × 阴影原值，不乘菲涅尔（Lit_Water PS 全文仅
     一对 log+exp=pow，无第二宽瓣/GGX——「GGX 宽瓣」旧记系同一项误读，指令计数纠正；
     第十二轮一度自造 pow48×0.6 宽瓣致浅水 44%→28% 削顶，第十三轮按严格对标删除，
     削顶回落 2%）。亮网观感 = 原作式长连通脊贴图的碎金随相机距离在屏面融合成网；
   - **光照色（原作场景灯实测）**：太阳 `(1.0,0.9709,0.9403)×1.0`、天光第二方向光
     `(0.0627,0.1333,0.2196)×1.0`（解析水底与沙面共用，无自造增益）；
   - **泡沫**：模拟破碎通道 lerp 白水色（岸线白水属 W4 Whitewater 粒子，水体 PS
     无泡沫项——逆向档案 §10.3）。
3. **不透明直出的理由**：水色完全自包含（解析水底×吸收），「透明度」只是透过率调制
   底色亮度；透明队列的 alpha=1−min T 对水深指数敏感，近岸薄水处叠加上掠射压缩会
   产生蓝白骤变，不透明化后该伪影类整类消失，近岸回归原作的连续颜色结构。Linear 色空间。

## 4. 海滩层（W3）：湿沙与泡沫观感

- `WaterLabSand.shader`：地形着色 = 干沙 albedo 与湿沙 albedo 按 `_WetnessTex`（模拟输出）lerp
  （湿沙深且饱和），沿高度叠 2–3 条层理色带（Strata 思路的程序化版）；
- 水下地形由水体 shader 的解析水底呈现（吸收着色），水线以上湿沙带随浪线移动；
- 泡沫场在水体 shader 内渲染（单 pass，不做独立层）。
