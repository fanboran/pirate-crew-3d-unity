# 双风格切换

> **提案（2026-11-08，待实机验收）**：本文定义游戏内两套像素化渲染风格的指代名、共用口径与切换架构；规格细节见两份调研档
> [PostLine 规格](../调研/PostLine规格.md)、[CellShade 缺口规格](../调研/CellShade缺口规格.md)。
> 像素比口径：**两风格共用 2:1**（960×540 艺术画布 @1080p，创始人 2026-11-08 裁决）——不跟随任一参照库的原始内部署分辨率。

---

## 1. 两个指代名

此前文档混用「v3」「参考库/参照库」，两个外部参照项目指向不清。本文起用两个唯一代号，**本仓技术文档一律用新名**：

| 代号 | 全称 | 参照库 | 许可 | 渲染哲学 |
| --- | --- | --- | --- | --- |
| **PostLine** | 屏后描边线 | `external/ref/unity-isometric-pixel-pipeline`（作者 Bababuyyy，Unity 6，HEAD `f08bc6b`） | MIT | **全分辨率着色** → 低分辨率后处理：降采 → 屏幕空间描边（剪影=邻色压暗 / 棱线=方向对比度提亮）→ 合成 → 锐利上采样 |
| **CellShade** | 单元着色线 | `external/sloane-urp`（作者 SL0ANE，Unity 2022.3.43f1，原「v3」） | MIT | 7 张 G-buffer（超采样）→ 连通域（Check/Flood/Result）→ **低分辨率域着色**（色带/内线降档/高光/GI/边缘光）→ 帧级调色板 → 点采样上屏 |

两者的共同骨架相同：**先产出一张低分辨率「艺术画布」，再上屏**。分野是**着色发生在哪一档分辨率**：
PostLine 在全分辨率着色、靠后处理把边画在降采后的画布上；CellShade 物体 pass 只写数据、着色搬到低分辨率域。

**命名纪律**：新代码、新文档、新资产命名一律用 `PostLine` / `CellShade`；旧文档中的「v3」在改到该文件时顺手替换（`v3蓝本.md` 暂无改名必要，其内容即 CellShade 规格）。

## 2. 共用口径

| 项 | 口径 |
| --- | --- |
| 像素比 | **2:1**（960×540 @1080p；`pixelScale=2`，随屏幕档位走现有 `PixelScaleState`） |
| 相机 | 30° 俯角、正交、可见 22.5 m（现行战斗基准；不照抄 PostLine 的 20°/CellShade 的 Celeste 6.125） |
| UI/HUD | 两风格共用；UI 走像素化透明叠加趟，不参与风格切换 |
| 场景/关卡 | 共用；两风格的差异只发生在像素化渲染链内部 |

## 3. 切换架构

### 3.1 单一开关

- 运行期真值 `RenderStyleState.Current`（静态，仿 `PixelScaleState`），取值 `PostLine` / `CellShade`。
- 持久化：设置存档新键（与音频/视频同槽，读改写）；出厂默认 `CellShade`（现役观感）。
- 切换入口：**设置页「渲染风格」两档**（主菜单设置面板）；调试菜单/快捷键供开发期快速对照。
- 切换生效方式：**热切换**——rig 每帧比对真值枚举，变化即切换主相机 Renderer 索引并启停 Cast 相机；
  不重载场景，战斗中途切换不丢对局。两套 Renderer 的 feature 天然隔离；PostLine 渲染器未装配时
  告警并回退 CellShade（不静默降级观感）。

### 3.2 两套 Renderer 资产

| 风格 | Renderer 资产 | 相机结构 |
| --- | --- | --- |
| CellShade | `PixelartCast_Renderer` + `PixelartScreen_Renderer`（现役） | 双相机：Cast（G-buffer + 全部特征）+ Screen（上屏）；`PixelartCameraRig` 现状 |
| PostLine | 新增 `PostLine_Renderer`（4 pass：Downsample/Outline/Composite/SharpUpscale；URP14 下省 CopyColor） | 单相机：主相机全分辨率渲染 + 后处理链；Cast/Overlay 子相机不启用 |

两套资产都注册进 URP 渲染器列表；`PixelartCameraRig` 按 `RenderStyleState` 决定初始化哪一套（启/停子相机、绑定 renderer index）。

### 3.3 材质换装（切风格时换材质，切回还原）

两条链的物体 shader 数据流不同（一条写 7 张 G-buffer、一条全分辨率前向着色），**不合并成双 pass**，
由 `PostLineMaterialSwapper` 在切换到 PostLine 时遍历场景，把 `PirateCrew/Pixelart/PixelartObject`
材质换成 `PirateCrew/PostLineToonLit` 的派生材质（取源材质的 `_BaseColor` / `_MainLightLevel` /
`_DitherStrength`，云材质另加 Palette 影调与 Patch 噪声）；切回 CellShade 时原样还原。

- 不污染场景序列化：派生材质只存在于运行时，`Exit()` 用原始材质数组覆盖回去。
- 运行时生成的单位/地形由 `Refresh()` 增量补换装（rig 在 PostLine 模式下定期调用）；幂等集合防重复。
- 换装成本只在切换瞬间与新增渲染器时；未换装成功的物体在 PostLine 下按源材质渲染（观感不同但不崩）。

## 4. 特性对照（两库 vs 本仓）

| 特性 | PostLine | CellShade | 本仓现状 | 迁移动作 |
| --- | --- | --- | --- | --- |
| 剪影描边 | 屏幕空间 8 邻域深度边，线色=邻色压暗 | 逐物体覆盖膨胀墨线 | PostLine：屏幕空间后处理（已接）；CellShade：逐物体黑墨 1px（现役） | 已落地，二者按各自规格并存 |
| 棱线 | 方向对比度 + 提亮 | 连通域降档内线（压暗一档） | PostLine：画布上提亮（已接）；CellShade：法线差阈值 + 压暗（现役） | 已落地 |
| 上采样 | sharp（fwidth+smoothstep） | Point 最近邻 | PostLine：SharpUpscale（已接）；CellShade：Point | 已落地 |
| 色带 | ToonLit cuts/steepness/wrap | `multiStep` + 连通域 AA | 各自实现（PostLine 4 档 + 平滑带；CellShade 4 档 multiStep） | 已落地 |
| 抖动 | Bayer 4×4（屏幕/画布坐标） | 1-bit 密度图（贴物体） | PostLine：Bayer 画布坐标；CellShade：Bayer 贴艺术像素 | 已落地 |
| 高光 | 无（PBR 不参与） | 独立 Specular 缓冲（金锭闪光的来源） | CellShade：Specular 趟已有；材质默认 S/M=0，现给船员铜/铁试点喂入 | 参照 006 Gold 的金属观感有了载体 |
| 边缘光 | 无 | 逐物体 `_RimLightColor` × rim 光 + 连通域门控 + 两档量化 | CellShade：门控/两档量化/金属 tint 已接（ndotl 背光侧收窄为美术裁决，不接） | 缺 32 盏独立 rim 光列表（当前用主光方向） |
| 帧级调色板 | 无 | CIEDE2000 3D LUT → 2D 条带（参照库能力） | 已删除（裁决「彻底去掉配色限制」，本仓链路已清仓） | 不做 |
| GI | 无（扁平） | SH + 环境光 | CellShade：环境色 × albedo（简化）；PostLine：`_GlobalAmbientColor` 加数 | 已接环境光，SH/反射仍简化 |
| 云影 | 全局噪声云影（11 个全局） | 无 | PostLine：`PostLineEnvironment` 每帧下发（已接） | 参照 CloudShadowManager 常数 |
| 地形 patch | 世界噪声双色层 | 无 | PostLine：云材质双层噪声 + Palette 影调（已接） | 云台不再是纯白平面 |
| 草叶 | GPU instanced 草 | 无 | 无 | 单列评估（与草坪线三件待办合并） |
| 昼夜 | 有（Demo） | 无 | 无 | 不进本次范围（游戏固定光照） |

### 5.1 2026-11-09 保真审计结论摘要

两份逐项对账报告：

- [PostLine 复刻保真审计](../../../项目/审计/PostLine复刻保真审计-2026-11-09.md)
- [CellShade 复刻保真审计](../../../项目/审计/CellShade复刻保真审计-2026-11-09.md)

结论：**shader 数学内核基本逐行同源，破口集中在运行时接线与数据喂入**。已修：

1. PostLine 的 `_GlobalAmbientColor` 与云影 11 个全局原本**零写入**（环境恒 0 →
   未受光面纯黑、云影恒 1 无影）。现由 `PostLineEnvironment` 每帧下发；
   噪声图 `CloudNoise` 入 `Resources/PixelartNoise/`（MIT 归属见同目录 LICENSE）。
2. CellShade 的 `_PixelartAmbientColor` 原读场景烘焙 Trilight 深棕（线性 0.045）；
   现与 PostLine 同源读 `ambientLight × ambientIntensity`。第 1 关云端按关覆写为
   天空环境色 `#7E90A3 × 0.85`（`AmbientDirector.ApplySkyLevelAmbientOverride`）。
3. 云材质在 PostLine 下开 Palette（冷蓝灰暗面 / 暖白亮面）+ 双层 Patch 噪声，
   `_DitherStrength` 0.21→0.08；源 albedo 修正为"顶白 #FFFFFF / 底冷 #EDF4FB"。
4. 船员 `CrewBrass` / `CrewIron` 试点喂入 `_Metallic` 0.8、`_Smoothness` 1/0.75、
   `_RimLightColor`——这是参照 006 Gold 金属高光/边缘光的第一批数据载体。

仍缺（已登记，不在本轮范围）：

- PostLine 像素完美平移（相机 texel snap + `_PixelPanOffset`）——Spec §10。
- CellShade 帧级调色板：shader/feature/烘炉在盘、默认关、缺 LUT 资产。
- CellShade 32 盏独立 rim 光列表（当前用主光方向；门控/两档量化/金属 tint 已接）。
- PostLine 草地实例、昼夜（游戏固定光照，不接）。

## 6. 红线

- 像素比恒 2:1，不因风格切换改变艺术画布尺寸（只换着色/描边/上采样链）。
- 参照库只做源码级翻译改编，不 vendor 整包（AGENTS 参照库纪律）。
- 两条线共用场景与 UI，任何风格差异不得渗进场景序列化（材质换装只在运行时派生、切回还原即为此设计）。
- 切换是低频操作（设置页点击）；rig 的检测是每帧一次枚举比对，不做逐帧重建。
