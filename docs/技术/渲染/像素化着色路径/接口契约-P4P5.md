# 像素化着色路径 · P4/P5 补齐的接口契约

> **这份文档是什么**：P4（连通域 + 边缘光 + 多趟着色 + 合成 + v3 式屏幕空间描边）与 P5（帧级调色板）
> 补齐时**冻结的接口**：分辨率域、缓冲表（名字/格式/语义）、shader 全局名、pass 名、Feature 顺序、
> 文件域划分。**它不是变更记录**；是并行实现的互不冲突依据。
> 契约之外的名字一律不许自造（同 EventBus 事件名的纪律：拼错一个字母就是静默失效）。
>
> **上位文档**：现行口径 [像素化着色路径.md](像素化着色路径.md)；v3 源码逐行读通的结果
> [蓝图-新渲染管线-v3蓝本.md](蓝图-新渲染管线-v3蓝本.md)（下称**蓝图**）。
> 凡标【本仓口径】的是**故意与 v3 不同**处，理由在 §6；标【提案】的是待创始人追认的写法。
> **v3 源码**：`external/sloane-urp/Assets/SloanePixelartRenderPipeline/`（下称 `$P/`，参照库不入库）。

## 0. 三个分辨率域（本轮定型）

| 域 | 尺寸 | 记法 | 谁在这里算 |
|---|---|---|---|
| **屏幕档**（= v3 的超采样档） | `ArtW×k × ArtH×k`（k = `pixelScale`） | `FineW × FineH` | **几何 + 7 张 G-buffer + 深度**；连通域的 Check / Flood |
| **艺术画布**（低分辨率域） | `Screen ÷ k`（锁整数倍） | `ArtW × ArtH` | **描边 / 4 趟着色 / 合成 / 帧级调色板 / 结果** |

**为什么几何在屏幕档**（照 v3，创始人 2026-09-22 裁决）：v3 的艺术画布 320×180、G-buffer 1600×900
= 画布 × 5 = 它的**屏幕分辨率**——即"几何/G-buffer 就是常规延迟渲染的 G-buffer，全分辨率"，
省 fill rate 的是**着色那几趟**（只有画布那么多像素）。本仓同构：G-buffer 画在屏幕档，
着色与描边画在艺术画布。降采是隐式的——**点采样取到的就是"块中心那个纹素"**，
与"直接在艺术画布上光栅化"逐点等价（块中心连续坐标 `id*k + k/2` 同时是画布像素中心的放大像）。

**像素密度口径**（创始人 2026-09-22 裁决：`k = 3`、**保取景**）：
`worldPerPixel = 可见米数@1080p ÷ (1080 ÷ k)`。可见米数是**美术锚**，不随 k 变：
广角 28m、中景 18m、近景 8m ⇒ k=3 时分别是 0.07778 / 0.05 / 0.02222 m 每艺术像素。
1080p 下画布 640×360、1440p 下 853×480（可见 28m→37.3m 不变）。

## 1. 缓冲表

### 1.1 屏幕档（`FineW × FineH`）—— 7 张 MRT + 深度

| 缓冲 | shader 全局名 | 格式 | 语义 | 对应 v3 |
|---|---|---|---|---|
| Albedo | `_PixelartAlbedoBuffer` | ARGB32 | rgb = 亮部色；**a = 覆盖标记** | `_AlbedoBuffer` |
| Normal0 | `_PixelartNormal0Buffer` | ARGBHalf | **屏幕空间几何法线** `normalize(cross(ddy(positionWS), ddx(positionWS)))` | `_Normal0Buffer`（连通域输入） |
| Normal1 | `_PixelartNormal1Buffer` | ARGBHalf | 切线空间法线贴图→世界法线（无贴图时= 平滑法线） | `_Normal1Buffer`（着色用） |
| Physical | `_PixelartPhysicalBuffer` | ARGBHalf | r = 光滑度；g = 金属度 | `_PhysicalPropertyBuffer` |
| Shape | `_PixelartShapeBuffer` | ARGBHalf | r = 优先级（**预留 0**）；g = 未用（写 0）；b = 法线边阈值；a = AA 缩放 | `_ShapePropertyBuffer` |
| Palette | `_PixelartPaletteBuffer` | ARGBHalf | r = 主光档数；g = 抖动标量（0..1，中心 0.5）；b = 边光档数；a = **applyOutline**（0/1，逐物体描边开关） | `_PalettePropertyBuffer` |
| RimLightProperty | `_PixelartRimLightPropertyBuffer` | ARGBHalf | rgb = 逐物体边缘光色 | `_RimLightPropertyBuffer` |
| Depth | `_PixelartDepthBuffer` | depth 24（**可采样**） | 深度；着色里用来重建 `positionWS`（阴影坐标与附加光都要） | `_DepthBuffer` |

v3 的第 8 个输出 `_LightmapUVBuffer` **不做**（v3 自己也没接通，蓝图 §2 注意 2、§7.3 第 7 条）。
缓冲格式**不跟 v3 的 `SNorm16` + `PackFloatInt8bit` 字节打包**——本仓直存（蓝图 §2 注意 1：那套换格式即静默失效）。

### 1.2 艺术画布域（`ArtW × ArtH`）

| 缓冲 | shader 全局名 | 格式 | 语义 |
|---|---|---|---|
| ConnectivityResult | `_PixelartConnectivityResultBuffer` | ARGB32 | `r` = 单元内连通比例；`g` = 连通或更近比例；`b` = 单元内最大法线差；`a` = 打包的四方向 connected/closer（v3 §3.3） |
| **Outline** | `_PixelartOutlineBuffer` | ARGB32 | `r` = **墨线标记**（1 = 本像素是墨线）。**本仓新增的一档**——描边不再是几何壳，见 §4.4 |
| Diffuse | `_PixelartDiffuseBuffer` | ARGBHalf | rgb = 漫反射着色；a = 1（合成 `clip(a-1)` 用） |
| Specular | `_PixelartSpecularBuffer` | ARGBHalf | rgb = 高光累加 |
| GI | `_PixelartGIBuffer` | ARGBHalf | rgb = 环境光项（本仓简化为 `环境色 × albedo`） |
| RimLight | `_PixelartRimLightBuffer` | ARGBHalf | rgb = 边缘光累加（先清空） |
| PaletteLut | `_PixelartPaletteLut` | RGB 条带 | 帧级调色板 LUT（尺寸与采样公式照 v3 `Shared/Blit/ColorCorrection.shader`） |
| ResultBuffer | （Cast 相机的 `targetTexture`） | ARGB32 | 最终结果，`FilterMode.Point` |

### 1.3 连通域中间档（屏幕档）

| 缓冲 | shader 全局名 | 格式 | 语义 |
|---|---|---|---|
| ConnectivityDetail | `_PixelartConnectivityDetailBuffer` | ARGB32 | 逐方向打包 bit7 connected / bit6 closer / bit5 center |
| ConnectivityPrev | `_PixelartConnectivityPrevBuffer` | ARGB32 | Flood 的 ping-pong 备份 |

## 3. Feature 顺序（Cast 渲染器，数组顺序即入队顺序；装配器写入）

| 序 | Feature | 时机 | 职责 |
|---|---|---|---|
| 1 | `PixelartBeforeRenderFeature` | `BeforeRendering` | 视图矩阵平移 snap；下发 `UnitSize`/`FineUnitSize`/四个尺寸；算上屏 UV 补偿量存进 rig |
| 2 | `PixelartObjectFeature` | `AfterRendering` | 清屏幕档目标 → `DrawRenderers(ShaderTagId("PixelartOpaque"))` 写 7 MRT + 深度 → 把 7 张 + 深度设成全局 |
| 3 | `PixelartConnectivityFeature` | `AfterRendering` | Check（屏幕档）→ Flood × `max(1,Mathf.RoundToInt(k*1.5))`（屏幕档，ping-pong）→ Result（艺术画布） |
| 4 | `PixelartOutlineFeature` | `AfterRendering` | v3 式描边（艺术画布）→ 写 `Outline` 缓冲 |
| 5 | `PixelartRimLightFeature` | `AfterRendering` | 清 RimLight → 累加 blit → `RimLightCorrection.compute` 去孤立点（就地） |
| 6 | `PixelartShadingFeature` | `AfterRendering` | 清四张 → Diffuse → Specular → GI → **Combine**（四项相加 → Cast 颜色目标） |
| 7 | `PixelartColorCorrectionFeature` | `AfterRendering` | 帧级调色板 LUT 映射（就地） |

Screen 渲染器：`PixelartScreenCopyFeature`（点采样上屏 + `_PixelartSnapOffsetUv` 偏移）。

**先后是契约的一部分**：边缘光早于 Diffuse（Diffuse 读 RimLight 缓冲做 `applyAA` 门控）；
描边早于着色（着色读 Outline 决定墨线像素）；合成晚于四趟；调色板最后。

## 4. 各模块口径

### 4.1 连通域（`$P/ComputerShaders/Connectivity/*.compute` + `$P/Shaders/Includes/Connectivity.hlsl:42-104`）

- **Check** `[numthreads(8,8,1)]`，派发 `ceil(FineW/8) × ceil(FineH/8)`：读 `Normal0` + `Depth`，
  四方向各一次 `CheckConnectedDepthNormal`，打包 bit7/6/5 → `ConnectivityDetail`。
- **Flood** 同尺寸、跑 `RoundToInt(k*1.5)` 次，每次先 `Detail → Prev` 再就地传播。
- **Result** 派发 `ceil(ArtW/8) × ceil(ArtH/8)`，遍历每个画布像素对应的 `k×k` 细粒度单元。
- **判据本体**：两端法线各自预测深度、比残差，**两端同时超阈值**才判不连通（蓝图 §3.1）。
  **本仓坐标系**：法线是**世界**法线、深度是**深度附件**。翻译时把 v3 的视图空间量与之一致化，
  并在注释里写清做了哪一步变换（这是本移植里唯一需要推导的部分，必须留痕）。

### 4.2 漫反射与高光（`$P/Shaders/Includes/Passes/ShadingPass.hlsl`，逐行）

```hlsl
// DiffuseShading（:37-63）量化段之后的三行，本仓口径见 §6
if (ndotl > singleLevel && connect < _PixelartAAThreshold) ndotl -= applyAA * singleLevel;  // 连通域降档 = 内线
if (normalDiff > normalEdgeThreshold)                      ndotl += singleLevel * normalEdgeLevel;
ndotl = clamp(ndotl, 0.0, 1.0 + singleLevel);
ndotl = lerp(transmission, 1.0, ndotl);
```
- `applyAA` 三项：`rim` 缓冲三通道**都判**（v3 `:93` 把 `g` 判两次、`b` 一次没判——**不继承**，
  蓝图 §4.4 第 2 条）× `shape.a`（AA 缩放）。
- 附加光：`LIGHT_LOOP_BEGIN(_PixelartAdditionalLightCount)` + `GetAdditionalPerObjectLight(lightIndex, positionWS)`，
  档数用 `level * 0.5`、偏移 3.0（v3 `:101-104`）。阴影：`GetMainLight(shadowCoord)`，坐标由
  **深度重建的 `positionWS`** 算出（`_MAIN_LIGHT_SHADOWS(_CASCADE)` 那组 multi_compile 要加回来）。
- Specular：v3 `:117-126` 逐行（`multiStep(pow(NdotH, expSmoothness))`），光滑度/金属度来自 `Physical`。
- GI：本仓简化为 `环境色 × albedo`（蓝图 §7.2 第 5 条），**暗部色即此项**。
- 墨线像素（`Outline.r > 0.5`）在 **Diffuse/Specular/GI/RimLight 四趟里都提前返回 0**，
  由 Diffuse 输出墨色；否则墨线会被环境光/边缘光染色【本仓口径】。
- 背景像素（`albedo.a < 0.5`）`clip` 掉，保留 Cast 颜色目标上的背景色。

### 4.3 边缘光（`$P/Shaders/Includes/RimLight.hlsl:16-20`）

屏幕空间光向门控：`TransformWorldToViewDir(direction).xy` 归一化 → 四方向 clamp → 乘 `(1 - connected)`
→ 乘 `RimLightProperty.rgb`。`RimLightCorrection.compute`（3×3 去孤立点）只作用于 RimLight 缓冲。
**边缘光是"光照层的边缘提亮"，与墨线正交**——命名与代码一律不许混。

### 4.4 描边（**本仓口径：v3 `OutlinePass.hlsl` 的屏幕空间膨胀**，创始人 2026-09-22 裁决）

几何壳（反向壳）被弃用：它沿面法线外扩，在箱体的左下/右下两条剪影边（正面墙底边）上投影到
`cos45° ≈ 0.7` 艺术像素 < 1 ⇒ 亚像素 ⇒ 量化后**断续**、且角部外扩重叠出堆块（r6 实测定位）。

新口径（艺术画布，1 采样/像素）：

1. 采样本像素与 4 邻域的 `Albedo.a`（覆盖）与 `Palette.a`（applyOutline 位）；
2. 邻接判据（v3 `OutlinePass.hlsl` 原样）：本像素无覆盖/属于背景、或邻域属于**另一个物体**
   （连通域门控 `connectedTo* < 1 && closerThan* < 1`）；
3. 命中且该物体 `applyOutline != 0` ⇒ 写 `Outline.r = 1`（线宽恒为 **1 艺术像素**，必然闭合）。

墨色取全局 `_PixelartInkColor`（默认 `#120C14`）；逐物体墨色是后续扩展（v3 自己也是单色）。

### 4.5 帧级调色板（P5）

`PaletteGenerationCIEDE.compute`（`[numthreads(8,8,8)]` + **三维派发**，通用 `ComputeShaderPass` 装不下）
→ 2D RGB 条带 LUT；`ColorCorrection.shader` 的采样公式照 v3；调色板数据 = `Color[]`。
**本仓**：默认调色板**从试点场景的材质色自动生成**（材质 `_BaseColor` + 墨色 + 环境暗部色），
色数 = 收集到的唯一色数（创始人 2026-09-22 裁决：首版观感变化最小）。

## 6. 与 v3 的刻意差异

1. **G-buffer 在屏幕档、着色/描边在艺术画布**（= v3 的原样；蓝本 §1.3 的九步就是把着色搬进低分辨率域）。
2. **描边机制**：v3 的 `OutlineRendererFeature` 是 `m_Active: 0`（关着的），我们**启用并改造**它
   ——它给的是艺术画布的屏幕空间线，正好解决几何壳的断续。这不违反"补齐 v3"，反而是把 v3 里没接通的零件接通。
3. **墨线标记放独立缓冲 `Outline`**（不占 `Shape.g`/`Palette.a`——`Palette.a` 保持 v3 的 applyOutline 语义）。
4. **优先级仲裁 / UV 缓冲不移植**（v3 的死 pass，蓝图 §4.1/§7.3 第 1 条）；`Shape.r` 写 0 预留。
5. **第 8 个 MRT 输出（lightmap UV）不做**（v3 未接通）。
6. **不用 `_ScreenParams`**；走显式尺寸全局。
7. **缓冲格式直存**，不用 v3 的 `SNorm16` + 字节打包。
8. **GI 简化为环境光项**（蓝图 §7.2 第 5 条）；`Specular` 与 `Physical` 本轮**补回**（创始人裁决）。
9. **逐物体像素吸附**：实现 v3 `CommonPass.hlsl:5-57` 的顶点着色器原点对齐（**取一层**，蓝图 §1.4 ⚠），
   由材质 `_SnapToPixelGrid` 开关，**默认开**（创始人裁决）。
10. **上屏宽高比**：保留本仓"锁 pixelScale 整数倍"（蓝图 §7.2 第 7 条），不退化成 v3 的固定尺寸拉伸。
11. **不用 `DrawRenderers` 之外的排序**：描边改屏幕空间后，几何只靠深度测试分前后（`ZTest LEqual`），
    远→近的手工排序与逐物体提交**一并删除**。

实现与首轮实拍（[r7 归档](../../images/pixelart-path/r7/README.md)）之后，以下几条已经定型，
它们是**契约的一部分**，不是"实现细节"：

| # | 口径 | 为什么冻结 |
| --- | --- | --- |
| 1 | 连通域判据本体落在 `Assets/Art/Compute/Connectivity/Connectivity.hlsl`（**与三个 compute 同目录**），不在 §5 表里写的 `Art/Shaders/Pixelart/Includes/` | `#include "Connectivity.hlsl"` 才能直接解析；也因此**描边与着色 shader include 不到它**，它们各自照抄 `Result.a` 的位序解包——两边必须同口径 |
| 2 | `ConnectivityResult.a` 位序（冻结）：`bit7/6/5/4 = connected 右/左/上/下`，`bit3/2/1/0 = closer 右/左/上/下`；**直存 UNorm8**（写 `byte/255`、读 `round(a*255)`），不用 v3 的 `PackFloatInt8bit` | 与 v3 `BuffersResolver.hlsl:23-31` 同序。**一位之差就是静默失效**（描边整体不出现或乱长）。描边与边缘光两处解包都按此实现且已互相核对 |
| 3 | 连通域 compute 的私有 uniform 名是 `_Threshold`（v3 同名），由 `PixelartConnectivityFeature.threshold` 字段（默认 0.25）下发；**它不是 shader 全局** | 只有 Check / Result 两段用 `SetComputeFloatParam` 绑它 |
| 4 | 另有一张 ping-pong 备份纹理 `_PixelartConnectivityPrevBuffer`（常量 `PixelartPath.ConnectivityPrevId`），**只作为 kernel 纹理绑定、不发布成全局** | 没有任何 shader 阶段按 uv 采样它 |
| 5 | **凡是被后续趟按全局名采样的缓冲，写完之后必须 `SetGlobalTexture` 发布**（Diffuse/Specular/GI 由着色趟发布；RimLight 由边缘光趟发布；Outline/ConnectivityResult 由各自趟发布） | 首轮实拍的整屏同色事故就是这个：只当渲染目标写过、没发布 ⇒ 后续趟读到未绑定 ⇒ `clip(diffuse.a-1)` 剪空，**每一趟日志都"执行成功"** |
| 6 | 物体 shader 的法线贴图通道用 `#pragma shader_feature_local _NORMALMAP` 隔开，**没有真挂贴图时整段不参与编译** | 不隔开时内建 `"gray"` 默认贴图会被 `UnpackNormalScale` 在 RG-or-AG 分支解成倾斜 30° 的假法线；而法线贴图活在**切线空间**，于是同一世界朝向的物体各自偏掉（创始人报的"两个角色打光方向不一致""地面没有全局光照"） |
| 7 | `_PixelartLightDirWS` / `_PixelartLightColor` 由 rig 每帧下发，且**着色两趟在 `GetMainLight()` 之后用它们覆盖主光的方向与颜色**（只借 URP 的 `shadowAttenuation`） | 不覆盖时 `PixelartCameraRig.lightIntensity` 这个美术旋钮失效、判据脚本的"下发值对色号"也不再成立（两者都是静默的） |
| 8 | 帧级调色板**默认关**（装配器 `PixelartPathInstaller.EnableFramePalette = false`，把 `palette` 字段置空 ⇒ 那一趟整趟跳过） | 首轮实测 LUT 索引口径不对：底色蓝灰被映射成暗紫、整屏发怪，且污染判据的颜色假设。资产仍然生成，改回 true 即开 |
| 9 | 实时阴影机制接通、**试点场景暂时 `sun.shadows = None`** | 首轮实测地面整片被判在阴影里（解析式核对：地面实测 = 纯环境项）。是阴影距离/级联/bias 的调参问题，不是架构问题 |
| 10 | 调试档位表（全局唯一，`_PixelartDebugMode`）：`0` 正常 / `1` albedo / `2` Normal1 / `3` 逐物体参数 / `4` 墨线标记 / `5` 连通域结论；**描边 shader 自己的诊断档取高位 `8`（门控命中）/`9`（覆盖图）**，避免与上面撞号 | 曾经描边用 5/6 而着色用 5 = 连通域，同一帧里两个 pass 对同一个全局量各有一套解释 |



## 7. 验收

- **编译**：batchmode 打开工程退出码 0；**shader 必须在真实渲染路径验证**（`-nographics` 不编译 shader）。
- **出图判据**（新增三项，与既有五项并存）：
  - **内线存在**：连通域降档像素占非背景像素比例 > 0；
  - **描边闭合**：`tools/pixel-review/ink_gap_probe.py` 的「剪影外侧无墨线的边界」占比 **< 0.5%**（现状 2.7%）；
  - **调色板生效**：出图唯一色数 ≤ 调色板色数 + 少数抗锯齿边。
- **可回退**：每个子件能单独关（`applyOutline` / `_RimLightColor` 黑 / 调色板资产为空 = 不映射）。
