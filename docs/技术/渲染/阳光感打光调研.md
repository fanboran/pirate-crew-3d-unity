## 0. 结论先行（TL;DR）

现状的核心问题不是"不够亮"，而是**直射与天光的比例偏低 + 天光颜色偏灰 + Bloom 阈值过低**，
于是画面"亮但平、亮而糊"，读不出"太阳"这个单一强光源。三条最高性价比改法：

1. **把阴影做实**：主光 `shadowStrength` 0.7 → **0.86**（`Battle.unity:10908` + `BattleSceneLighting.cs:799`）。
   本项目 shader 的环境光**不乘阴影衰减**（`PirateSurface.shader:452-454`），所以加深阴影**不会死黑**，
   只会把"太阳直射 vs 天光"的分界线拉清楚——最便宜的一刀。
2. **拉开直射:天光比例**：主光 1.35 → **1.55**，环境光强度 1.0 → **0.85**
   （两处必须同步：`BattleSceneLighting.cs:766` 与 `AmbientTimeOfDayCatalog.cs:141,143`）。
   依据：Unreal 官方文档给出晴天**天光约占总照度 20%**（直射:天光 ≈ 4:1，【已核实 S13】）；
   现状【估算】仅 ≈2.6:1（§2.5），所以"太阳感"立不住。
3. **Bloom 阈值抬回正常区**：threshold 0.85 → **1.05**、intensity 0.55 → **0.42**、scatter 0.70 → **0.62**
   （`BattleSceneLighting.cs:538/540/542`）。URP 官方文档明确 Bloom Threshold 是 **gamma 空间亮度截断、
   默认 0.9、无上限**（【已核实 S3】）；0.85 会把大片"接近白"的沙地/水面也点亮，正是"亮而糊/刺"的直接来源，
   也与工程自己的美术风格指南 §4.5 区间（1.0–1.2 / 0.25–0.45）相矛盾，属实现偏离文档。

> 一句话：**阳光感 = 单一强方向光的高对比 + 被蓝天空染色的透气阴影 + 一点点镜面闪烁 + 不糊的亮部**，
> 而不是"把画面调亮"或"把太阳画出来"。

## 1. 阳光感的视觉构成要素（不依赖太阳盘/地平线）

判断前提：**阳光是一种"光的关系"，不是"天上那个圆盘"**。取景里没有太阳时，观众靠下列间接证据链仍能
读作晴天；反过来，缺任何一环，即使把太阳盘画得很亮也只像"补光灯下的室内"。

### 1.1 暖白主光：色温与"单一光源"的绝对主导
- 日光标准色温在 D55–D65（约 5500–6500K）；Unity `Light` 与 Unreal Directional Light 都把 **6500K 定义为"白"**
  （【已核实 S15】：Unreal "Temperature ... White is 6500K"）。低于 6500K = 偏暖白，这就是"阳光"的底色。
  本工程主光 `#FFF4E0`（≈5000K 暖白）方向正确。
- 关键不是"多暖"，而是**它必须是唯一主导光源**：两盏同等强度的方向光立刻把"晴天"打成"摄影棚"
  （工程美术风格指南 §4.1 也明文禁止）。
- **纯度纪律**：主光暖色若被后处理整体白平衡抵消，暖冷关系就丢了。调暖白平衡时必须同时让天光**更蓝**，
  不能两边一起变暖。

### 1.2 天空环境光的蓝色反弹（Rayleigh 散射的必然结果）
- 白天天空发蓝是 Rayleigh 散射的波长选择性（【已核实 S13】：Unreal Sky Atmosphere 文档
  "Rayleigh ... is wavelength-dependent, makes daytime sky blue"）。
- 让场景"沐浴天光"的标准做法是用**天空作环境光来源**：Unreal Sky Light 就是"捕获远处场景（大气/天空）
  当作环境光"（【已核实 S14】）；Godot 的 `ambient_light_source = Sky` + `Sky Contribution`（默认 1.0）同理
  （【已核实 S17】）。
- **工程含义**：环境光必须**明显偏蓝**，且**亮度低于直射**。天光偏蓝 → 阴影偏蓝（§1.3）；天光过亮 →
  阴影发灰、对比被稀释。
- **三色 Gradient 的物理对应**：Unity 的 Sky / Equator / Ground 是给"朝上 / 竖直 / 朝下"三种法线分别配色
  （【已核实 S10】）。对应户外：朝上的面接收整片蓝天（冷）→ 竖直面接收一半天空（中性偏冷）→
  朝下的面接收地面反弹（暖）。物理对应物是 Unreal Sky Light 的 Lower Hemisphere Color（S14）与 GI 反弹项。

### 1.3 阴影的浓度与颜色：晴天阴影"偏蓝，但不是黑"
- 背光面**只被天空照亮**，所以户外阴影天然**偏蓝**——这是 §1.2 的推论，不是美术口味。
- **浓度的物理上界**：Unreal 官方给出，太阳在正头顶约 120,000 lux，白色漫反射面总照度约 150,000 lux，
  其中**天空约占 20%**（【已核实 S13】）→ **直射:天光 ≈ 4:1**（阴影亮度约为受光面的 1/5）。
  这是"晴天阴影该多深"的物理上界；游戏为可读性通常软一点（3:1~4:1）。
- **工程关键机理**：`PirateSurface.shader:452-454` 把 `SampleSH` 环境光**加在阴影衰减之外**——阴影里的漫反射
  **不随阴影变暗**。好处：阴影永不"死黑"；代价：**阴影浓度完全由环境光强度决定**。故想加深阴影，
  要么提 `shadowStrength`（只压直射，安全），要么降环境光强度（会压暗全局，需配合曝光补偿）。

### 1.4 高光锐度：specular glints 是"阳光在闪烁"的直接证据
- 太阳是**极小立体角**的强光源，对光滑表面的镜面高光因此非常**紧、亮、随视角滑动**。这套"闪烁"
  （水面波光、黄铜棱角、铁器边缘）是"画面里有太阳"最有力的**动态**证据，且**不需要太阳入镜**。
- 前提三件套：① 材质 smoothness 够高；② 曝光**不过曝**（过曝后高光变成死白，闪烁感消失）；
  ③ 有可反射的亮环境（天空/反射探针）。
- 现状：水面 `_Smoothness 0.92 / _SpecularIntensity 2.2`（`BattleSceneLighting.cs:443-444`）glint 基础很好；
  金属偏哑（黄铜 0.75 / 铁 0.45）；沙地 0.12 几乎无高光（符合"干沙"物理）。
- **注意**：真实晴天沙地有**微弱**颗粒反光，0.12 偏保守；略升到 0.15–0.18 会更"像沙"，但别超 0.2（会塑料化）。

### 1.5 明暗对比：亮部不过曝、暗部不死黑
- 曝光中性锚点是 **18% 中灰**（【已核实 S16】Unreal Auto Exposure）。实际含义：**画面"中间"应落在中灰，
  而非接近白**。直射面大面积贴到 1.0，就没有"上方空间"给高光，tonemap 滚降被压平——观感就是"刺"。
- 亮部滚降由 Tonemapping 承担（URP Neutral 只对 >1 的 HDR 高光滚降、保色，但滚降弱于 ACES，【已核实 S4】）；
  曝光由 Color Adjustments 的 `Post Exposure`（EV、tonemap 之前）承担（【已核实 S5】）。
- **"暗部透气"不是把暗部抬亮**，而是让暗部**有颜色、有层次**：偏蓝天光 + 暖地面反弹 + 不压到 0。
  这天然由 §1.2 的三色 Gradient 提供。

### 1.6 色彩饱和策略：暖色主导 + 冷色阴影的互补
- 明媚不是"整体高饱和"，而是**暖冷互补**：受光/高光偏暖（黄→橙→暖白），背光/阴影偏冷（蓝→青）。
  URP 有两套现成工具：**Split Toning**（Shadows/Highlights 各选色相 + Balance，【已核实 S9】）与
  **Shadows Midtones Highlights**（三亮度区间分别色相/明度偏移，【已核实 S7】；本工程已用，
  `BattleSceneLighting.cs:584-590`）。两者**二选一**，勿叠加。
- 饱和度要**分区看**：整体猛拉会把阴影也拉艳，反而脏。正确做法是阴影"冷而干净"、受光面"暖而饱和"。

### 1.7 大气透视：远景向天空色收敛
- 晴天远处空气把远景"洗"向天空/地平线色，同时**降对比、降饱和**——既是深度线索也是"开阔感"来源。
  机制是 Mie 散射与气溶胶（【已核实 S13】：Unreal Rayleigh/Mie + AerialPerspectiveLUT）。
- 工程等价物是**线性雾**，纪律是：**雾色必须与天空/地平线同族**，否则不是"大气透视"而是"盖灰"
  （工程美术风格指南 §4.4 同款结论）。
- **本工程特殊约束**：相机 45° 俯视、画面上缘在水平线下约 15°，**地平线不入画**
  （`BattleSceneLighting.cs:699-702` 已记录）。雾只服务"远处海面/远景剪影与近景分离"，**不为地平线衔接负责**。

**两个机理问题（读代码得出，非猜测）**：

- **P1 环境光不吃阴影衰减**：`PirateSurface.shader:452-454` 注释明写"环境光不乘阴影衰减——否则阴影里会死黑"。
  因此**阴影浓度 100% 由环境光强度决定**，也意味着**提 `shadowStrength` 绝对安全**（只压直射）。
- **P2 运行时正午档会覆盖主光与雾**：`AmbientDirector.ApplyPreset()`（`AmbientDirector.cs:378-405`）在 Start 用
  `AmbientTimeOfDayCatalog.For(Noon)` 覆写主光颜色/强度/姿态与雾。**任何改主光或雾的调法必须同步
  `AmbientTimeOfDayCatalog.cs:138-144`，否则一开局被写回旧值。** 另注：该函数在非 Skybox 模式会写
  `RenderSettings.ambientLight`，但 Gradient 模式下 `ambientLight` **无效**（只用三色）——即
  `NoonAmbientHex = #C8DDF0` 这行**没有任何画面效果**。想改环境光颜色只能改
  `BattleSceneLighting.ApplyThreePointAmbient()`。这是当前"改了没反应"的陷阱，建议后续清理注释。

**"太阳盘与天空盒"的机会成本（重要）**：相机 pitch 固定 45°、FOV 60°，画面上缘在水平线下约 15°，
太阳盘与地平线**永不入画**（`BattleSceneLighting.cs:699-702` 已记录）；又因环境模式是 Gradient，
天空盒**不参与漫反射**。它只剩两个真实作用：① 背景（抬头才见）；② 默认反射（`m_DefaultReflectionMode: 0`，
分辨率仅 128）给 `GlobalIllumination()` 的间接镜面提供一点环境。
结论：**继续调天空盒太阳盘对"阳光感"近乎零产出**，预算应转向"反射探针 + 镜面 glint + 对比/颜色"。

| --- | --- | --- |
| **Sea of Thieves**（Rare，海盗题材，与本项目最贴近） | 高饱和暖色 albedo + 单一强太阳 + 大面积天光 + 强烈空气透视；海面镜面 glint 极亮极紧，是"太阳在闪"的主证据【未核验】 | ① albedo 直接画饱和（不靠后处理拉）；② 让海面/金属有**紧的高光**并允许略过曝（Bloom 只收它）；③ 雾把远景洗向天空色，制造开阔 |

| **Northgard**（Shiro Games） | 低模 + 高饱和地块 + 暖太阳；"晴朗"来自**地面材质本身的饱和度**与天光，而非把光照调亮【未核验】 | ① 地面色阶饱和度优先于打光；② 阴影柔和且方向一致；③ 避免材质大幅 AO 压暗（会显脏） |
| **Overwatch**（暴雪，日照图如伊利奥斯） | 强太阳 + 强天光，但角色任何朝向都**可读**：靠环境光补足暗面【未核验】 | ① 保证阴影侧仍有足够天光（本工程靠 Trilight Equator）；② 轮廓靠自发光/描边而非提亮阴影；③ 暖冷分离明确 |

## 4. 给我们工程的 8–12 条具体调法清单（按性价比排序）

> 全部【提案/待定】。改主光/雾**必须同步 `AmbientTimeOfDayCatalog.cs` 正午档**（§2.5 P2）；
> 改场景序列化值**必须同步对应 Editor 脚本**（否则重建场景回退）。旧值均已核对到文件行。

**第 1 档：低风险、高收益（先做这 4 条）**

- **A1 阴影做深（只压直射，绝对安全）**
  `Battle.unity:10908` + `BattleSceneLighting.cs:799`：shadowStrength **0.7 → 0.86**。
  依据：Unity 阴影强度默认 1.0（S11）；环境光不乘阴影衰减（`PirateSurface.shader:452-454`），加深不会死黑。
- **A2 拉开直射:天光比例（两处文件必须同步）**
  `BattleSceneLighting.cs:765-766`、`AmbientTimeOfDayCatalog.cs:141/143`：主光 **1.35 → 1.55**，
  环境光强度 **1.0 → 0.85**。依据：Unreal"天光约占总照度 20%"（S13）→ 4:1；现状【估算】≈2.6:1
  （受光面 ≈1.35×0.74+0.63 ≈1.63，阴影面 ≈0.63；0.74 = sin48°）。目标先取 **≈3.2:1**（给可读性留余量），
  实机不刺再往 3.8:1 推。
- **A3 Bloom 回到正常区（直接解决"刺/糊"）**
  `BattleSceneLighting.cs:538/540/542`：threshold **0.85 → 1.05**、intensity **0.55 → 0.42**、
  scatter **0.70 → 0.62**。依据：URP Bloom 文档 Threshold 为 gamma 空间截断、默认 **0.9**、无上限；
  Intensity 0–1；Scatter 默认 0.7（S3）。工程美术风格指南 §4.5 区间亦为 1.0–1.2 / 0.25–0.45。
- **A4 上曝光负补偿，把亮度从主光手里拿回来**
  `BattleSceneLighting.cs:559`：postExposure **0 → −0.15 EV**（配合 A2 抬光，整体观感亮度不变、高光有空间）。
  依据：Post Exposure 在 tonemap 前、以 EV 计（S5）；18% 中灰锚点要求"亮部之上还有空间"（S16）。

**第 2 档：中收益、需实机对色（再做这 4 条）**

- **B1 天光三色提纯** `BattleSceneLighting.cs:761-763`：Sky `#7EA8CC → #6E9FCF`；
  Equator `#93A2AC → #86A2BE`；Ground `#C9A268 → #D2A96A`。
  依据：天空因 Rayleigh 偏蓝（S13）；竖直面应由"半天空+半反弹"得**中性偏冷**；地面反弹偏暖（S14）。幅度刻意保守。
- **B2 强化暖冷互补** `BattleSceneLighting.cs:586/590`：shadows `(0.956,1,1.090) → (0.94,1,1.12)`；
  highlights `(1.045,1,0.935) → (1.06,1,0.92)`。依据：URP SMH 分区调色（S7）；也可改用 Split Toning（S9）——
  **两者不要同叠**。⚠ 本工程 `m_ColorGradingMode = HDR`（线性 log 域 LUT），SMH 感知强度与 LDR 档不同，需实机 A/B。
- **B3 对比/饱和微升** `BattleSceneLighting.cs:561/563`：contrast **+12 → +20**；saturation **+10 → +14**。
  依据：明暗分离是"阳光感"核心（S5）；饱和要克制，配合阴影变冷才不脏（§1.6）。
- **B4 反射探针（把天空盒变成"可见的光"）** 新增 1 个 Baked Reflection Probe 覆盖竞技场
  （中心 y≈2、Box Projection），可选水面附近 1 个（128）。依据：URP 间接镜面走
  `GlossyEnvironmentReflection` → `unity_SpecCube0`（`GlobalIllumination.hlsl:309/362` 已核实）；
  当前无探针、只有 128px 默认天空盒反射 → 金属反射钝。探针能把天空盒亮度投到黄铜/铁/水面，
  回收 §2.5"天空盒零产出"。

**第 3 档：风格微调（有余力再做）**

- **C1 水面 glint 更"闪"**（与 A3 配套，确保不过曝成白片）`BattleSceneLighting.cs:444`：
  `_SpecularIntensity` **2.2 → 2.8**（`_Smoothness` 0.92 不变）。依据：太阳为小立体角强光源 → 镜面高光紧而亮（§1.4）。
- **C2 沙地/地形微高光** `BattleSceneLighting.cs:173`（干沙）、`:484`（地形）：**0.12 → 0.16**、**0.15 → 0.18**。
  依据：真实沙面有微弱颗粒反光；上限 0.2 以内防塑料化。湿沙已有 0.22 + 湿润增益，不动。
- **C3 主光色温口径显式化（可选）** `BattleSceneLighting.cs:793` 附近：`light.useColorTemperature = true;
  light.colorTemperature = 5200f`（`Battle.unity:10943` 现为 0）。依据：Unreal 以 6500K 为白（S15）；
  日光标准色温 D55–D65【通用知识，未核验】。若维持 hex 原色则本条可跳过（工程已开 `lightsUseColorTemperature`）。
- **C4 单位接触阴影** 新增脚底径向渐变 Decal/贴片（直径约 0.6 单位）+ `BattleSceneSetup` 装配。
  依据：工程美术风格指南 §4.1【AI 提案】；低模强阳下缺接触阴影会明显浮空，是"阳光可信度"最后一环。成本中等故排第 3 档。

**明确"不要做"的两条**

- **不要加第二盏方向光补光**：`PirateSurface/PirateTerrain/PirateOutline` 只取 `GetMainLight + SampleSH`，
  **不支持 additional lights**（`PirateSurface.shader:165` 仅编译阴影关键字，无 `_ADDITIONAL_LIGHTS`）；
  加了也不影响场上材质，且违反风格指南 §4.1。补光一律走环境光 SH。
- **不要再投天空盒太阳盘**：取景永不见太阳盘，且 Gradient 模式下天空盒不参与漫反射
  （`m_AmbientMode: 1`，`Battle.unity:27`）。除非未来放宽相机 pitch，否则投入产出比≈0。

**落地后的程序化验收判据（建议）**：在 `ArtReviewCapture` 取景下采样——① 受光沙地 vs 同材质阴影区亮度比
**2.8:1 ~ 3.8:1**；② 溢出像素（=1.0）占比 **<3%**；③ 阴影区最暗不低于 **0.12–0.15**（不死黑）；
④ 阴影区平均色相对受光区**偏蓝**（B 通道占比更高）。四条同满足才算"亮而不刺、暗部透气、有暖冷对比"。
