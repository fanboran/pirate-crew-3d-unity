## 1. 坐标系（本文档是权威）

```
世界 X = 竞技场横向      ← 关卡数据网格列 gridX
世界 Z = 竞技场纵深      ← 关卡数据网格行 gridY
世界 Y = 高度（向上为正） ← 重力方向；地面顶面 y = 0，水面 y = -0.4（真源 LevelGeometry，现行口径）
```

**要点**：

- 竞技场是 **XZ 水平面**（不是竖直面）；重力沿 **-Y**。
- 关卡数据的网格坐标按**平面图**投影：`(gridX, gridY) → (X, Z)`。gridY 表示**纵深位置**；
  关卡数据里的旧水面行字段**不再参与映射**（见 §4 水域）。
- **数据网格 1 格 = 2 m**（现行格距，M2 落地时为对齐竞技场跨度放大；换算真源 `LevelGeometry`）。
- **y 轴不再取负**：gridY 直接成为 +Z。理由：原 2D 侧视布局里"越往下"= 越靠近观众；
  在平面图里"越靠近观众"= +Z（相机在 +Z 侧），方向天然一致，无需翻转。
- 单位枢轴（pivot）离地 0.25 世界单位，即脚底贴 y = 0、枢轴在 y = 0.25
  （与原版角色贴图的脚底偏移同源，换算真源 `LevelGeometry`）。

## 3. 投掷与瞄准

- **方向**：标准投掷的方向角是**世界方位角**（操作模组参数，XZ 水平面上取值）；操作中相机
  锁定，瞄准参数与世界方向的映射与相机方位无关。旧「屏幕拖拽 → 相机基向量投影」映射已随
  弹弓/炮台合成口径退役（米制重立，2026-10-03）。
- **力度/初速/仰角/重力**：均为**米制常量**，规格与真源在
  [投掷行为契约](投掷行为契约.md)（`StandardThrowRules`），本文不重复数值；本文只锁语义：
  仰角只决定初速方向、不改初速大小；重力沿 -Y 全工程统一——这是"预览 = 实弹"的根基，**不动**。
- **"预览 = 实弹"这条不变量（重要）**：预览、实弹（以及重做后的 AI）共用**同一积分器、同一份初速、
  同一份重力与 dt**——载体与完整规格见[投掷行为契约](投掷行为契约.md)。
  ⚠ 不要让任何人再写第二套 3D 积分。
- **瞄准落点**：射线打 XZ 地面（y = 0 平面）。
- **选中拾取**：屏幕空间 30px 规则，与维度无关，**不动**。

## 4. 水域与死亡

- 水面 = 世界 Y 阈值常量 **y = -0.4**（现行值以 `LevelGeometry` 为准；M4 起海洋平面亦按此对齐）。
- 判定按「世界 Y 是否低于水面阈值」进行；方向无关——从 X 或 Z 任一侧掉出地面都会落水。
- 关卡数据里的旧水面字段仅作存档保留，不参与运行时映射（地图已平坦化，竞技场为平面）。

## 5. 爆炸与击退

- **合成口径**：距离用 **3D 距离**（含高度差），爆炸为 3D 球；击退 = 3D 径向单位向量（水平分量）
  再叠加竖直抬升项。公式与常数的真源在爆炸结算与平衡配置模块（代码注释即口径）。
- 实现约束：坐标/目标加第三分量后，既有 2D 用例（z=0）结果**逐值不变**；3D 运行路径传真实高度。

## 7. 明确保留的既有决策

- 数值三层（纯 C# 目录 → SO → 编辑器生成器）的**分层结构不变**；各数值本体的取值口径属对应模块
  （本文不为其背书，见各模块的设计文档与代码注释）。
- 战斗纯逻辑（回合/计分/武器触发）**口径不变**。
- 描边链路**不变**——现役为像素化着色路径的描边（口径见[渲染管线.md §6.1](渲染/管线/渲染管线.md)）。
- 固定物理步长（1/25 s）与 25 Hz 回合节奏口径**不变**；投掷重力与初速为**米制常量**
  （真源 `StandardThrowRules`，见[投掷行为契约](投掷行为契约.md)）。

## 关卡重制的设计契约（2026-09-14 用户裁决：不能摊成一排平面，要做出真 3D 的空间感）

原版关卡是 **2D 侧视**布局（仅作灵感来源）：行 rowY 表示**离水面的竖直高度**，不是深度。本工程重制沿用其高度语义：
1. **rowY → 高度**：草皮/甲板行的行号决定该岛悬浮高度（行号越大浮越高，贴水行贴水）；换算以水面行为 0 向上累计，
   相邻可互达岛高差 ≤ 投掷竖直跨越上限，大高差保留"越水武器/绕路"玩法语义。
2. **Z 深度是 3D 新增维度**：每岛 2-5 格厚度（按 X 跨度缩放），相邻岛 Z 错开制造纵深；单位在岛厚内按确定性规则分路。
3. **单位坐标语义**：gridX/gridY 记为 (x, 行)；落位时 gridY 查所属岛 → 世界高度 = 岛高 + 岛内 Z 分路。
4. 土/岩石行 = 岛体厚度（视觉），草皮/甲板行 = 可站顶面。
（"gridY→Z 直接铺平面"口径废止——那会摊成"一排平面 pancake"。）

**【想象力条款（2026-09-14 用户二次裁决："重制时发挥想象力，别被具体坐标框住，要做出真正 2D 变 3D 的空间感"）】**
上述映射是**底线约束不是设计方法**。硬锚点只有四个：①单位出生在正确的岛的可行走面；②岛间相对高度次序保持；
③隔水对与水距语义保持；④每关的记忆点必须在（大船/乌鸦巢/最高峰等）。底线之上是**重制设计师的自由**：
岛形有机化（把像素方块读成"这座岛本来该有的样子"）、Z 纵深按 3D 构图摆布、尺寸 ±30% 呼吸、高度按可读性与手感调。
