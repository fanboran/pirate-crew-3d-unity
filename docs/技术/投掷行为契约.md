# 投掷行为契约

> **定位**：战斗投掷「玩家可感知行为」的**唯一规格**（单一事实源）。
> 实现 = `AimThrowController`（输入/状态机）+ `LevelGeometry`（换算）+ `ThrowTrajectory`（积分）；
> 测试 = `Assets/Tests/Battle/` 既有纯 C# 用例（本契约的可执行形式）+ PlayMode 契约用例（待补）。
>
> **为什么有这份文档**：r12 把瞄准改成炮台模式后，旧的鼠标弹弓拖拽路径成为不可达死代码，
> 但注释/参数/文档仍按「拖拽」口径描述行为——实现与规格分叉。交互形态经创始人
> 2026-09-24 裁决为**炮台为唯一瞄准交互**（死路径已根除），本契约自此立约：
> **行为改动必须先改本契约，再动实现，同步测试**（AGENTS.md「核心行为指令」§4）。

## 不变量（任何改动不得破坏）

1. **预览 = 实弹 双端同源**（AI 评估链已整拔，评估端随武器重做再立）：唯一积分器
   `ThrowTrajectory.Predict`、唯一初速入口 `LevelGeometry.ThrowVelocityForWeight`、
   同一 dt（1/25）与重力（`-39.0625 × weight`）。
2. **抛自己 / 用武器二选一**（§3.4 回合经济；`TurnRules.ApplyThrowSelf/ApplyUseWeapon`）。
3. **误触保护**：炮台虚拟拖拽下限 `TurretMinDragPixels = 5px`（力度 0 时仍有最小初速，不产生零向量发射）。
4. **数值取 Flash**：`Ballistics` 的 0.25 系数 / `twangMax` / `FullForceDragDistance` 不在本契约的改动范围
   （改动须创始人裁决并过 `BallisticsTests`；逆向文档已归档，仅作历史出处）。
