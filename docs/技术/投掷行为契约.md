## 不变量（任何改动不得破坏）

1. **预览 = 实弹 双端同源**：唯一积分器 `ThrowTrajectory.Predict`、同一初速（`StandardThrowRules.ComputeLaunchVelocity`）、同一重力与 dt（固定步长 1/25 s 保留）。AI 评估链将来再立时同用。
2. **抛自己 / 用武器二选一**（§3.4 回合经济；`TurnRules.ApplyThrowSelf/ApplyUseWeapon`）。
3. **误触保护**：力度下限 0.10（`MinPower`）——任何确认路径不产生零向量/近零发射。
4. **米制常量单源**：`MaxLaunchSpeed` / `LaunchGravity` / `ThrowOriginHeight` 只在
   `StandardThrowRules` 声明；`Physics.gravity`、弹体重力、预览积分全部引用它，**禁止第二处字面量**。
5. **旧换算链不得回流**：Flash px/帧、`twangMax`、0.25 系数、`FlashSpeedScale`、固定 ThrowLift=0.7
   等旧口径已随米制重立退役；爆炸域的 px 换算（`PixelsToUnits`/`ExplosionResolver` 接口）属武器
   数值域，**保留至武器系统重做**，不得当作投掷口径复用的理由。

## 重构纪律

1. **数值改动先过本契约**：速率/范围/默认值/常量的取值改动 = 契约表格改动（提案→定案须创始人
   实机验收），实现与测试随后同步。
2. **测试是契约的可执行形式**：#3 参数步进与夹取、#8 初速合成、#9 预览落点行为均由无头单测钉住。
